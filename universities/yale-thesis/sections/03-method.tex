\chapter{Block-Debiased Inference}
\label{ch:method}

Let the variants be partitioned into $B$ linkage blocks $G_1, \dots, G_B$, estimated from a
reference panel. Rather than debiasing each coefficient separately, we correct the lasso
estimate $\hat\beta$ one block at a time,
\begin{equation}
  \tilde\beta_{G_b} = \hat\beta_{G_b} + \frac{1}{n}\,\hat\Theta_{G_b} X^{\top}
  \bigl(y - X\hat\beta\bigr),
  \label{eq:blockdebias}
\end{equation}
where $\hat\Theta_{G_b}$ approximates the rows of the inverse covariance for block $b$. Because
the correction uses the whole block, the resulting test statistic asks whether \emph{any}
variant in the block is associated with the trait, a question that remains answerable when the
variants within it cannot be told apart.

Figure~\ref{fig:pipeline} summarizes the procedure. The block statistics feed a knockoff filter
built on the same partition, so discoveries are reported as blocks.
