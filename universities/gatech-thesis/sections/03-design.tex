\chapter{A Two-Sided Zero-Skipping Processing Element}
\label{ch:design}

Our processing element buffers compressed weight and activation fibres and uses a small
intersection unit to emit only coordinate-matched pairs to the multiplier. A load-balancing
network redistributes work between neighbouring elements when one runs out of effectual pairs.
