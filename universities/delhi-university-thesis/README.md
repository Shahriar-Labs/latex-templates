# Delhi University Thesis LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/universities/delhi-university-thesis/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

An unofficial University of Delhi thesis template on A4 in Palatino, with a declaration, a certificate by the supervisor, theorem environments and ten tables.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/universities/delhi-university-thesis/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Delhi University Thesis preview](preview.png)

## What is in it
- Document class: `report` with `12pt, a4paper, oneside`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, and 24 section files under `sections/`

## Use it online
Open **[Delhi University Thesis on LetX](https://letx.app/templates/universities/delhi-university-thesis/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/universities/delhi-university-thesis
latexmk -pdf main.tex
```
