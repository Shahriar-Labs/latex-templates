\section{System Architecture}
AL-TO is deployed as a sidecar scheduler co-located with an API gateway, as shown in Figure~\ref{fig:arch}. Incoming requests are annotated with predicted latency and routed to the edge cluster or cloud region that minimises expected SLA violation subject to the current cost budget.
