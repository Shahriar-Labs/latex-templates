\section{Future Directions}

Several avenues remain open for investigation:

\begin{enumerate}[leftmargin=*,itemsep=6pt]
    \item \textbf{Learned IAM.} The interference affinity matrix is currently profiled offline. Online learning of IAM coefficients from production traces would enable adaptation to workload drift and novel workload types.

    \item \textbf{Federated Edge Scheduling.} This work assumes a single scheduling domain. Hierarchical and federated scheduling across multiple edge domains (e.g., across cell towers owned by different operators) requires distributed consensus mechanisms.

    \item \textbf{Integration with Serverless.} Serverless edge platforms such as Cloudflare Workers and AWS Lambda@Edge introduce cold-start and invocation-pattern considerations that the current model does not capture.

    \item \textbf{Sustainability-Aware Placement.} Incorporating carbon intensity signals into scheduling decisions would allow edge operators to shift workloads temporally and spatially toward cleaner energy sources.
\end{enumerate}

The journey from cloud to edge is accelerating. Efficient scheduling is the quiet infrastructure that determines whether that journey succeeds. This thesis offers one piece of that foundation.
