\section{System Model}

We model an edge cluster as a set of \(M\) heterogeneous nodes
\(\mathcal{N} = \{n_1, n_2, \ldots, n_M\}\),
each characterized by a capacity vector
\(\mathbf{c}_i \in \mathbb{R}^d\) where \(d\) denotes the number of resource dimensions
(CPU cores, memory GiB, GPU fraction, network bandwidth Mbps).

\vspace{6pt}
A workload \(W\) is defined by a tuple
\((\mathbf{r}, \ell, \tau, \sigma)\) where:
\begin{itemize}[leftmargin=2em,itemsep=2pt]
    \item \(\mathbf{r} \in \mathbb{R}^d\) is the resource demand vector.
    \item \(\ell\) is the maximum tolerable latency (SLA), in milliseconds.
    \item \(\tau\) is the workload type (video analytics, stream processing, inference, batch).
    \item \(\sigma\) is the estimated throughput, in requests per second.
\end{itemize}
