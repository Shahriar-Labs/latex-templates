# University of Waterloo Thesis LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/universities/waterloo-thesis/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

An unofficial University of Waterloo thesis template on two-sided letter paper with a declaration, abstract, acknowledgements and an example edge computing thesis.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/universities/waterloo-thesis/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![University of Waterloo Thesis preview](preview.png)

## What is in it
- Document class: `report` with `12pt, letterpaper, twoside`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, and 23 section files under `sections/`

## Use it online
Open **[University of Waterloo Thesis on LetX](https://letx.app/templates/universities/waterloo-thesis/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/universities/waterloo-thesis
latexmk -pdf main.tex
```
