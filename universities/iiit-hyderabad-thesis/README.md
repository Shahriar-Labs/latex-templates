# IIIT Hyderabad Thesis LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/universities/iiit-hyderabad-thesis/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

An unofficial IIIT Hyderabad thesis template with the title, copyright and adviser's certificate pages its theses carry. If you can reach the intranet template, start from that one.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/universities/iiit-hyderabad-thesis/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![IIIT Hyderabad Thesis preview](preview.png)

## What is in it
- Document class: `report` with `12pt, oneside`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, `references.bib`, and 10 section files under `front/`, `sections/`

## Use it online
Open **[IIIT Hyderabad Thesis on LetX](https://letx.app/templates/universities/iiit-hyderabad-thesis/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/universities/iiit-hyderabad-thesis
latexmk -pdf main.tex
```
