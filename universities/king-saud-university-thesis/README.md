# King Saud University Thesis LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/universities/king-saud-university-thesis/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

An unofficial King Saud University thesis template for XeLaTeX or LuaLaTeX with polyglossia, carrying an Arabic abstract (ملخص البحث) alongside the English one and a committee approval page.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/universities/king-saud-university-thesis/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![King Saud University Thesis preview](preview.png)

## What is in it
- Document class: `report` with `12pt`
- Compiler: xelatex
- Files: `main.tex`, `preamble.tex`, and 25 section files under `sections/`

## Use it online
Open **[King Saud University Thesis on LetX](https://letx.app/templates/universities/king-saud-university-thesis/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/universities/king-saud-university-thesis
latexmk -xelatex main.tex
```
