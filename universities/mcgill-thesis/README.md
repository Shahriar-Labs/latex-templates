# McGill University Thesis LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/universities/mcgill-thesis/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

An unofficial McGill University thesis template on two-sided letter paper with an abstract and a French résumé, and a chapter on the university's bilingual context.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/universities/mcgill-thesis/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![McGill University Thesis preview](preview.png)

## What is in it
- Document class: `report` with `12pt, letterpaper, twoside`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, and 17 section files under `sections/`

## Use it online
Open **[McGill University Thesis on LetX](https://letx.app/templates/universities/mcgill-thesis/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/universities/mcgill-thesis
latexmk -pdf main.tex
```
