\section{Descriptor Set and Surrogate Model}

Each candidate SAM molecule is represented by an eight-dimensional feature
vector $\mathbf{x} = (x_1,\ldots,x_8)$ comprising anchoring-group binding
energy, molecular dipole moment, steric footprint (solvent-accessible
surface area), HOMO--LUMO gap, chain length, terminal-group Hammett
constant, computed $\log P$, and literature-reported deposition
concentration. The regression target is the measured $V_{oc}$-deficit
reduction, $\Delta V_{oc}^{\text{def}}$, relative to an untreated control
processed in the same batch.

A gradient-boosted regression tree (GBRT) ensemble of 300 trees (maximum
depth 4, learning rate 0.05) was trained with five-fold cross-validation,
achieving a held-out $R^2$ of 0.81 and root-mean-square error of 14~mV.
The trained surrogate $\hat{f}(\mathbf{x})$ and its predictive variance
$\hat{\sigma}^2(\mathbf{x})$, estimated from the ensemble spread, define
the expected-improvement acquisition function

\begin{equation}
\mathrm{EI}(\mathbf{x}) = \left(\hat{f}(\mathbf{x}) - f^{\star}\right)\,
\Phi(z) + \hat{\sigma}(\mathbf{x})\,\phi(z), \qquad
z = \frac{\hat{f}(\mathbf{x}) - f^{\star}}{\hat{\sigma}(\mathbf{x})},
\label{eq:ei}
\end{equation}

where $f^{\star}$ is the best value observed so far and $\Phi$, $\phi$
denote the standard normal CDF and PDF, respectively. Candidates were
ranked by $\mathrm{EI}(\mathbf{x})$ over a virtual library of 8{,}400
synthetically accessible molecules generated by combinatorial substitution
of anchoring groups, spacers, and terminal groups.

\begin{keybox}[title=Algorithm 3.1 --- Closed-Loop Candidate Selection]
\begin{enumerate}[leftmargin=*, itemsep=2pt]
\item Fit GBRT ensemble on current labeled dataset $\mathcal{D}$.
\item Score virtual library $\mathcal{V}$ using Equation~\eqref{eq:ei}.
\item Select top-$k$ ($k=3$) unlabeled candidates by $\mathrm{EI}$.
\item Synthesize candidates; fabricate and test devices.
\item Append new $(\mathbf{x}, y)$ pairs to $\mathcal{D}$; return to step 1.
\end{enumerate}
\end{keybox}
