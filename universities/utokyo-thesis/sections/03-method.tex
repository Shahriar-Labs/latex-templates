\chapter{A Matching Decoder with Learned Corrections}
\label{ch:method}

Minimum-weight perfect matching finds the most likely set of independent errors consistent with
the syndrome. We adjust its edge weights with a small neural network that recognizes syndrome
patterns typical of leakage and crosstalk, and run the matching on programmable logic next to the
control electronics.
