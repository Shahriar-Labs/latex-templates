\chapter{Background}
\label{ch:background}

The surface code arranges data and measurement qubits on a lattice and detects errors through
repeated stabilizer measurements \citep{kitaev2003, fowler2012}. Below a threshold physical error
rate $p_{\mathrm{th}}$, the logical error rate of a distance-$d$ code decreases as
\begin{equation}
  p_L \approx A \left(\frac{p}{p_{\mathrm{th}}}\right)^{\lfloor (d+1)/2 \rfloor},
  \label{eq:threshold}
\end{equation}
so each increase in distance suppresses errors further, provided the decoder is good enough.
