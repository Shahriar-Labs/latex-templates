# Tsinghua Thesis LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/universities/tsinghua-thesis/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

An unofficial Tsinghua University thesis template on the book class, A4 one-sided, in newpx fonts, with an example model compression thesis on deep neural network architectures.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/universities/tsinghua-thesis/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Tsinghua Thesis preview](preview.png)

## What is in it
- Document class: `book` with `12pt, a4paper, oneside`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, and 15 section files under `sections/`

## Use it online
Open **[Tsinghua Thesis on LetX](https://letx.app/templates/universities/tsinghua-thesis/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/universities/tsinghua-thesis
latexmk -pdf main.tex
```
