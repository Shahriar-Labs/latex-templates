\chapter{Plan-Then-Answer Decomposition}
\label{ch:method}

The procedure first asks the model to write a plan, a list of sub-questions whose answers
compose to the final answer, and then answers each sub-question in a fresh context that
contains only the answers it depends on. Separating the contexts prevents an early error from
being copied into later steps.
