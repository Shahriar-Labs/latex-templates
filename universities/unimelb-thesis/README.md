# UniMelb Thesis LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/universities/unimelb-thesis/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

An unofficial University of Melbourne PhD thesis template with the total-fulfilment title page, a 300 to 500 word abstract, the three-part declaration and a preface on contributions.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/universities/unimelb-thesis/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![UniMelb Thesis preview](preview.png)

## What is in it
- Document class: `report` with `12pt, oneside, a4paper`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, `references.bib`, and 9 section files under `front/`, `sections/`

## Use it online
Open **[UniMelb Thesis on LetX](https://letx.app/templates/universities/unimelb-thesis/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/universities/unimelb-thesis
latexmk -pdf main.tex
```
