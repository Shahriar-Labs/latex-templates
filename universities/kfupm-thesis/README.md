# KFUPM Thesis LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/universities/kfupm-thesis/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

An unofficial KFUPM thesis template on the two-sided report class in Palatino, with dedication, acknowledgment and abstract pages before the chapters and eleven tables.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/universities/kfupm-thesis/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![KFUPM Thesis preview](preview.png)

## What is in it
- Document class: `report` with `12pt, twoside`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, and 29 section files under `sections/`

## Use it online
Open **[KFUPM Thesis on LetX](https://letx.app/templates/universities/kfupm-thesis/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/universities/kfupm-thesis
latexmk -pdf main.tex
```
