# Brown University Thesis LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/universities/brown-thesis/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

An unofficial Brown University thesis template on the report class, one-sided, in Palatino with TeX Gyre Heros headings, with an abstract and an example framework chapter.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/universities/brown-thesis/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Brown University Thesis preview](preview.png)

## What is in it
- Document class: `report` with `12pt, oneside`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, and 6 section files under `sections/`

## Use it online
Open **[Brown University Thesis on LetX](https://letx.app/templates/universities/brown-thesis/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/universities/brown-thesis
latexmk -pdf main.tex
```
