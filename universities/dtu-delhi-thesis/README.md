# DTU Delhi Thesis LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/universities/dtu-delhi-thesis/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

An unofficial DTU Delhi thesis template on A4 with a certificate, a candidate's declaration, abstract, acknowledgements and a list of abbreviations before the chapters.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/universities/dtu-delhi-thesis/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![DTU Delhi Thesis preview](preview.png)

## What is in it
- Document class: `report` with `12pt, a4paper`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, and 31 section files under `sections/`

## Use it online
Open **[DTU Delhi Thesis on LetX](https://letx.app/templates/universities/dtu-delhi-thesis/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/universities/dtu-delhi-thesis
latexmk -pdf main.tex
```
