# Northwestern Thesis LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/universities/northwestern-thesis/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

An unofficial Northwestern thesis template on the one-sided report class, letter paper, with research questions, contributions and an example distributed consensus thesis.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/universities/northwestern-thesis/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Northwestern Thesis preview](preview.png)

## What is in it
- Document class: `report` with `12pt, letterpaper, oneside`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, and 11 section files under `sections/`

## Use it online
Open **[Northwestern Thesis on LetX](https://letx.app/templates/universities/northwestern-thesis/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/universities/northwestern-thesis
latexmk -pdf main.tex
```
