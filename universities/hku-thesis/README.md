# HKU Thesis LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/universities/hku-thesis/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

An unofficial University of Hong Kong thesis template on A4 with a declaration, an English abstract and a Chinese abstract, acknowledgements, and a literature review chapter.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/universities/hku-thesis/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![HKU Thesis preview](preview.png)

## What is in it
- Document class: `report` with `12pt, a4paper`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, and 27 section files under `sections/`

## Use it online
Open **[HKU Thesis on LetX](https://letx.app/templates/universities/hku-thesis/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/universities/hku-thesis
latexmk -pdf main.tex
```
