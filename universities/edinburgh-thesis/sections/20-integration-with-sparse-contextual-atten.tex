\section{Integration with Sparse Contextual Attention}

HMG is designed to complement SCA rather than replace it. In our joint architecture,
each transformer layer computes both SCA (for fine-grained local interactions) and
HMG memory reads (for long-horizon recall), combining their outputs via a learned
gating mechanism:

\begin{equation}
  H_{\text{out}} = \alpha \odot \operatorname{SCA}(Q,K,V)
    + (1-\alpha) \odot \operatorname{MemRead}(Q, \mathcal{M}),
  \label{eq:joint}
\end{equation}

where $\alpha = \sigma(W_{\alpha}\, H + b_{\alpha})$ and $\odot$ denotes element-wise
multiplication. This allows the model to dynamically balance local precision and global
context depending on the input.
