# Peking Thesis LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/universities/peking-thesis/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

An unofficial Peking University dissertation template on the pkuthss class from TeX Live, with the Chinese cover, copyright statement, Chinese and English abstracts, and GB/T 7714 references.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/universities/peking-thesis/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Peking Thesis preview](preview.png)

## What is in it
- Document class: `pkuthss` with `UTF8, ugly, fontset=fandol`
- Compiler: xelatex
- Files: `main.tex`, `preamble.tex`, `references.bib`, and 10 section files under `front/`, `sections/`

## Use it online
Open **[Peking Thesis on LetX](https://letx.app/templates/universities/peking-thesis/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/universities/peking-thesis
latexmk -xelatex main.tex
```
