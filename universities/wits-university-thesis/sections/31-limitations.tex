\section{Limitations}
\begin{itemize}
  \item Field validation is limited to a single test feeder at one site.
  \item Markov-gap simulation, while fitted to real outage logs, may not capture rarer
        correlated failure modes (e.g.\ region-wide load shedding).
  \item The Bayesian correction layer assumes residual stationarity within each weekly
        recalibration window.
\end{itemize}
