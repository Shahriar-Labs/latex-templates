# Johns Hopkins Thesis LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/universities/johns-hopkins-thesis/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

An unofficial Johns Hopkins thesis template on the report class with chapter epigraphs, natbib references, seven theorem environments and an example multi-robot coordination thesis.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/universities/johns-hopkins-thesis/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Johns Hopkins Thesis preview](preview.png)

## What is in it
- Document class: `report` with `12pt, oneside`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, and 28 section files under `sections/`

## Use it online
Open **[Johns Hopkins Thesis on LetX](https://letx.app/templates/universities/johns-hopkins-thesis/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/universities/johns-hopkins-thesis
latexmk -pdf main.tex
```
