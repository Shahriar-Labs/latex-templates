Graphs with billions of edges now describe social platforms, citation records and the web
itself, yet many classical graph algorithms assume the whole graph fits in the memory of one
machine. This dissertation develops algorithms for three core analysis tasks, ranking,
community detection and sparsification, that run in time nearly linear in the number of edges
and parallelize across machines. Chapter~2 reviews spectral and combinatorial approaches.
Chapter~3 presents a streaming variant of the Louvain method whose memory grows with the
number of vertices rather than edges. Chapter~4 evaluates the methods on graphs with up to 3.1
billion edges, where the streaming method matches the modularity of the in-memory method to
within 0.4\% while using a sixth of the memory.
