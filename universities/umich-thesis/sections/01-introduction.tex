\chapter{Introduction}
\label{ch:introduction}

Network analysis asks global questions about local data: which pages are most central, which
groups of accounts form communities, which edges can be removed without changing the graph's
large-scale structure. Classical answers to all three rely on repeated passes over the edge
list \citep{page1999, newman2006}. At the scale of modern graphs a single pass is expensive,
and holding the graph in memory may be impossible.

This dissertation argues that each of these tasks admits an algorithm whose cost is nearly
linear in the number of edges and whose memory is proportional to the number of vertices. We
make that argument concrete for ranking, community detection and spectral sparsification.
