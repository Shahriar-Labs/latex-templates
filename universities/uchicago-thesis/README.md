# UChicago Dissertation LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/universities/uchicago-thesis/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

An unofficial University of Chicago dissertation template on two-sided letter paper in newtx Times, with an example optimization dissertation built around a named gradient algorithm.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/universities/uchicago-thesis/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![UChicago Dissertation preview](preview.png)

## What is in it
- Document class: `report` with `12pt, letterpaper, twoside`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, and 15 section files under `sections/`

## Use it online
Open **[UChicago Dissertation on LetX](https://letx.app/templates/universities/uchicago-thesis/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/universities/uchicago-thesis
latexmk -pdf main.tex
```
