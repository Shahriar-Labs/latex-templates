\section{System Architecture}
\textsc{Meridian-Beam} operates as a two-stage control loop at each base
station. The coarse stage performs a reduced hierarchical codebook sweep to
narrow the candidate beam set; the refinement stage then applies a compact
policy network, trained via reinforcement learning, to select a fine-grained
beam offset based on recent received-signal-strength history and user
trajectory estimates. Figure~\ref{fig:architecture} illustrates the data flow
between the two stages and the scheduler.
