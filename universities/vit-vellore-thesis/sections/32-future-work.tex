\section{Future Work}
\begin{itemize}[leftmargin=1.4em]
  \item Deploy FedGuard on a live pilot fleet to validate simulation-derived results
        under real network jitter and gateway churn.
  \item Extend volatility scoring to cold-start clients using transfer from similar
        machine classes.
  \item Explore secure-aggregation protocols to remove trust in the regional
        aggregator entirely.
  \item Investigate personalised federated models that retain a per-client fine-tuning
        head atop the shared global backbone.
\end{itemize}
