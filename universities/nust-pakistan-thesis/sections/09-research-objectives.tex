\section{Research Objectives}
This thesis pursues the following objectives:
\begin{enumerate}[label=\textbf{O\arabic*.}, leftmargin=2.2em]
  \item Design a lightweight, locally computed volatility estimator suitable for
        microcontroller-class hardware.
  \item Develop a MAC-layer listen-before-sleep negotiation protocol that avoids full
        network-wide clock synchronization.
  \item Implement and evaluate the combined framework (AeroCycle) on both a physical testbed
        and a large-scale discrete-event simulation.
  \item Quantify the energy--latency trade-off achieved relative to static and
        state-of-the-art adaptive baselines.
\end{enumerate}
