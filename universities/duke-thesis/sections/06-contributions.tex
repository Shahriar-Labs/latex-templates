\section{Contributions}

This dissertation makes four principal contributions:

\begin{enumerate}[leftmargin=*,itemsep=4pt]
  \item \textbf{Changepoint-regularized HMM estimation.} We introduce a reversible-jump MCMC sampler that jointly infers the number of regimes $K$ and their parameters, penalizing superfluous states through a birth--death process on the transition matrix. This avoids the ad-hoc information-criterion selection common in the literature.

  \item \textbf{Regime-conditional CVaR optimization.} We formulate the portfolio problem as minimizing conditional value-at-risk under a mixture-of-Gaussians return model, transforming a non-convex objective into a second-order cone program solvable via ADMM. Convergence guarantees are established under $\alpha$-mixing conditions on the regime chain.

  \item \textbf{Empirical calibration and backtesting.} Using a synthetic data engine calibrated to post-2008 market structure and out-of-sample tests on a multi-asset panel spanning 1994--2024, we document consistent improvements in downside-risk metrics without sacrificing upside capture.

  \item \textbf{Open-source software.} The \texttt{regimePort} package for \texttt{R} provides a modular implementation interfacing with \texttt{Stan} for Bayesian computation and \texttt{CVXR} for convex optimization, lowering the barrier for practitioners.

\end{enumerate}
