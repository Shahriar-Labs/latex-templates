# Duke University Thesis LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/universities/duke-thesis/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

An unofficial Duke University thesis template on the book class, one-sided, with an abstract and dedication, an example finance thesis, and the bibliography listed in the contents.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/universities/duke-thesis/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Duke University Thesis preview](preview.png)

## What is in it
- Document class: `book` with `12pt, oneside`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, and 15 section files under `sections/`

## Use it online
Open **[Duke University Thesis on LetX](https://letx.app/templates/universities/duke-thesis/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/universities/duke-thesis
latexmk -pdf main.tex
```
