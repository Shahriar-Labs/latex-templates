# Cairo University Thesis LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/universities/cairo-university-thesis/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

An unofficial Cairo University thesis template on A4 with an English abstract and an Arabic abstract, a list of abbreviations, and chapters from problem statement to scope and limitations.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/universities/cairo-university-thesis/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Cairo University Thesis preview](preview.png)

## What is in it
- Document class: `report` with `12pt, a4paper, oneside`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, and 32 section files under `sections/`

## Use it online
Open **[Cairo University Thesis on LetX](https://letx.app/templates/universities/cairo-university-thesis/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/universities/cairo-university-thesis
latexmk -pdf main.tex
```
