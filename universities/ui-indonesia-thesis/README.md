# Universitas Indonesia Thesis LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/universities/ui-indonesia-thesis/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

An unofficial Universitas Indonesia thesis template written in Indonesian on A4, opening with Pendahuluan (Latar Belakang, Rumusan Masalah, Tujuan Penelitian) and Tinjauan Pustaka.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/universities/ui-indonesia-thesis/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Universitas Indonesia Thesis preview](preview.png)

## What is in it
- Document class: `report` with `12pt, a4paper`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, and 26 section files under `sections/`

## Use it online
Open **[Universitas Indonesia Thesis on LetX](https://letx.app/templates/universities/ui-indonesia-thesis/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/universities/ui-indonesia-thesis
latexmk -pdf main.tex
```
