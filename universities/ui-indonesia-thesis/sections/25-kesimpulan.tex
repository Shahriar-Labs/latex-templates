\section{Kesimpulan}
Berdasarkan hasil penelitian, dapat disimpulkan sebagai berikut.
\begin{enumerate}
  \item Model \emph{collaborative filtering} berbasis ALS dengan 64 faktor
    laten memberikan performa terbaik dengan RMSE 0,742, Precision@10
    0,381, dan NDCG@10 0,447 pada data interaksi implisit platform Nimbus.
  \item Model ALS secara konsisten mengungguli baseline \emph{user-based}
    maupun \emph{item-based} \emph{nearest neighbor} pada seluruh metrik
    evaluasi.
  \item Mekanisme peluruhan waktu terbukti meningkatkan relevansi
    rekomendasi khususnya bagi pengguna \emph{cold-start} dengan riwayat
    interaksi pendek.
\end{enumerate}
