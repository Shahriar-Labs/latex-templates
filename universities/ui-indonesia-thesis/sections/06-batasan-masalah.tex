\section{Batasan Masalah}
Penelitian ini dibatasi pada beberapa hal berikut.
\begin{itemize}
  \item Data yang digunakan adalah data interaksi tersamar (\emph{anonymized})
    periode Januari--Desember 2025.
  \item Model yang dibandingkan terbatas pada \emph{matrix factorization}
    (ALS) dan \emph{neighborhood-based collaborative filtering}; metode
    berbasis \emph{deep learning} berada di luar cakupan penelitian ini.
  \item Evaluasi dilakukan secara \emph{offline} menggunakan data historis,
    tanpa pengujian \emph{A/B} pada pengguna produksi.
\end{itemize}
