\section{Kerangka Pemikiran}
Gambar~\ref{fig:kerangka} menggambarkan kerangka pemikiran penelitian ini,
mulai dari data interaksi mentah hingga evaluasi model rekomendasi.

\begin{figure}[htb]
\centering
\begin{tikzpicture}[
  node distance=10mm and 14mm,
  box/.style={draw=uinavy, thick, rounded corners=2pt, fill=uibg,
    minimum width=30mm, minimum height=10mm, align=center, font=\small},
  arrow/.style={-{Latex[length=2.2mm]}, thick, color=uigray}
]
\node[box] (data) {Data Interaksi\\Implisit};
\node[box, right=of data] (prep) {Praproses\\\& Pembobotan};
\node[box, right=of prep] (model) {Model\\Collaborative Filtering};
\node[box, below=of model] (eval) {Evaluasi\\RMSE, Precision, NDCG};
\node[box, left=of eval] (rec) {Daftar\\Rekomendasi};

\draw[arrow] (data) -- (prep);
\draw[arrow] (prep) -- (model);
\draw[arrow] (model) -- (eval);
\draw[arrow] (model) -- (rec);
\draw[arrow] (rec) -- (eval);
\end{tikzpicture}
\caption{Kerangka pemikiran penelitian}
\label{fig:kerangka}
\end{figure}
