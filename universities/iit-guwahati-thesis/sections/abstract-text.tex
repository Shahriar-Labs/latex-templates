Wireless sensor networks deployed for environmental and structural monitoring run on batteries
that are hard to replace, so the network's useful life is set by how carefully it spends
energy on communication. This thesis designs routing and medium-access protocols that extend
network lifetime without sacrificing data delivery. It proposes a clustering protocol that
rotates cluster heads according to residual energy and link quality, and a duty-cycling scheme
that aligns sensor wake-up times with the cluster head's schedule. In simulation and on a
48-node testbed, the combined protocols extend the time until the first node dies by 37\%
compared with the LEACH protocol at a packet delivery ratio above 98\%.

\medskip\noindent\textbf{Keywords:} wireless sensor networks, clustering, duty cycling, network
lifetime, energy efficiency
