\section{Limitations}

Several limitations of this work suggest directions for future investigation. First, our
convergence analysis assumes i.i.d.\ sampling of minibatches, which excludes the shuffling and
curriculum strategies commonly used in practice. Extending the NPG framework to non-i.i.d.\
data streams — e.g., using the recent martingale-based analyses of shuffle-once SGD — would
narrow the remaining theory--practice gap.

Second, the NPG framework requires the preconditioner $P_t$ to be positive definite and
bounded away from zero, which excludes methods that employ aggressive gradient clipping or
sparsity-inducing preconditioners. Relaxing this requirement could bring methods like LAMB
\cite{you2020} and SignSGD \cite{bernstein2018} into the unified framework.
