# Yonsei University Thesis LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/universities/yonsei-thesis/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

An unofficial Yonsei University thesis template on A4 in Palatino, with an example thesis on edge and fog scheduling from problem statement to related work.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/universities/yonsei-thesis/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Yonsei University Thesis preview](preview.png)

## What is in it
- Document class: `report` with `12pt, a4paper`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, and 23 section files under `sections/`

## Use it online
Open **[Yonsei University Thesis on LetX](https://letx.app/templates/universities/yonsei-thesis/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/universities/yonsei-thesis
latexmk -pdf main.tex
```
