\chapter*{Lay Summary}
\addcontentsline{toc}{chapter}{Lay Summary}
Computing centres run thousands of programs at once and must decide which program gets which
machine, and when. The usual rules of thumb are written by hand and can make programs wait
longer than they need to. This thesis trains a computer program to learn better decisions from
practice runs, much as a person learns a game by playing it. The learned program finished work
about a fifth faster than the best hand-written rules in our tests, and it was built so that it
can never assign more work to a machine than the machine can hold.
