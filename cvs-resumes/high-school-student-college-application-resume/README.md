# High School Student College Application Resume LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/cvs-resumes/high-school-student-college-application-resume/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A college application resume for a high school student: Education, Honors & Awards, Leadership & Extracurricular Activities, Volunteer & Community Service, Work Experience and Skills.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/cvs-resumes/high-school-student-college-application-resume/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![High School Student College Application Resume preview](preview.png)

## What is in it
- Document class: `article` with `9.3pt, letterpaper`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[High School Student College Application Resume on LetX](https://letx.app/templates/cvs-resumes/high-school-student-college-application-resume/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/cvs-resumes/high-school-student-college-application-resume
latexmk -pdf main.tex
```
