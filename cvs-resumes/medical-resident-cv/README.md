# Medical Resident CV LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/cvs-resumes/medical-resident-cv/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A medical resident CV on letter paper with Licensure & Board Examinations, Core Clinical Rotations, Research & Publications, and Honors, Awards & Leadership.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/cvs-resumes/medical-resident-cv/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Medical Resident CV preview](preview.png)

## What is in it
- Document class: `article` with `10pt, letterpaper`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Medical Resident CV on LetX](https://letx.app/templates/cvs-resumes/medical-resident-cv/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/cvs-resumes/medical-resident-cv
latexmk -pdf main.tex
```
