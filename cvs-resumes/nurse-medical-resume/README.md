# Nurse / Medical Resume LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/cvs-resumes/nurse-medical-resume/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

Clean registered-nurse & healthcare resume LaTeX template, credentials header, Professional Summary, Licensure & Certifications, Clinical Experience, Clinical Skills and Education. One page, ATS-friendly.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/cvs-resumes/nurse-medical-resume/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Nurse / Medical Resume preview](preview.png)

## What is in it
- Document class: `article` with `10pt, letterpaper`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Nurse / Medical Resume on LetX](https://letx.app/templates/cvs-resumes/nurse-medical-resume/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/cvs-resumes/nurse-medical-resume
latexmk -pdf main.tex
```
