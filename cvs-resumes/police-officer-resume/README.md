# Police Officer Resume LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/cvs-resumes/police-officer-resume/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A police officer resume with Certifications & Licenses near the top and an Areas of Expertise section after the experience, closing with Education.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/cvs-resumes/police-officer-resume/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Police Officer Resume preview](preview.png)

## What is in it
- Document class: `article` with `10pt`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Police Officer Resume on LetX](https://letx.app/templates/cvs-resumes/police-officer-resume/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/cvs-resumes/police-officer-resume
latexmk -pdf main.tex
```
