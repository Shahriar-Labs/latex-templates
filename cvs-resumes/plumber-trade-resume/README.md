# Plumber Trade Resume LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/cvs-resumes/plumber-trade-resume/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A plumber's trade resume with Master and Journeyman licences, backflow tester, OSHA 30 and medical gas certifications, and skills grouped as Systems, Installation, Equipment and Expertise.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/cvs-resumes/plumber-trade-resume/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Plumber Trade Resume preview](preview.png)

## What is in it
- Document class: `article` with `10pt`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Plumber Trade Resume on LetX](https://letx.app/templates/cvs-resumes/plumber-trade-resume/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/cvs-resumes/plumber-trade-resume
latexmk -pdf main.tex
```
