# School Counselor Resume LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/cvs-resumes/school-counselor-resume/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A school counselor resume on letter paper with Certifications & Licenses and a Key Counseling Skills section before Professional Experience and Education.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/cvs-resumes/school-counselor-resume/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![School Counselor Resume preview](preview.png)

## What is in it
- Document class: `article` with `10pt, letterpaper`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[School Counselor Resume on LetX](https://letx.app/templates/cvs-resumes/school-counselor-resume/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/cvs-resumes/school-counselor-resume
latexmk -pdf main.tex
```
