## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/school-counselor-resume.git
cd school-counselor-resume
latexmk -pdf main.tex
```
Compiler: **pdflatex** (see `metadata.json`).
