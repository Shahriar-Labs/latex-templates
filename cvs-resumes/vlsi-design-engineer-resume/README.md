# VLSI Design Engineer Resume LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/cvs-resumes/vlsi-design-engineer-resume/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A VLSI design engineer resume in Source Sans Pro on letter paper, with Technical Skills, Professional Experience and a Selected Engineering Project section.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/cvs-resumes/vlsi-design-engineer-resume/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![VLSI Design Engineer Resume preview](preview.png)

## What is in it
- Document class: `article` with `10pt, letterpaper`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[VLSI Design Engineer Resume on LetX](https://letx.app/templates/cvs-resumes/vlsi-design-engineer-resume/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/cvs-resumes/vlsi-design-engineer-resume
latexmk -pdf main.tex
```
