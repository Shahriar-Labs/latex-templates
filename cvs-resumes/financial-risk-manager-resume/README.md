# Financial Risk Manager (FRM) Resume LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/cvs-resumes/financial-risk-manager-resume/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A financial risk manager resume in navy and gold, with the FRM credential in the header and a Certifications section that names the issuing body and year before the experience.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/cvs-resumes/financial-risk-manager-resume/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Financial Risk Manager (FRM) Resume preview](preview.png)

## What is in it
- Document class: `article` with `10pt`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Financial Risk Manager (FRM) Resume on LetX](https://letx.app/templates/cvs-resumes/financial-risk-manager-resume/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/cvs-resumes/financial-risk-manager-resume
latexmk -pdf main.tex
```
