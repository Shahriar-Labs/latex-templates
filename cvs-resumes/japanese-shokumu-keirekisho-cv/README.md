# Japanese Shokumu Keirekisho CV LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/cvs-resumes/japanese-shokumu-keirekisho-cv/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A Japanese shokumu keirekisho (職務経歴書) on A4 in five numbered parts: Career Summary, Work History, Applicable Experience and Skills, Qualifications & Licences, and Self PR.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/cvs-resumes/japanese-shokumu-keirekisho-cv/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Japanese Shokumu Keirekisho CV preview](preview.png)

## What is in it
- Document class: `article` with `10pt, a4paper`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Japanese Shokumu Keirekisho CV on LetX](https://letx.app/templates/cvs-resumes/japanese-shokumu-keirekisho-cv/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/cvs-resumes/japanese-shokumu-keirekisho-cv
latexmk -pdf main.tex
```
