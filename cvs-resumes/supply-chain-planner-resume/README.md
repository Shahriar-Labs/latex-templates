# Supply Chain Planner Resume LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/cvs-resumes/supply-chain-planner-resume/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A supply chain planner resume tracing a path from demand planning analyst to senior planner, with Core Competencies and a Planning Systems & Tools section.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/cvs-resumes/supply-chain-planner-resume/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Supply Chain Planner Resume preview](preview.png)

## What is in it
- Document class: `article` with `10pt`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Supply Chain Planner Resume on LetX](https://letx.app/templates/cvs-resumes/supply-chain-planner-resume/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/cvs-resumes/supply-chain-planner-resume
latexmk -pdf main.tex
```
