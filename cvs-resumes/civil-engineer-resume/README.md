# Civil Engineer Resume LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/cvs-resumes/civil-engineer-resume/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A civil engineer resume set in Lato with Professional Experience & Projects, Key Achievements, Certifications, Technical Skills and a Project Specs Grid table summarising major projects.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/cvs-resumes/civil-engineer-resume/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Civil Engineer Resume preview](preview.png)

## What is in it
- Document class: `article` with `10pt`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Civil Engineer Resume on LetX](https://letx.app/templates/cvs-resumes/civil-engineer-resume/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/cvs-resumes/civil-engineer-resume
latexmk -pdf main.tex
```
