# Undergraduate Research Assistant CV LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/cvs-resumes/undergraduate-research-assistant-cv/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

An undergraduate research assistant CV on letter paper: Education, Research Experience, Technical & Laboratory Skills, and Projects & Leadership.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/cvs-resumes/undergraduate-research-assistant-cv/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Undergraduate Research Assistant CV preview](preview.png)

## What is in it
- Document class: `article` with `10pt, letterpaper`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Undergraduate Research Assistant CV on LetX](https://letx.app/templates/cvs-resumes/undergraduate-research-assistant-cv/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/cvs-resumes/undergraduate-research-assistant-cv
latexmk -pdf main.tex
```
