# Student Resume with No Work Experience LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/cvs-resumes/student-resume-no-work-experience/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A student resume for someone with no work experience yet: Education first, then Academic & Independent Projects, Skills, Leadership & Volunteering, and Certifications & Honors.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/cvs-resumes/student-resume-no-work-experience/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Student Resume with No Work Experience preview](preview.png)

## What is in it
- Document class: `article` with `10pt, letterpaper`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Student Resume with No Work Experience on LetX](https://letx.app/templates/cvs-resumes/student-resume-no-work-experience/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/cvs-resumes/student-resume-no-work-experience
latexmk -pdf main.tex
```
