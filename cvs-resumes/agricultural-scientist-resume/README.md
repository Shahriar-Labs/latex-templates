# Agricultural Scientist Resume LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/cvs-resumes/agricultural-scientist-resume/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

An agricultural scientist's resume that reads like a research CV: Professional Profile, Core Expertise, Selected Research Impact, Selected Publications, and Grants, Recognition & Service, on letter paper.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/cvs-resumes/agricultural-scientist-resume/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Agricultural Scientist Resume preview](preview.png)

## What is in it
- Document class: `article` with `10pt, letterpaper`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Agricultural Scientist Resume on LetX](https://letx.app/templates/cvs-resumes/agricultural-scientist-resume/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/cvs-resumes/agricultural-scientist-resume
latexmk -pdf main.tex
```
