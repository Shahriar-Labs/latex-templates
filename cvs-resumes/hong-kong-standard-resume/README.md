# Hong Kong Standard Resume LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/cvs-resumes/hong-kong-standard-resume/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A Hong Kong-format resume on A4 with Selected Achievements, Education & Professional Development, Core Skills, and a Languages & Additional Information section.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/cvs-resumes/hong-kong-standard-resume/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Hong Kong Standard Resume preview](preview.png)

## What is in it
- Document class: `article` with `10pt, a4paper`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Hong Kong Standard Resume on LetX](https://letx.app/templates/cvs-resumes/hong-kong-standard-resume/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/cvs-resumes/hong-kong-standard-resume
latexmk -pdf main.tex
```
