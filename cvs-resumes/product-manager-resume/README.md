# Product Manager Resume LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/cvs-resumes/product-manager-resume/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A product manager resume on letter paper, set in TeX Gyre Heros, with Professional Summary, Core Competencies, Professional Experience, Education and Certifications.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/cvs-resumes/product-manager-resume/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Product Manager Resume preview](preview.png)

## What is in it
- Document class: `article` with `11pt, letterpaper`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Product Manager Resume on LetX](https://letx.app/templates/cvs-resumes/product-manager-resume/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/cvs-resumes/product-manager-resume
latexmk -pdf main.tex
```
