# Backend Developer Resume LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/cvs-resumes/backend-developer-resume/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A backend developer resume on A4 in two columns: a sidebar for certifications (AWS, CKAD, Kafka, Terraform), core technologies and languages beside a main column of experience.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/cvs-resumes/backend-developer-resume/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Backend Developer Resume preview](preview.png)

## What is in it
- Document class: `article` with `11pt, a4paper`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Backend Developer Resume on LetX](https://letx.app/templates/cvs-resumes/backend-developer-resume/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/cvs-resumes/backend-developer-resume
latexmk -pdf main.tex
```
