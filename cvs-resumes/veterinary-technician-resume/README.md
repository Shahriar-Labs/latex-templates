# Veterinary Technician Resume LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/cvs-resumes/veterinary-technician-resume/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A veterinary technician resume set in Lato on letter paper, with Licensure & Certifications, Clinical Experience and a Veterinary Skills section.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/cvs-resumes/veterinary-technician-resume/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Veterinary Technician Resume preview](preview.png)

## What is in it
- Document class: `article` with `10pt, letterpaper`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Veterinary Technician Resume on LetX](https://letx.app/templates/cvs-resumes/veterinary-technician-resume/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/cvs-resumes/veterinary-technician-resume
latexmk -pdf main.tex
```
