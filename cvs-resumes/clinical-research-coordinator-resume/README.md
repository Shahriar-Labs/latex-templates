# Clinical Research Coordinator Resume LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/cvs-resumes/clinical-research-coordinator-resume/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A clinical research coordinator resume on letter paper in five sections: Professional Summary, Experience, Education, Certifications and Skills.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/cvs-resumes/clinical-research-coordinator-resume/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Clinical Research Coordinator Resume preview](preview.png)

## What is in it
- Document class: `article` with `10pt, letterpaper`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Clinical Research Coordinator Resume on LetX](https://letx.app/templates/cvs-resumes/clinical-research-coordinator-resume/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/cvs-resumes/clinical-research-coordinator-resume
latexmk -pdf main.tex
```
