# Librarian Resume LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/cvs-resumes/librarian-resume/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A librarian resume on letter paper with Core Competencies, Education & Professional Development, and a Professional Affiliations section after the experience.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/cvs-resumes/librarian-resume/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Librarian Resume preview](preview.png)

## What is in it
- Document class: `article` with `10pt, letterpaper`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Librarian Resume on LetX](https://letx.app/templates/cvs-resumes/librarian-resume/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/cvs-resumes/librarian-resume
latexmk -pdf main.tex
```
