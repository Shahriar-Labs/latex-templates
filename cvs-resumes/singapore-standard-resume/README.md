# Singapore Standard Resume LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/cvs-resumes/singapore-standard-resume/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A Singapore-format resume on A4 in 9pt type (extarticle), with Core Competencies, Selected Achievements, Education & Credentials and Additional Information.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/cvs-resumes/singapore-standard-resume/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Singapore Standard Resume preview](preview.png)

## What is in it
- Document class: `extarticle` with `9pt, a4paper`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Singapore Standard Resume on LetX](https://letx.app/templates/cvs-resumes/singapore-standard-resume/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/cvs-resumes/singapore-standard-resume
latexmk -pdf main.tex
```
