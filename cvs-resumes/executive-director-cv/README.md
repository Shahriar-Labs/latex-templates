# Executive Director CV LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/cvs-resumes/executive-director-cv/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

Refined C-suite executive CV LaTeX template, Executive Summary, Core Competencies grid, Leadership Experience with P&L and growth metrics, and Board & Advisory roles. Understated navy palette.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/cvs-resumes/executive-director-cv/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Executive Director CV preview](preview.png)

## What is in it
- Document class: `article` with `10pt, letterpaper`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Executive Director CV on LetX](https://letx.app/templates/cvs-resumes/executive-director-cv/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/cvs-resumes/executive-director-cv
latexmk -pdf main.tex
```
