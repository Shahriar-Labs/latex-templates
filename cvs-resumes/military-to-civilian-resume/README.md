# Military to Civilian Resume LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/cvs-resumes/military-to-civilian-resume/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A military-to-civilian transition resume that leads with civilian credentials (PMP, Lean Six Sigma Green Belt, OSHA 30), groups skills as Operations & Logistics, Security & Compliance and Technical Systems.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/cvs-resumes/military-to-civilian-resume/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Military to Civilian Resume preview](preview.png)

## What is in it
- Document class: `article` with `10pt, letterpaper`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Military to Civilian Resume on LetX](https://letx.app/templates/cvs-resumes/military-to-civilian-resume/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/cvs-resumes/military-to-civilian-resume
latexmk -pdf main.tex
```
