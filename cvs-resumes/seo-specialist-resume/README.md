# SEO Specialist Resume LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/cvs-resumes/seo-specialist-resume/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

An SEO specialist resume on A4 with Core Skills, Professional Experience, a Selected Projects section, and Education & Certifications.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/cvs-resumes/seo-specialist-resume/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![SEO Specialist Resume preview](preview.png)

## What is in it
- Document class: `article` with `10pt, a4paper`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[SEO Specialist Resume on LetX](https://letx.app/templates/cvs-resumes/seo-specialist-resume/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/cvs-resumes/seo-specialist-resume
latexmk -pdf main.tex
```
