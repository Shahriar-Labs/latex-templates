# CNC Machinist Resume LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/cvs-resumes/cnc-machinist-resume/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A CNC machinist resume on letter paper that puts Certifications & Licenses and Technical Skills ahead of experience, closing with Education & Vocational Training.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/cvs-resumes/cnc-machinist-resume/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![CNC Machinist Resume preview](preview.png)

## What is in it
- Document class: `article` with `10pt, letterpaper`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[CNC Machinist Resume on LetX](https://letx.app/templates/cvs-resumes/cnc-machinist-resume/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/cvs-resumes/cnc-machinist-resume
latexmk -pdf main.tex
```
