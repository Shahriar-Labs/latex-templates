# Medical Doctor CV LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/cvs-resumes/medical-doctor-cv/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A medical doctor's CV on A4 with Board Certifications, Clinical Experience, Academic Appointments, Selected Publications, Invited Lectures, Memberships & Honors and Licensure.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/cvs-resumes/medical-doctor-cv/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Medical Doctor CV preview](preview.png)

## What is in it
- Document class: `article` with `11pt, a4paper`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Medical Doctor CV on LetX](https://letx.app/templates/cvs-resumes/medical-doctor-cv/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/cvs-resumes/medical-doctor-cv
latexmk -pdf main.tex
```
