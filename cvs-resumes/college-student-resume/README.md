# College Student Resume LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/cvs-resumes/college-student-resume/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

Entry-level college student resume LaTeX template, education-first ordering with GPA, coursework and honors, plus Projects, Internships, Skills and Activities. One page, internship-ready.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/cvs-resumes/college-student-resume/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![College Student Resume preview](preview.png)

## What is in it
- Document class: `article` with `10pt, letterpaper`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[College Student Resume on LetX](https://letx.app/templates/cvs-resumes/college-student-resume/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/cvs-resumes/college-student-resume
latexmk -pdf main.tex
```
