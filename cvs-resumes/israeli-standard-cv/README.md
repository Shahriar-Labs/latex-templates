# Israeli Standard CV LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/cvs-resumes/israeli-standard-cv/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

An Israeli-format CV on A4 with a Military Service section between Professional Experience and Education, and a closing Technical Skills section.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/cvs-resumes/israeli-standard-cv/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Israeli Standard CV preview](preview.png)

## What is in it
- Document class: `article` with `10pt, a4paper`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Israeli Standard CV on LetX](https://letx.app/templates/cvs-resumes/israeli-standard-cv/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/cvs-resumes/israeli-standard-cv
latexmk -pdf main.tex
```
