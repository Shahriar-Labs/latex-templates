# Europass CV Template LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/cvs-resumes/europass-cv/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A Europass-style CV on A4 in two columns (paracol), set in Lato, with Professional Summary, Professional Experience and Education laid out as dated entries.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/cvs-resumes/europass-cv/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Europass CV Template preview](preview.png)

## What is in it
- Document class: `article` with `10pt, a4paper`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Europass CV Template on LetX](https://letx.app/templates/cvs-resumes/europass-cv/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/cvs-resumes/europass-cv
latexmk -pdf main.tex
```
