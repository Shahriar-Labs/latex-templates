# HVAC Technician Resume LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/cvs-resumes/hvac-technician-resume/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

An HVAC technician resume that lists EPA Section 608 Universal, NATE and OSHA credentials first, with skills grouped as Systems, Diagnostics, Refrigeration and Controls & Service.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/cvs-resumes/hvac-technician-resume/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![HVAC Technician Resume preview](preview.png)

## What is in it
- Document class: `article` with `10pt, letterpaper`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[HVAC Technician Resume on LetX](https://letx.app/templates/cvs-resumes/hvac-technician-resume/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/cvs-resumes/hvac-technician-resume
latexmk -pdf main.tex
```
