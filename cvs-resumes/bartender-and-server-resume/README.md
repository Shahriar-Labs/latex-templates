# Bartender and Server Resume LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/cvs-resumes/bartender-and-server-resume/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A bartender and server resume with a certifications strip for ServSafe Manager, TIPS, LEAD and First Aid & CPR, followed by service experience written as bullet points.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/cvs-resumes/bartender-and-server-resume/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Bartender and Server Resume preview](preview.png)

## What is in it
- Document class: `article` with `10pt`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Bartender and Server Resume on LetX](https://letx.app/templates/cvs-resumes/bartender-and-server-resume/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/cvs-resumes/bartender-and-server-resume
latexmk -pdf main.tex
```
