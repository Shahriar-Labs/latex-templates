# German Lebenslauf CV LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/cvs-resumes/german-lebenslauf/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A German Lebenslauf on A4 in two columns, with a sidebar for Fähigkeiten, Sprachen, IT-Kenntnisse (ERP, Office, CAD, BI), Zertifikate and Interessen beside the career history.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/cvs-resumes/german-lebenslauf/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![German Lebenslauf CV preview](preview.png)

## What is in it
- Document class: `article` with `11pt, a4paper`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[German Lebenslauf CV on LetX](https://letx.app/templates/cvs-resumes/german-lebenslauf/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/cvs-resumes/german-lebenslauf
latexmk -pdf main.tex
```
