# Executive MBA CV LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/cvs-resumes/executive-mba-cv/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

An Executive MBA CV that leads with Education and Certifications, then Core Competencies, a Board & Advisory section and an Executive Summary before Professional Experience.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/cvs-resumes/executive-mba-cv/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Executive MBA CV preview](preview.png)

## What is in it
- Document class: `article` with `10pt`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Executive MBA CV on LetX](https://letx.app/templates/cvs-resumes/executive-mba-cv/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/cvs-resumes/executive-mba-cv
latexmk -pdf main.tex
```
