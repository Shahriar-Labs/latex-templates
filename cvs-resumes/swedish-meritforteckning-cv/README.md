# Swedish Meritforteckning CV LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/cvs-resumes/swedish-meritforteckning-cv/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A Swedish CV (meritförteckning) written in Swedish on A4, with a Kontakt block and a Kompetenser section rated on a five-point scale, in a dark-banner layout.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/cvs-resumes/swedish-meritforteckning-cv/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Swedish Meritforteckning CV preview](preview.png)

## What is in it
- Document class: `article` with `10pt, a4paper`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Swedish Meritforteckning CV on LetX](https://letx.app/templates/cvs-resumes/swedish-meritforteckning-cv/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/cvs-resumes/swedish-meritforteckning-cv
latexmk -pdf main.tex
```
