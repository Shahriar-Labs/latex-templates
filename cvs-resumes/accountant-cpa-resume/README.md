# Accountant & CPA Resume LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/cvs-resumes/accountant-cpa-resume/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

An accountant and CPA resume on letter paper with an icon-led header: Professional Summary, Core Competencies, Experience, Certifications & Licenses, Technical Skills and a Key Achievements section.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/cvs-resumes/accountant-cpa-resume/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Accountant & CPA Resume preview](preview.png)

## What is in it
- Document class: `article` with `11pt, letterpaper`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Accountant & CPA Resume on LetX](https://letx.app/templates/cvs-resumes/accountant-cpa-resume/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/cvs-resumes/accountant-cpa-resume
latexmk -pdf main.tex
```
