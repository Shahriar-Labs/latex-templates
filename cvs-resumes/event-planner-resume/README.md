# Event Planner Resume LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/cvs-resumes/event-planner-resume/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

An event planner resume with a boxed Areas of Expertise section, a two-column skills list, Professional Summary, Professional Experience, and Education & Credentials.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/cvs-resumes/event-planner-resume/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Event Planner Resume preview](preview.png)

## What is in it
- Document class: `article`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Event Planner Resume on LetX](https://letx.app/templates/cvs-resumes/event-planner-resume/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/cvs-resumes/event-planner-resume
latexmk -pdf main.tex
```
