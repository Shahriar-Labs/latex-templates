## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/video-editor-motion-designer-resume.git
cd video-editor-motion-designer-resume
latexmk -pdf main.tex
```
Compiler: **pdflatex** (see `metadata.json`).
