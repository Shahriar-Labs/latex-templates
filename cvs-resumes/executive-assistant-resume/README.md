# Executive Assistant Resume LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/cvs-resumes/executive-assistant-resume/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

An executive assistant resume that puts Certifications & Licences and Core Skills ahead of Professional Experience, with a Professional Summary opening and Education closing.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/cvs-resumes/executive-assistant-resume/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Executive Assistant Resume preview](preview.png)

## What is in it
- Document class: `article` with `10pt`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Executive Assistant Resume on LetX](https://letx.app/templates/cvs-resumes/executive-assistant-resume/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/cvs-resumes/executive-assistant-resume
latexmk -pdf main.tex
```
