# Creative Director CV LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/cvs-resumes/creative-director-cv/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A creative director's CV that leads with awards (Cannes Gold Lion, D&AD Wood Pencil, Clio Gold, Red Dot) and a Signature Campaigns section beside Professional Experience.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/cvs-resumes/creative-director-cv/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Creative Director CV preview](preview.png)

## What is in it
- Document class: `article` with `10pt`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Creative Director CV on LetX](https://letx.app/templates/cvs-resumes/creative-director-cv/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/cvs-resumes/creative-director-cv
latexmk -pdf main.tex
```
