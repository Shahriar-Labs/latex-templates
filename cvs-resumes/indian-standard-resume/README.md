# Indian Standard Resume LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/cvs-resumes/indian-standard-resume/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

An Indian-format resume on A4 for graduates, with Career Objective, Education, Internships, Projects, Technical Skills, Achievements & Leadership and Personal Details.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/cvs-resumes/indian-standard-resume/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Indian Standard Resume preview](preview.png)

## What is in it
- Document class: `article` with `a4paper, 10pt`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Indian Standard Resume on LetX](https://letx.app/templates/cvs-resumes/indian-standard-resume/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/cvs-resumes/indian-standard-resume
latexmk -pdf main.tex
```
