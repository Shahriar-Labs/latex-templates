# UI/UX Researcher Resume LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/cvs-resumes/ui-ux-researcher-resume/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A UI/UX researcher resume that writes results as measured changes (time-to-task, retention, usability scores), with a named navigation case study and NN/g UX certification.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/cvs-resumes/ui-ux-researcher-resume/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![UI/UX Researcher Resume preview](preview.png)

## What is in it
- Document class: `article` with `10pt`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[UI/UX Researcher Resume on LetX](https://letx.app/templates/cvs-resumes/ui-ux-researcher-resume/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/cvs-resumes/ui-ux-researcher-resume
latexmk -pdf main.tex
```
