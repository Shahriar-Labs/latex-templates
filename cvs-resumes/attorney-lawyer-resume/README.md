# Attorney & Legal Resume LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/cvs-resumes/attorney-lawyer-resume/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

An attorney's resume on A4 with Bar Admissions & Credentials near the top, followed by Professional Experience, Representative Matters, Publications & Speaking Engagements and Professional Affiliations.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/cvs-resumes/attorney-lawyer-resume/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Attorney & Legal Resume preview](preview.png)

## What is in it
- Document class: `article` with `11pt, a4paper`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Attorney & Legal Resume on LetX](https://letx.app/templates/cvs-resumes/attorney-lawyer-resume/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/cvs-resumes/attorney-lawyer-resume
latexmk -pdf main.tex
```
