# Business Analyst Resume LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/cvs-resumes/business-analyst-resume/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A business analyst resume with skills grouped into Process Modeling, Data & SQL, Visualization and Methodologies boxes, followed by experience bullets and education.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/cvs-resumes/business-analyst-resume/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Business Analyst Resume preview](preview.png)

## What is in it
- Document class: `article` with `10pt`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Business Analyst Resume on LetX](https://letx.app/templates/cvs-resumes/business-analyst-resume/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/cvs-resumes/business-analyst-resume
latexmk -pdf main.tex
```
