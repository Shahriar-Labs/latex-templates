# Marketing Specialist Resume LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/cvs-resumes/marketing-specialist-resume/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A marketing specialist resume set in Lato on letter paper, with experience first and Core Competencies and Certifications after Education, under a TikZ-accented header.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/cvs-resumes/marketing-specialist-resume/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Marketing Specialist Resume preview](preview.png)

## What is in it
- Document class: `article` with `11pt, letterpaper`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Marketing Specialist Resume on LetX](https://letx.app/templates/cvs-resumes/marketing-specialist-resume/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/cvs-resumes/marketing-specialist-resume
latexmk -pdf main.tex
```
