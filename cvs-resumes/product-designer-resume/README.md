# Product Designer Resume LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/cvs-resumes/product-designer-resume/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A product designer resume with a Selected Case Studies section after Experience, then Skills & Tools and Education, in a boxed layout with TikZ accents.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/cvs-resumes/product-designer-resume/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Product Designer Resume preview](preview.png)

## What is in it
- Document class: `article` with `10pt`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Product Designer Resume on LetX](https://letx.app/templates/cvs-resumes/product-designer-resume/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/cvs-resumes/product-designer-resume
latexmk -pdf main.tex
```
