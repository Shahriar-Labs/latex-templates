# PhD Candidate CV LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/cvs-resumes/phd-candidate-cv/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A PhD candidate's academic CV on letter paper with Research Interests, Publications, Research Experience, Awards and Fellowships, Teaching, Invited Talks and Academic Service.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/cvs-resumes/phd-candidate-cv/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![PhD Candidate CV preview](preview.png)

## What is in it
- Document class: `article` with `10pt, letterpaper`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[PhD Candidate CV on LetX](https://letx.app/templates/cvs-resumes/phd-candidate-cv/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/cvs-resumes/phd-candidate-cv
latexmk -pdf main.tex
```
