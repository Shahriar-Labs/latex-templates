# Welder Trade Resume LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/cvs-resumes/welder-trade-resume/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A welder's trade resume that opens with Technical Skills, then Professional Experience and Education & Training, in a boxed, icon-led layout.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/cvs-resumes/welder-trade-resume/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Welder Trade Resume preview](preview.png)

## What is in it
- Document class: `article` with `10pt`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Welder Trade Resume on LetX](https://letx.app/templates/cvs-resumes/welder-trade-resume/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/cvs-resumes/welder-trade-resume
latexmk -pdf main.tex
```
