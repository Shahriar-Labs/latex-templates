# Brazilian Curriculo Resume LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/cvs-resumes/brazilian-curriculo-resume/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A Brazilian currículo in Portuguese on A4, with each role written as measured results (deploy time cut by 62%, 2 million active users) and a multi-column skills area.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/cvs-resumes/brazilian-curriculo-resume/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Brazilian Curriculo Resume preview](preview.png)

## What is in it
- Document class: `article` with `11pt, a4paper`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Brazilian Curriculo Resume on LetX](https://letx.app/templates/cvs-resumes/brazilian-curriculo-resume/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/cvs-resumes/brazilian-curriculo-resume
latexmk -pdf main.tex
```
