# Retail Manager Resume LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/cvs-resumes/retail-manager-resume/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A retail manager resume on letter paper with Certifications & Licenses and Key Areas of Expertise before Professional Experience.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/cvs-resumes/retail-manager-resume/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Retail Manager Resume preview](preview.png)

## What is in it
- Document class: `article` with `10pt, letterpaper`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Retail Manager Resume on LetX](https://letx.app/templates/cvs-resumes/retail-manager-resume/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/cvs-resumes/retail-manager-resume
latexmk -pdf main.tex
```
