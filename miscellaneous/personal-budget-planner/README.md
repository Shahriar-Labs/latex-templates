# Personal Budget Planner LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/miscellaneous/personal-budget-planner/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

Monthly personal budget planner LaTeX template, a summary box, a savings-goal tracker, and category tables (income, housing, transport, food, utilities, savings) with budgeted/actual/difference columns.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/miscellaneous/personal-budget-planner/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Personal Budget Planner preview](preview.png)

## What is in it
- Document class: `article` with `11pt`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Personal Budget Planner on LetX](https://letx.app/templates/miscellaneous/personal-budget-planner/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/miscellaneous/personal-budget-planner
latexmk -pdf main.tex
```
