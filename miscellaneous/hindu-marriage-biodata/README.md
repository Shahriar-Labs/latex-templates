# Hindu Marriage Biodata LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/miscellaneous/hindu-marriage-biodata/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

Elegant Hindu marriage biodata LaTeX template, warm maroon & gold border with a lotus motif, photo placeholder, and Personal, Astro (Rashi, Nakshatra, Gotra, Gan, Manglik), Family & Contact sections. One page.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/miscellaneous/hindu-marriage-biodata/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Hindu Marriage Biodata preview](preview.png)

## What is in it
- Document class: `article` with `10pt, a4paper`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Hindu Marriage Biodata on LetX](https://letx.app/templates/miscellaneous/hindu-marriage-biodata/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/miscellaneous/hindu-marriage-biodata
latexmk -pdf main.tex
```
