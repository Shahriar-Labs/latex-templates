# Printable Event Ticket LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/miscellaneous/printable-ticket/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A printable event ticket sheet in Lato for a gala concert, with three ticket tiers and printing instructions for heavy cardstock.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/miscellaneous/printable-ticket/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Printable Event Ticket preview](preview.png)

## What is in it
- Document class: `article` with `10pt, letterpaper`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Printable Event Ticket on LetX](https://letx.app/templates/miscellaneous/printable-ticket/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/miscellaneous/printable-ticket
latexmk -pdf main.tex
```
