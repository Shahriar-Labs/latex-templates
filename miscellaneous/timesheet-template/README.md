# Timesheet LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/miscellaneous/timesheet-template/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A weekly timesheet in Lato with the employee details, a time record, hours by project, an hours summary, a project code legend, notes, and an approval block.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/miscellaneous/timesheet-template/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Timesheet preview](preview.png)

## What is in it
- Document class: `article` with `11pt`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Timesheet on LetX](https://letx.app/templates/miscellaneous/timesheet-template/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/miscellaneous/timesheet-template
latexmk -pdf main.tex
```
