# Non-Disclosure Agreement LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/miscellaneous/nda-template/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

Mutual non-disclosure agreement (NDA) LaTeX template, party preamble, numbered legal clauses (confidential information, obligations, term, remedies, governing law) and a two-party signature block.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/miscellaneous/nda-template/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Non-Disclosure Agreement preview](preview.png)

## What is in it
- Document class: `article` with `11pt, a4paper`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, and 8 section files under `sections/`

## Use it online
Open **[Non-Disclosure Agreement on LetX](https://letx.app/templates/miscellaneous/nda-template/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/miscellaneous/nda-template
latexmk -pdf main.tex
```
