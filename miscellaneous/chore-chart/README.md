# Kids Chore Chart LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/miscellaneous/chore-chart/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A kids' chore chart on letter paper in Lato with a weekly grid of tasks and a star reward ladder at 15, 30 and 45 stars.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/miscellaneous/chore-chart/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Kids Chore Chart preview](preview.png)

## What is in it
- Document class: `article` with `10pt, letterpaper`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Kids Chore Chart on LetX](https://letx.app/templates/miscellaneous/chore-chart/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/miscellaneous/chore-chart
latexmk -pdf main.tex
```
