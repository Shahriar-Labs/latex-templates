# Internship Certificate LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/miscellaneous/internship-certificate/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

An internship certificate in Lato with a bordered layout, the company name and line of business, a certificate ID and a verification link.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/miscellaneous/internship-certificate/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Internship Certificate preview](preview.png)

## What is in it
- Document class: `article` with `10pt`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Internship Certificate on LetX](https://letx.app/templates/miscellaneous/internship-certificate/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/miscellaneous/internship-certificate
latexmk -pdf main.tex
```
