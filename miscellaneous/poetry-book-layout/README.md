# Poetry Book Layout LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/miscellaneous/poetry-book-layout/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A poetry book layout on A4 in TeX Gyre Pagella with a title page for a selection of poems, an epigraph with attribution, and a press imprint.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/miscellaneous/poetry-book-layout/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Poetry Book Layout preview](preview.png)

## What is in it
- Document class: `article` with `12pt, a4paper`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Poetry Book Layout on LetX](https://letx.app/templates/miscellaneous/poetry-book-layout/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/miscellaneous/poetry-book-layout
latexmk -pdf main.tex
```
