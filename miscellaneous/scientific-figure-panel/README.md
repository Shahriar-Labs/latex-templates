# Scientific Figure Panel LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/miscellaneous/scientific-figure-panel/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

Publication-quality multi-panel scientific figure LaTeX template, a 2x2 grid of labelled (A-D) pgfplots panels (line+error bands, grouped bars with significance, scatter+fit, heatmap) with a shared multi-part caption.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/miscellaneous/scientific-figure-panel/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Scientific Figure Panel preview](preview.png)

## What is in it
- Document class: `article` with `10pt`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Scientific Figure Panel on LetX](https://letx.app/templates/miscellaneous/scientific-figure-panel/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/miscellaneous/scientific-figure-panel
latexmk -pdf main.tex
```
