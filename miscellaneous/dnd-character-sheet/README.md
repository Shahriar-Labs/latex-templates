# D&D Character Sheet LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/miscellaneous/dnd-character-sheet/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A Dungeons & Dragons character sheet in Lato with ability scores, weapon and attack tables, spellcasting ability, save DC and attack bonus, and an inventory by quantity and weight.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/miscellaneous/dnd-character-sheet/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![D&D Character Sheet preview](preview.png)

## What is in it
- Document class: `article` with `10pt`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[D&D Character Sheet on LetX](https://letx.app/templates/miscellaneous/dnd-character-sheet/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/miscellaneous/dnd-character-sheet
latexmk -pdf main.tex
```
