# Appreciation Certificate LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/miscellaneous/appreciation-certificate/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A landscape certificate of appreciation on A4 with a calligraphic name line in TeX Gyre Pagella and a citation naming the contribution being recognised.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/miscellaneous/appreciation-certificate/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Appreciation Certificate preview](preview.png)

## What is in it
- Document class: `article` with `11pt, a4paper, landscape`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Appreciation Certificate on LetX](https://letx.app/templates/miscellaneous/appreciation-certificate/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/miscellaneous/appreciation-certificate
latexmk -pdf main.tex
```
