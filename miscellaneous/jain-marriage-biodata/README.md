# Jain Marriage Biodata LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/miscellaneous/jain-marriage-biodata/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A Jain marriage biodata on letter paper in Palatino with about me, education, a dated professional journey, and a section for sect and lifestyle.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/miscellaneous/jain-marriage-biodata/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Jain Marriage Biodata preview](preview.png)

## What is in it
- Document class: `article` with `10pt, letterpaper`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Jain Marriage Biodata on LetX](https://letx.app/templates/miscellaneous/jain-marriage-biodata/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/miscellaneous/jain-marriage-biodata
latexmk -pdf main.tex
```
