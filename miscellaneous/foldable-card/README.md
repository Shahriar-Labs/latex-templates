# Tri-Fold Brochure LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/miscellaneous/foldable-card/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

Tri-fold brochure / foldable card LaTeX template, a landscape page of three panels (content panels + a colored front cover) with fold guides. Great for studios, events and small businesses.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/miscellaneous/foldable-card/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Tri-Fold Brochure preview](preview.png)

## What is in it
- Document class: `article` with `a4paper`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Tri-Fold Brochure on LetX](https://letx.app/templates/miscellaneous/foldable-card/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/miscellaneous/foldable-card
latexmk -pdf main.tex
```
