# Telugu Marriage Biodata LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/miscellaneous/telugu-marriage-biodata/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A Telugu marriage biodata on A4 in Palatino opening with Sri Ganeshaya Namaha, with personal details and a rashi table giving each sign with its Telugu name.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/miscellaneous/telugu-marriage-biodata/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Telugu Marriage Biodata preview](preview.png)

## What is in it
- Document class: `article` with `11pt, a4paper`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Telugu Marriage Biodata on LetX](https://letx.app/templates/miscellaneous/telugu-marriage-biodata/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/miscellaneous/telugu-marriage-biodata
latexmk -pdf main.tex
```
