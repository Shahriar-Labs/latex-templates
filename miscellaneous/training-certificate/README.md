# Training Certificate LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/miscellaneous/training-certificate/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A training certificate of completion on A4 in Lato for a twelve-week professional programme, with the institute's name, the recipient and a description of the course.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/miscellaneous/training-certificate/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Training Certificate preview](preview.png)

## What is in it
- Document class: `article` with `11pt, a4paper`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Training Certificate on LetX](https://letx.app/templates/miscellaneous/training-certificate/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/miscellaneous/training-certificate
latexmk -pdf main.tex
```
