# Business Card Sheet LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/miscellaneous/business-card/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

Print-ready 10-up business card sheet LaTeX template, a 2x5 grid of standard 3.5x2in cards with monogram, contact icons, an accent stripe and dashed cut guides. Fully editable in TikZ.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/miscellaneous/business-card/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Business Card Sheet preview](preview.png)

## What is in it
- Document class: `article` with `12pt`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Business Card Sheet on LetX](https://letx.app/templates/miscellaneous/business-card/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/miscellaneous/business-card
latexmk -pdf main.tex
```
