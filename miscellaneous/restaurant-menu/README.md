# Restaurant Menu LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/miscellaneous/restaurant-menu/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

Elegant fine-dining restaurant menu LaTeX template, decorative header, sections (starters, mains, desserts, beverages) with dish names, dotted price leaders and italic descriptions. Classic serif typography.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/miscellaneous/restaurant-menu/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Restaurant Menu preview](preview.png)

## What is in it
- Document class: `article` with `11pt`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Restaurant Menu on LetX](https://letx.app/templates/miscellaneous/restaurant-menu/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/miscellaneous/restaurant-menu
latexmk -pdf main.tex
```
