# Guitar Chord Chart LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/miscellaneous/chord-diagram/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A guitar chord chart in Lato with a legend for strings, fingers and symbols, major, minor and seventh chord diagrams, and practice notes on muting and barre chords.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/miscellaneous/chord-diagram/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Guitar Chord Chart preview](preview.png)

## What is in it
- Document class: `article` with `11pt`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Guitar Chord Chart on LetX](https://letx.app/templates/miscellaneous/chord-diagram/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/miscellaneous/chord-diagram
latexmk -pdf main.tex
```
