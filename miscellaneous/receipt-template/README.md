# Receipt LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/miscellaneous/receipt-template/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A payment receipt in Lato with an itemised table by description, quantity, unit and amount, and a TikZ-drawn header.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/miscellaneous/receipt-template/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Receipt preview](preview.png)

## What is in it
- Document class: `article` with `11pt`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Receipt on LetX](https://letx.app/templates/miscellaneous/receipt-template/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/miscellaneous/receipt-template
latexmk -pdf main.tex
```
