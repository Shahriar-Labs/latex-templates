# Wedding Program LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/miscellaneous/wedding-program/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

Wedding ceremony program LaTeX template, decorative header with couple names, an Order of Ceremony list with dotted leaders, a Wedding Party section, and a thank-you note. Elegant serif.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/miscellaneous/wedding-program/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Wedding Program preview](preview.png)

## What is in it
- Document class: `article` with `11pt`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Wedding Program on LetX](https://letx.app/templates/miscellaneous/wedding-program/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/miscellaneous/wedding-program
latexmk -pdf main.tex
```
