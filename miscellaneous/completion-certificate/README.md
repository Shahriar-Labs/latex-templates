# Course Completion Certificate LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/miscellaneous/completion-certificate/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A landscape course completion certificate in TeX Gyre Pagella with a double border, a seal of excellence drawn in TikZ, the recipient's name and the course completed.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/miscellaneous/completion-certificate/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Course Completion Certificate preview](preview.png)

## What is in it
- Document class: `article` with `landscape, 12pt`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Course Completion Certificate on LetX](https://letx.app/templates/miscellaneous/completion-certificate/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/miscellaneous/completion-certificate
latexmk -pdf main.tex
```
