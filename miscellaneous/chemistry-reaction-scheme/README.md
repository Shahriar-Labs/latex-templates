# Chemistry Reaction Scheme LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/miscellaneous/chemistry-reaction-scheme/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

Organic chemistry reaction scheme LaTeX template using chemfig, a single-step reaction with a reagent arrow, a multi-step synthesis, and a reaction mechanism with curved electron-pushing arrows. Fully editable.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/miscellaneous/chemistry-reaction-scheme/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Chemistry Reaction Scheme preview](preview.png)

## What is in it
- Document class: `article` with `11pt, a4paper`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, and 3 section files under `sections/`

## Use it online
Open **[Chemistry Reaction Scheme on LetX](https://letx.app/templates/miscellaneous/chemistry-reaction-scheme/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/miscellaneous/chemistry-reaction-scheme
latexmk -pdf main.tex
```
