# Travel Itinerary LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/miscellaneous/travel-itinerary/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

Modern day-by-day travel itinerary LaTeX template, colored header band, flight/hotel/budget summary with icons, and per-day activity cards with times, locations and notes. Includes a realistic 3-day sample trip.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/miscellaneous/travel-itinerary/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Travel Itinerary preview](preview.png)

## What is in it
- Document class: `article` with `11pt, a4paper`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Travel Itinerary on LetX](https://letx.app/templates/miscellaneous/travel-itinerary/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/miscellaneous/travel-itinerary
latexmk -pdf main.tex
```
