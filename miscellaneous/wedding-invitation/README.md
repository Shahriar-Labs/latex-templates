# Wedding Invitation LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/miscellaneous/wedding-invitation/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

Elegant wedding invitation LaTeX template, delicate double border with corner ornaments, calligraphic couple names, the invitation wording, date, venue and RSVP line. Soft, romantic palette.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/miscellaneous/wedding-invitation/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Wedding Invitation preview](preview.png)

## What is in it
- Document class: `article` with `12pt`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Wedding Invitation on LetX](https://letx.app/templates/miscellaneous/wedding-invitation/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/miscellaneous/wedding-invitation
latexmk -pdf main.tex
```
