# South Indian Marriage Biodata LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/miscellaneous/south-indian-marriage-biodata/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

South Indian marriage biodata LaTeX template, temple-gold & maroon styling with a horoscope/Jathagam section (Rasi, Nakshatra, Lagnam, Gothram, Dosham) and a traditional Rasi chart. One page.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/miscellaneous/south-indian-marriage-biodata/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![South Indian Marriage Biodata preview](preview.png)

## What is in it
- Document class: `article` with `10pt, oneside`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[South Indian Marriage Biodata on LetX](https://letx.app/templates/miscellaneous/south-indian-marriage-biodata/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/miscellaneous/south-indian-marriage-biodata
latexmk -pdf main.tex
```
