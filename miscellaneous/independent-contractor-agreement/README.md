# Independent Contractor Agreement LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/miscellaneous/independent-contractor-agreement/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

An independent contractor agreement set in Lato, covering the parties, services, term and notice, fees and payment days, expenses and taxes.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/miscellaneous/independent-contractor-agreement/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Independent Contractor Agreement preview](preview.png)

## What is in it
- Document class: `article` with `10pt`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Independent Contractor Agreement on LetX](https://letx.app/templates/miscellaneous/independent-contractor-agreement/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/miscellaneous/independent-contractor-agreement
latexmk -pdf main.tex
```
