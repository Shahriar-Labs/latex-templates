# Royal Rajput Biodata LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/miscellaneous/royal-rajput-biodata/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A Rajput marriage biodata on A4 in Palatino with birth date, time and place, height, complexion, blood group, rashi, nakshatra, gotra and manglik status.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/miscellaneous/royal-rajput-biodata/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Royal Rajput Biodata preview](preview.png)

## What is in it
- Document class: `article` with `11pt, a4paper`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Royal Rajput Biodata on LetX](https://letx.app/templates/miscellaneous/royal-rajput-biodata/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/miscellaneous/royal-rajput-biodata
latexmk -pdf main.tex
```
