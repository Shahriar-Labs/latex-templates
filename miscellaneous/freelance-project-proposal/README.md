## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/freelance-project-proposal.git
cd freelance-project-proposal
latexmk -pdf main.tex
```
Compiler: **pdflatex** (see `metadata.json`).
