# Name Tag Badge LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/miscellaneous/name-tag/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A conference name badge on A4 in Lato for a named event, with the attendee's name, role and company, the city, and a QR code.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/miscellaneous/name-tag/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Name Tag Badge preview](preview.png)

## What is in it
- Document class: `article` with `a4paper`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Name Tag Badge on LetX](https://letx.app/templates/miscellaneous/name-tag/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/miscellaneous/name-tag
latexmk -pdf main.tex
```
