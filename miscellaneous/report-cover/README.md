# Report Cover Page LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/miscellaneous/report-cover/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A report cover page in Lato drawn in TikZ, with a colour band across the top, a bold report title block and a decorative circle motif.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/miscellaneous/report-cover/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Report Cover Page preview](preview.png)

## What is in it
- Document class: `article` with `11pt`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Report Cover Page on LetX](https://letx.app/templates/miscellaneous/report-cover/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/miscellaneous/report-cover
latexmk -pdf main.tex
```
