# Gantt Project Plan LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/miscellaneous/gantt-project-plan/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

Gantt project plan LaTeX template (pgfgantt), a landscape timeline with grouped tasks, progress bars, milestones and dependency links, plus a deliverables/ownership summary table.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/miscellaneous/gantt-project-plan/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Gantt Project Plan preview](preview.png)

## What is in it
- Document class: `article` with `a4paper, landscape`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Gantt Project Plan on LetX](https://letx.app/templates/miscellaneous/gantt-project-plan/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/miscellaneous/gantt-project-plan
latexmk -pdf main.tex
```
