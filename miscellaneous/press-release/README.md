# Press Release LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/miscellaneous/press-release/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

Corporate press release LaTeX template, FOR IMMEDIATE RELEASE header, headline & subheadline, dateline, structured body, an executive pull-quote, boilerplate About box, media contact and a centered end mark.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/miscellaneous/press-release/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Press Release preview](preview.png)

## What is in it
- Document class: `article` with `10pt, a4paper`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Press Release on LetX](https://letx.app/templates/miscellaneous/press-release/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/miscellaneous/press-release
latexmk -pdf main.tex
```
