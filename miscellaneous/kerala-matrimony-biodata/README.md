# Kerala Matrimonial Biodata LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/miscellaneous/kerala-matrimony-biodata/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A Kerala matrimonial biodata on A4 in Palatino with astrological details (star, rasi, gothram, kuja dosha, time and place of birth) and personal details.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/miscellaneous/kerala-matrimony-biodata/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Kerala Matrimonial Biodata preview](preview.png)

## What is in it
- Document class: `article` with `11pt, a4paper`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Kerala Matrimonial Biodata on LetX](https://letx.app/templates/miscellaneous/kerala-matrimony-biodata/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/miscellaneous/kerala-matrimony-biodata
latexmk -pdf main.tex
```
