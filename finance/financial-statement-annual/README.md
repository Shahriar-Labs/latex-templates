# Annual Financial Statement LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/finance/financial-statement-annual/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

An annual financial statement on A4 with strategic highlights, and consolidated statements of operations, comprehensive income and the balance sheet.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/finance/financial-statement-annual/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Annual Financial Statement preview](preview.png)

## What is in it
- Document class: `article` with `11pt, a4paper`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, and 4 section files under `sections/`

## Use it online
Open **[Annual Financial Statement on LetX](https://letx.app/templates/finance/financial-statement-annual/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/finance/financial-statement-annual
latexmk -pdf main.tex
```
