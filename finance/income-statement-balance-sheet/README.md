# Balance Sheet & Income Statement LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/finance/income-statement-balance-sheet/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A balance sheet and income statement on letter paper with key metrics and ratios, consolidated operations, the statement of financial position, cash flows and notes.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/finance/income-statement-balance-sheet/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Balance Sheet & Income Statement preview](preview.png)

## What is in it
- Document class: `article` with `10pt, letterpaper`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, and 7 section files under `sections/`

## Use it online
Open **[Balance Sheet & Income Statement on LetX](https://letx.app/templates/finance/income-statement-balance-sheet/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/finance/income-statement-balance-sheet
latexmk -pdf main.tex
```
