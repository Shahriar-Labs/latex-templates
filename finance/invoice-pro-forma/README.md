# Pro Forma Invoice LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/finance/invoice-pro-forma/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A pro forma invoice on A4 with itemised lines in euros and terms covering validity, acceptance, currency risk, intellectual property, confidentiality, governing law and force majeure.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/finance/invoice-pro-forma/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Pro Forma Invoice preview](preview.png)

## What is in it
- Document class: `article` with `11pt, a4paper`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Pro Forma Invoice on LetX](https://letx.app/templates/finance/invoice-pro-forma/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/finance/invoice-pro-forma
latexmk -pdf main.tex
```
