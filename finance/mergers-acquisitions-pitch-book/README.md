# Mergers & Acquisitions (M&A) Pitch Book LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/finance/mergers-acquisitions-pitch-book/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

An M&A pitch book in 16:9 Beamer with twenty-seven frames, set in Source Sans and Source Serif, with trading comparables, strategic rationale for an acquirer and nineteen tables.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/finance/mergers-acquisitions-pitch-book/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Mergers & Acquisitions (M&A) Pitch Book preview](preview.png)

## What is in it
- Document class: `beamer` with `10pt, aspectratio=169`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Mergers & Acquisitions (M&A) Pitch Book on LetX](https://letx.app/templates/finance/mergers-acquisitions-pitch-book/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/finance/mergers-acquisitions-pitch-book
latexmk -pdf main.tex
```
