# ETF Factsheet LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/finance/etf-factsheet/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

An ETF factsheet on A4 set in Lato, with the fund objective, top ten holdings, a sector breakdown chart, risk metrics and an ESG profile.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/finance/etf-factsheet/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![ETF Factsheet preview](preview.png)

## What is in it
- Document class: `article` with `11pt, a4paper`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, and 5 section files under `sections/`

## Use it online
Open **[ETF Factsheet on LetX](https://letx.app/templates/finance/etf-factsheet/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/finance/etf-factsheet
latexmk -pdf main.tex
```
