## Use it online (recommended)
Open **[Project Charter on LetX »](https://letx.app/templates/finance/project-charter)** and click *Open as Template* — it compiles in ~1 second, in your browser, free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/project-charter.git
cd project-charter
latexmk -pdf main.tex
```
Compiler: **pdflatex** (see `metadata.json`).
