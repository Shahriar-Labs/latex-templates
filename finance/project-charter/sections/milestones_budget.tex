\subsection{Budget Allocation}
The total approved budget for Project Zenith is \$1,250,000, allocated across the following resource categories:
\begin{itemize}
  \item \textbf{Internal Quantitative \& Dev Personnel:} \$750,000 (60\%)
  \item \textbf{Commercial Solver Licenses:} \$200,000 (16\%)
  \item \textbf{Infrastructure \& Cloud Compute:} \$180,000 (14.4\%)
  \item \textbf{Contingency Reserve (Risk Mitigation):} \$120,000 (9.6\%)
\end{itemize}
