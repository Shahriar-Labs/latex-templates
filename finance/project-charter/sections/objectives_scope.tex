\section{Project Objectives \& Scope}

\subsection{Primary Objectives}
The project aims to achieve the following quantitative and qualitative goals:
\begin{itemize}
  \item \textbf{Latency Reduction:} Decrease the portfolio optimization cycle time from 15 minutes to under 500 milliseconds for a universe of 5,000 active instruments.
  \item \textbf{Transaction Cost Mitigation:} Incorporate transaction cost models directly into the optimization objective function, targeting an annual 12\% reduction in trading slippage costs.
  \item \textbf{Risk Management Integration:} Enable real-time Value-at-Risk (VaR) and Conditional Value-at-Risk (CVaR) constraints during optimization runs.
  \item \textbf{Scalability:} Support concurrently managing up to 200 distinct portfolio configurations with varying constraint models.
\end{itemize}

\subsection{Scope Boundaries}
To ensure project execution remains disciplined and focused, the scope boundaries are defined as follows:

\begin{minipage}[t]{0.48\textwidth}
  \begin{callout-box}{In-Scope}
    \begin{itemize}[leftmargin=12pt]
      \item Development of the core optimization engine using C++20 and specialized solvers.
      \item REST and gRPC API development for integration with downstream execution systems.
      \item Configuration dashboard for portfolio managers to adjust risk parameters.
      \item Backtesting framework spanning 10 years of historical tick data.
    \end{itemize}
  \end{callout-box}
\end{minipage}
\hfill
\begin{minipage}[t]{0.48\textwidth}
  \begin{callout-box}{Out-of-Scope}
    \begin{itemize}[leftmargin=12pt]
      \item Direct execution routing (APOE will output target portfolios, not route orders).
      \item Integration with retail brokerages (strictly institutional trading).
      \item Frontend mobile application development (APOE dashboard will be web-only).
      \item Proprietary alpha signal generation models.
    \end{itemize}
  \end{callout-box}
\end{minipage}
