# Quant Research Note LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/finance/quant-research-note/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A quantitative research note in Lato with a two-column layout, covering signal construction, backtest results with pgfplots charts, and risk and implementation.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/finance/quant-research-note/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Quant Research Note preview](preview.png)

## What is in it
- Document class: `article` with `10pt`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, and 4 section files under `sections/`

## Use it online
Open **[Quant Research Note on LetX](https://letx.app/templates/finance/quant-research-note/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/finance/quant-research-note
latexmk -pdf main.tex
```
