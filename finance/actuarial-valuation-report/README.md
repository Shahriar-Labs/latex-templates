# Actuarial Valuation Report LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/finance/actuarial-valuation-report/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

An actuarial valuation report set in Lato, in four numbered parts: executive summary, actuarial assumptions, a reconciliation of the unfunded liability, and the actuarial certification.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/finance/actuarial-valuation-report/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Actuarial Valuation Report preview](preview.png)

## What is in it
- Document class: `article` with `11pt`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, and 4 section files under `sections/`

## Use it online
Open **[Actuarial Valuation Report on LetX](https://letx.app/templates/finance/actuarial-valuation-report/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/finance/actuarial-valuation-report
latexmk -pdf main.tex
```
