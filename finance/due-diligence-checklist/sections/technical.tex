\subsection{3.2 Workstream Summary \& Risk Analysis}
\begin{itemize}[leftmargin=*]
  \item \textbf{Cybersecurity Assessments (High Risk):} The lack of a recent penetration test (none conducted in the last 18 months) is a critical compliance gap. An external penetration test must be commissioned immediately.
  \item \textbf{Technical Debt (Medium Risk):} The legacy payment gateway API suffers from tight coupling, posing modular maintenance risks during integration into Vertex's core portfolio systems.
  \item \textbf{Scalability (Low Risk):} The microservice deployment on containerized orchestration clusters provides robust scalability, with current CPU/Memory headroom at approximately 45\%.
\end{itemize}
