## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/due-diligence-checklist.git
cd due-diligence-checklist
latexmk -pdf main.tex
```
Compiler: **pdflatex** (see `metadata.json`).
