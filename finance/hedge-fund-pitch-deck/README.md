# Hedge Fund Pitch Deck LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/finance/hedge-fund-pitch-deck/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A hedge fund pitch in 16:9 Beamer with an investment thesis, key financials, a catalyst roadmap, a valuation waterfall, a probability-weighted bull, base and bear case, and a risk matrix.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/finance/hedge-fund-pitch-deck/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Hedge Fund Pitch Deck preview](preview.png)

## What is in it
- Document class: `beamer` with `10pt, aspectratio=169`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Hedge Fund Pitch Deck on LetX](https://letx.app/templates/finance/hedge-fund-pitch-deck/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/finance/hedge-fund-pitch-deck
latexmk -pdf main.tex
```
