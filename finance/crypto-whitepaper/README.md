# Cryptocurrency Whitepaper LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/finance/crypto-whitepaper/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A cryptocurrency whitepaper covering a DAG consensus architecture, state settlement with ZK-rollups, mathematical performance modelling, and tokenomics and governance.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/finance/crypto-whitepaper/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Cryptocurrency Whitepaper preview](preview.png)

## What is in it
- Document class: `article` with `10pt`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, and 6 section files under `sections/`

## Use it online
Open **[Cryptocurrency Whitepaper on LetX](https://letx.app/templates/finance/crypto-whitepaper/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/finance/crypto-whitepaper
latexmk -pdf main.tex
```
