# OKR Planning Sheet LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/finance/okr-planning-sheet/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A quarterly OKR planning sheet with progress gauges, objectives on track, a confidence mix of high, medium and low key results, objectives at a glance, and a review cadence.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/finance/okr-planning-sheet/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![OKR Planning Sheet preview](preview.png)

## What is in it
- Document class: `article` with `10pt`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[OKR Planning Sheet on LetX](https://letx.app/templates/finance/okr-planning-sheet/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/finance/okr-planning-sheet
latexmk -pdf main.tex
```
