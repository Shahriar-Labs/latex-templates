# Service Level Agreement LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/finance/service-level-agreement/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A service level agreement (SLA) on A4 with purpose and scope, availability targets, support and escalation, service credits, governance and review, and execution.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/finance/service-level-agreement/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Service Level Agreement preview](preview.png)

## What is in it
- Document class: `article` with `11pt, a4paper`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, `references.bib`, and 7 section files under `sections/`

## Use it online
Open **[Service Level Agreement on LetX](https://letx.app/templates/finance/service-level-agreement/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/finance/service-level-agreement
latexmk -pdf main.tex
```
