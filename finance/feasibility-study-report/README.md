## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/feasibility-study-report.git
cd feasibility-study-report
latexmk -pdf main.tex
```
Compiler: **pdflatex** (see `metadata.json`).
