\section{Scenario Comparison and Sensitivity Analysis}
\label{sec:comparison}

To ensure a balanced evaluation, Project Meridian was compared against alternative implementation options. The comparison evaluates three distinct pathways:
\begin{enumerate}[leftmargin=1.5em]
  \item \textbf{Scenario A: Status Quo (Legacy Batch Processing):} Retain the existing file-transfer reconciliation systems.
  \item \textbf{Scenario B: Project Meridian (Digital Integration Hub):} Implement the hybrid-cloud event-driven hub proposed in this study.
  \item \textbf{Scenario C: Full Public Cloud Re-platform:} Completely rebuild Nexa's core ledger on a public cloud provider.
\end{enumerate}

\subsection{Sensitivity Analysis Summary}
A sensitivity analysis was performed to verify the robustness of Scenario B's economic returns under varied conditions:
\begin{itemize}[leftmargin=1.5em]
  \item \textbf{CapEx Cost Overrun:} An increase of 20\% in implementation cost reduces the 5-year NPV from \$485,000 to \$415,000, which remains well above the hurdle rate.
  \item \textbf{Implementation Delay:} A 3-month delay shifts the payback period to 2.4 years, but does not materially threaten the project's viability.
\end{itemize}
Scenario B represents the optimal balance between investment cost, deployment timeline, and operational risk.
