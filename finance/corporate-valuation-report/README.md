## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/corporate-valuation-report.git
cd corporate-valuation-report
latexmk -pdf main.tex
```
Compiler: **pdflatex** (see `metadata.json`).
