## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/venture-debt-term-sheet-summarizer.git
cd venture-debt-term-sheet-summarizer
latexmk -pdf main.tex
```
Compiler: **pdflatex** (see `metadata.json`).
