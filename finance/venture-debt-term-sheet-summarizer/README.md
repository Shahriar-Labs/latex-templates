# Venture Debt Term Sheet Summarizer LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/finance/venture-debt-term-sheet-summarizer/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A venture debt term sheet summary on letter paper that explains what matters most, the commercial terms, covenants, collateral, events of default and warrant economics.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/finance/venture-debt-term-sheet-summarizer/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Venture Debt Term Sheet Summarizer preview](preview.png)

## What is in it
- Document class: `article` with `10pt, letterpaper`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, and 13 section files under `sections/`

## Use it online
Open **[Venture Debt Term Sheet Summarizer on LetX](https://letx.app/templates/finance/venture-debt-term-sheet-summarizer/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/finance/venture-debt-term-sheet-summarizer
latexmk -pdf main.tex
```
