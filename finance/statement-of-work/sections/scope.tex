\section{Scope of Work}
The scope of this project is limited to the configuration, testing, and deployment of the Synapse Ledger Synchronizer module and the migration of historical transaction data from Nexa's regional legacy databases to Nimbus DB. The architecture leverages modern cloud computing practices for data scalability and replication \cite{cloudmigration}, managed using standard systems project methodologies \cite{projectmgmt}.

\subsection{In-Scope Activities}
Synapse Systems Group will perform the following activities:
\begin{itemize}[label=\textcolor{secondary}{\faCheck}, leftmargin=*]
  \item \textbf{Schema Analysis:} Review existing database tables across four regional offices to design unified schema maps.
  \item \textbf{Ingestion Setup:} Set up Apache Kafka queues for robust queuing and buffering of transaction streams.
  \item \textbf{Data Pipeline Development:} Write ETL scripts to migrate historical records with full integrity checks.
  \item \textbf{Security Configuration:} Deploy mutual TLS (mTLS) certificates and Cloudflare Tunnels for secure transport.
  \item \textbf{Performance Optimization:} Perform load testing up to 5,000 requests per second and tune database indexes.
  \item \textbf{Knowledge Transfer:} Run a two-day technical workshop and hand over complete runtime documentation.
\end{itemize}

\subsection{Out-of-Scope Activities}
Any tasks not explicitly listed as in-scope are out-of-scope. Specifically, the following are excluded:
\begin{itemize}[label=\textcolor{accent}{\faTimes}, leftmargin=*]
  \item Modification of front-end client-facing accounting software or customer billing portals.
  \item Provisioning or ongoing subscription billing of the Nimbus Infrastructure cloud services.
  \item Development of custom reporting tools (Nexa will connect their existing BI systems to the database).
  \item Ongoing post-deployment support past the standard 30-day warranty window.
\end{itemize}
