# Biotech Pitch Deck LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/finance/biotech-pitch-deck/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A biotech pitch deck in 16:9 Beamer covering the unmet need, mechanism of action, clinical pipeline, phase Ib response data, competitive landscape and IP estate.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/finance/biotech-pitch-deck/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Biotech Pitch Deck preview](preview.png)

## What is in it
- Document class: `beamer` with `aspectratio=169, 10pt`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Biotech Pitch Deck on LetX](https://letx.app/templates/finance/biotech-pitch-deck/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/finance/biotech-pitch-deck
latexmk -pdf main.tex
```
