## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/flipped-classroom-activity-guide.git
cd flipped-classroom-activity-guide
latexmk -pdf main.tex
```
Compiler: **pdflatex** (see `metadata.json`).
