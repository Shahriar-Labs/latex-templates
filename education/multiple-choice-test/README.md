# Multiple Choice Test Paper LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/education/multiple-choice-test/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A multiple choice test paper on A4 for a mid-term examination, with general instructions, student details and twenty-five questions set in two columns with tick boxes.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/education/multiple-choice-test/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Multiple Choice Test Paper preview](preview.png)

## What is in it
- Document class: `article` with `11pt, a4paper`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Multiple Choice Test Paper on LetX](https://letx.app/templates/education/multiple-choice-test/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/education/multiple-choice-test
latexmk -pdf main.tex
```
