# Grading Rubric LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/education/rubrics-evaluation-form/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A landscape grading rubric for a university project, with evaluation guidelines and four performance levels from exemplary to beginning for each criterion.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/education/rubrics-evaluation-form/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Grading Rubric preview](preview.png)

## What is in it
- Document class: `article` with `11pt, a4paper`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Grading Rubric on LetX](https://letx.app/templates/education/rubrics-evaluation-form/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/education/rubrics-evaluation-form
latexmk -pdf main.tex
```
