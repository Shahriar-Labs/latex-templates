# Class Attendance Register LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/education/attendance-register/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A landscape class attendance register for one course and semester, with the instructor, meeting times and room in the header and a student-by-session grid.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/education/attendance-register/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Class Attendance Register preview](preview.png)

## What is in it
- Document class: `article` with `12pt, landscape`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Class Attendance Register on LetX](https://letx.app/templates/education/attendance-register/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/education/attendance-register
latexmk -pdf main.tex
```
