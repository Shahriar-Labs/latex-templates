# University Course Welcome Packet & FAQ LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/education/university-course-welcome-packet-faq/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A university course welcome packet on A4 with the course overview and objectives, policies and grading, the schedule and milestones, and a frequently asked questions section.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/education/university-course-welcome-packet-faq/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![University Course Welcome Packet & FAQ preview](preview.png)

## What is in it
- Document class: `article` with `11pt, a4paper`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, `references.bib`, and 5 section files under `sections/`

## Use it online
Open **[University Course Welcome Packet & FAQ on LetX](https://letx.app/templates/education/university-course-welcome-packet-faq/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/education/university-course-welcome-packet-faq
latexmk -pdf main.tex
```
