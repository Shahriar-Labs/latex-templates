## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/university-course-welcome-packet-faq.git
cd university-course-welcome-packet-faq
latexmk -pdf main.tex
```
Compiler: **pdflatex** (see `metadata.json`).
