## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/formula-sheet-exam-cheat-sheet.git
cd formula-sheet-exam-cheat-sheet
latexmk -pdf main.tex
```
Compiler: **pdflatex** (see `metadata.json`).
