# Primary School Worksheet LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/education/primary-school-worksheet/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A primary school maths worksheet on A4 with a bright boxed layout and sections of addition problems with answer boxes, plus class and name fields.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/education/primary-school-worksheet/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Primary School Worksheet preview](preview.png)

## What is in it
- Document class: `article` with `12pt, a4paper`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Primary School Worksheet on LetX](https://letx.app/templates/education/primary-school-worksheet/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/education/primary-school-worksheet
latexmk -pdf main.tex
```
