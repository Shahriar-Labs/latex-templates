# Teacher Lesson Plan LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/education/lesson-plan/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A teacher lesson plan in Lato with learning objectives, materials, standards and key vocabulary, a timed procedure, differentiation for support and extension, and reflection notes.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/education/lesson-plan/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Teacher Lesson Plan preview](preview.png)

## What is in it
- Document class: `article` with `10pt`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Teacher Lesson Plan on LetX](https://letx.app/templates/education/lesson-plan/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/education/lesson-plan
latexmk -pdf main.tex
```
