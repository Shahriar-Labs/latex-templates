\section{Feedback Guidelines}
Writing high-quality feedback is one of your most important responsibilities. Students read feedback to understand their mistakes and improve their future work. Good feedback is specific, actionable, and encouraging.

\subsection{Tone and Style}
Always maintain a professional, polite, and encouraging tone. Never use sarcasm, exclamation marks in deductions, or judgmental language.

\begin{examplebox}{\faComments\ Examples of Grading Feedback}
    Below are comparative examples of poor and high-quality feedback.
    
    \vspace{0.8em}
    \noindent\textbf{Example 1: Logical Error in AVL Rotations}
    \begin{itemize}
        \item[\color{badred}\faTimes] \textbf{Poor:} ``Your rotation code is completely broken. -10 points. Check the slides.''
        \item[\color{goodgreen}\faCheck] \textbf{Good:} ``-10 points. Your implementation of right-left double rotation fails because you did not update the parent pointer of the root node after the first rotation. Refer to Lecture 6, slide 14 for the correct pointer update sequence.''
    \end{itemize}
    
    \vspace{0.8em}
    \noindent\textbf{Example 2: Code Quality and Comments}
    \begin{itemize}
        \item[\color{badred}\faTimes] \textbf{Poor:} ``No comments. Bad code quality. -5.''
        \item[\color{goodgreen}\faCheck] \textbf{Good:} ``-5 points. While your code compiles and passes all tests, there are no docstrings or inline comments explaining the search helper function. Adding descriptive comments makes your code maintainable and easier to debug.''
    \end{itemize}
\end{examplebox}

\subsection{Feedback Writing Checklist}
When writing feedback in the Synapse system, ensure you:
\begin{enumerate}
    \item State the \textbf{exact rubric item} and points deducted.
    \item Describe the \textbf{specific bug or omission} in the student's submission.
    \item Direct the student to a \textbf{resource} (e.g., lecture slide, textbook chapter, or discussion notes) where they can find the correct implementation.
    \item Write in complete, grammatically correct sentences.
\end{enumerate}
