## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/laboratory-practical-exam-paper.git
cd laboratory-practical-exam-paper
latexmk -pdf main.tex
```
Compiler: **pdflatex** (see `metadata.json`).
