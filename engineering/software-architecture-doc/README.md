# Software Architecture Document LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/engineering/software-architecture-doc/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A software architecture document in Charter with system goals, component architecture, an interface specification of API endpoints in code, and the security architecture.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/engineering/software-architecture-doc/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Software Architecture Document preview](preview.png)

## What is in it
- Document class: `article` with `11pt, a4paper`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, and 4 section files under `sections/`

## Use it online
Open **[Software Architecture Document on LetX](https://letx.app/templates/engineering/software-architecture-doc/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/engineering/software-architecture-doc
latexmk -pdf main.tex
```
