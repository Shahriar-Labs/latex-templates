# Engineering Specification Document LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/engineering/engineering-specification/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

An engineering specification document in Lato with revision history, applicable documents, technical requirements, verification methods and a verification cross-reference matrix.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/engineering/engineering-specification/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Engineering Specification Document preview](preview.png)

## What is in it
- Document class: `article` with `11pt, a4paper`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, and 9 section files under `sections/`

## Use it online
Open **[Engineering Specification Document on LetX](https://letx.app/templates/engineering/engineering-specification/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/engineering/engineering-specification
latexmk -pdf main.tex
```
