# Datasheet (Semiconductor) LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/engineering/semiconductor-datasheet/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A semiconductor datasheet in Lato with features, applications, pin configuration, absolute maximum ratings, operating conditions, electrical characteristics and package data.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/engineering/semiconductor-datasheet/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Datasheet (Semiconductor) preview](preview.png)

## What is in it
- Document class: `article` with `10pt, a4paper`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, and 11 section files under `sections/`

## Use it online
Open **[Datasheet (Semiconductor) on LetX](https://letx.app/templates/engineering/semiconductor-datasheet/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/engineering/semiconductor-datasheet
latexmk -pdf main.tex
```
