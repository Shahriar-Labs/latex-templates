# Root Cause Analysis Report LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/engineering/root-cause-analysis-report/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A root cause analysis report on A4 with the incident timeline, problem investigation, a 5-Whys analysis, corrective and preventive actions, lessons learned and sign-off.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/engineering/root-cause-analysis-report/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Root Cause Analysis Report preview](preview.png)

## What is in it
- Document class: `article` with `11pt, a4paper`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, and 7 section files under `sections/`

## Use it online
Open **[Root Cause Analysis Report on LetX](https://letx.app/templates/engineering/root-cause-analysis-report/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/engineering/root-cause-analysis-report
latexmk -pdf main.tex
```
