# CAD Drawing Title Block LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/engineering/cad-drawing-title-block/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A CAD drawing title block drawn in TikZ with a parts list (item, part number, description, material, quantity, mass) and revision, date, drafter and approver fields.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/engineering/cad-drawing-title-block/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![CAD Drawing Title Block preview](preview.png)

## What is in it
- Document class: `article` with `10pt`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[CAD Drawing Title Block on LetX](https://letx.app/templates/engineering/cad-drawing-title-block/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/engineering/cad-drawing-title-block
latexmk -pdf main.tex
```
