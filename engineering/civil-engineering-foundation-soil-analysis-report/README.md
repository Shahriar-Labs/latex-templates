# Civil Engineering Foundation Soil Analysis Report LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/engineering/civil-engineering-foundation-soil-analysis-report/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A foundation and soil analysis report with a site investigation, engineering properties, foundation alternatives, a preliminary bored-pile design, and seismic considerations, in twenty-two tables.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/engineering/civil-engineering-foundation-soil-analysis-report/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Civil Engineering Foundation Soil Analysis Report preview](preview.png)

## What is in it
- Document class: `article` with `11pt, a4paper`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, and 14 section files under `sections/`

## Use it online
Open **[Civil Engineering Foundation Soil Analysis Report on LetX](https://letx.app/templates/engineering/civil-engineering-foundation-soil-analysis-report/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/engineering/civil-engineering-foundation-soil-analysis-report
latexmk -pdf main.tex
```
