# Inspection Report (Nondestructive Testing) LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/engineering/ndt-inspection-report/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A nondestructive testing (NDT) inspection report on A4 with the technique summary, an indication summary, an acceptance criteria matrix, an annotated diagram and inspector certification.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/engineering/ndt-inspection-report/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Inspection Report (Nondestructive Testing) preview](preview.png)

## What is in it
- Document class: `article` with `a4paper, 11pt`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, and 9 section files under `sections/`

## Use it online
Open **[Inspection Report (Nondestructive Testing) on LetX](https://letx.app/templates/engineering/ndt-inspection-report/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/engineering/ndt-inspection-report
latexmk -pdf main.tex
```
