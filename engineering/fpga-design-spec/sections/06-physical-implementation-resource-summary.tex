\section{Physical Implementation \& Resource Summary}
The Vertex-9 core features isolated clock domains to optimize maximum speed paths. Hardware compilation properties are defined below.

\subsection{Clock Domain and Reset Strategy}
The logic structure relies on three distinct clock domains to prevent timing violation paths:
\begin{itemize}
    \item \textbf{System Clock (\texttt{sys\_clk}):} Operates at 250 MHz. Used for DMA controller logic and the ExpressLink physical link layer interface.
    \item \textbf{Configuration Clock (\texttt{cfg\_clk}):} Operates at 100 MHz. Used for low-speed CSR read/write access.
    \item \textbf{Core DSP Clock (\texttt{dsp\_clk}):} Runs at 400 MHz. Dedicated to parallel processing arithmetic.
\end{itemize}
Asynchronous Clock Domain Crossings (CDC) are isolated using dual-clock FIFOs and dual-flip-flop synchronizers.
