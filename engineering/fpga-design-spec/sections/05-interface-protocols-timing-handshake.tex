\section{Interface Protocols \& Timing Handshake}
The SynapseBus-Lite interface utilizes a strict handshaking interface. The master asserts the write enable (\texttt{WEN}) and supplies address and data. The slave core asserts the \texttt{READY} signal to indicate that the write operation has been accepted and registered.

\subsection{Write Transaction Sequence}
\begin{enumerate}
    \item \textbf{Time T1:} The bus master drives the write address (\texttt{0x0A24}) and write enable (\texttt{WEN}) signals. The write data bus (\texttt{WDATA}) becomes valid with the value \texttt{0xDEADBEEF}.
    \item \textbf{Time T2:} The slave core decodes the address and asserts \texttt{READY} on the falling edge of the clock cycle, signaling that it is prepared to register the transaction.
    \item \textbf{Time T3:} On the next rising edge of the system clock, the write operation is committed, data is latched into the target CSR, and the master de-asserts \texttt{WEN} to conclude the write transaction.
\end{enumerate}
