\section{Site Conditions and System Design}
\label{sec:site_design}

\subsection{Meteorological Design Conditions}
The Meridian Solar PV Facility is designed to operate under the arid, high-irradiation conditions characteristic of the Great Basin Desert. The system engineering must account for extreme diurnal temperature variations, high wind speeds, and localized dust accumulation. The design envelope is defined by the following parameters:
\begin{itemize}
    \item \textbf{Design Ambient Temperature Range:} $-10^\circ$C to $+45^\circ$C.
    \item \textbf{Extreme Wind Design Speed:} 140\,km/h (3-second gust, 50-year return period).
    \item \textbf{Annual Global Horizontal Irradiance (GHI):} 1,980\,kWh/m\textsuperscript{2}/year.
    \item \textbf{Annual Plane-of-Array (POA) Irradiance:} 2,240\,kWh/m\textsuperscript{2}/year (tracker-optimized).
\end{itemize}

\subsection{Electrical Configuration}
The system layout features a DC-to-AC overloading ratio of 1.25, which minimizes clipping losses while maximizing inverter capacity utilization. The nominal DC system voltage is 1500\,V. Each inverter block contains multiple DC sub-combiners with smart monitoring capability. 

The electrical transformation pathway from generation to interconnection is shown in Figure~\ref{fig:electrical_diagram}.
