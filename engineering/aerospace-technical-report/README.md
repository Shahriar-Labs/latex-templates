# Aerospace Technical Report LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/engineering/aerospace-technical-report/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

An aerospace technical report on the report class with revision history, symbols and abbreviations, applicable documents, system and functional architecture, and an avionics bus interface.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/engineering/aerospace-technical-report/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Aerospace Technical Report preview](preview.png)

## What is in it
- Document class: `report` with `12pt, a4paper`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, and 23 section files under `sections/`

## Use it online
Open **[Aerospace Technical Report on LetX](https://letx.app/templates/engineering/aerospace-technical-report/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/engineering/aerospace-technical-report
latexmk -pdf main.tex
```
