# NDSS Symposium Submission Template LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/conferences/ndss-symposium-submission-template/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

An NDSS submission on IEEEtran in conference mode, with Background, Threat Model, Design and Evaluation, algorithmic pseudocode and pgfplots charts.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/conferences/ndss-symposium-submission-template/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![NDSS Symposium Submission Template preview](preview.png)

## What is in it
- Document class: `IEEEtran` with `conference`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, `references.bib`, and 8 section files under `sections/`

## Use it online
Open **[NDSS Symposium Submission Template on LetX](https://letx.app/templates/conferences/ndss-symposium-submission-template/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/conferences/ndss-symposium-submission-template
latexmk -pdf main.tex
```
