# KDD Research Track Paper LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/conferences/kdd-research-track-paper/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A KDD research track paper on ACM's acmart class with the sigconf, anonymous and review options the KDD 2027 call gives, CCS concepts, figure descriptions and ACM-style references.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/conferences/kdd-research-track-paper/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![KDD Research Track Paper preview](preview.png)

## What is in it
- Document class: `acmart` with `sigconf, anonymous, review`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, `refs.bib`, and 7 section files under `sections/`

## Use it online
Open **[KDD Research Track Paper on LetX](https://letx.app/templates/conferences/kdd-research-track-paper/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/conferences/kdd-research-track-paper
latexmk -pdf main.tex
```
