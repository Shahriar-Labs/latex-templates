## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/naacl-2026-submission-paper.git
cd naacl-2026-submission-paper
latexmk -pdf main.tex
```
Compiler: **pdflatex** (see `metadata.json`).
