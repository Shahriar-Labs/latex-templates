# NAACL 2026 Submission Paper LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/conferences/naacl-2026-submission-paper/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A NAACL 2026-style paper on A4 in two columns with fourteen tables, pgfplots charts, and the Limitations, Ethical Considerations and Reproducibility Statement sections.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/conferences/naacl-2026-submission-paper/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![NAACL 2026 Submission Paper preview](preview.png)

## What is in it
- Document class: `article` with `11pt, a4paper, twocolumn`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, and 14 section files under `sections/`

## Use it online
Open **[NAACL 2026 Submission Paper on LetX](https://letx.app/templates/conferences/naacl-2026-submission-paper/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/conferences/naacl-2026-submission-paper
latexmk -pdf main.tex
```
