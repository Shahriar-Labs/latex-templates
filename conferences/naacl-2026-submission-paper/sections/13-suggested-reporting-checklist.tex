\section{Suggested Reporting Checklist}
\label{app:checklist}

\begin{enumerate}
  \item State who defined the target ``standard'' and why normalization is
        appropriate for the intended use.
  \item Report how speakers participated in collection, annotation,
        evaluation, governance, and benefit sharing.
  \item Separate retrieval-memory examples from all development and test
        conversations, speakers, and near-duplicates.
  \item Release uncertainty thresholds, gate features, datastore size,
        embedding model, index settings, and retrieval latency.
  \item Report confidence intervals and per-variety scores, including the
        number of examples behind each score.
  \item Manually audit entity changes and high-confidence errors before any
        deployment.
\end{enumerate}
