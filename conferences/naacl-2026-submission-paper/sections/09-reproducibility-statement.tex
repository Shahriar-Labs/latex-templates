\section{Reproducibility Statement}
\label{sec:reproducibility}

For an actual study, a release should include dataset licenses and datasheets,
speaker-disjoint split identifiers, preprocessing and alignment scripts,
memory-construction code, all hyperparameters, random seeds, per-example model
outputs, and bootstrap evaluation scripts. Reporting computational budgets and
failed configurations follows the broader recommendation to document
experimental work transparently \citep{dodge2019show}. Any private data should
be replaced by consented evaluation access or a privacy-preserving synthetic
test suite.
