# RecSys Submission Paper LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/conferences/recsys-submission-paper/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A RecSys submission on acmart with sigconf, review and anonymous options, with a named benchmark protocol, Claim-Aligned Reporting and a Reproducibility Checklist.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/conferences/recsys-submission-paper/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![RecSys Submission Paper preview](preview.png)

## What is in it
- Document class: `acmart` with `sigconf, review, anonymous`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, and 8 section files under `sections/`

## Use it online
Open **[RecSys Submission Paper on LetX](https://letx.app/templates/conferences/recsys-submission-paper/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/conferences/recsys-submission-paper
latexmk -pdf main.tex
```
