\section{Experiments}
\label{sec:experiments}
We evaluated DSR on the multilingual reasoning benchmark from the \citet{synapsenexa2025benchmark}, which evaluates reasoning under resource constraints.

\subsection{Baselines}
We compare DSR against three distinct routing paradigms:
\begin{itemize}
  \item \textbf{Baseline Transformer:} Standard monolithic structure without dynamic routing.
  \item \textbf{Mixture-of-Experts:} Traditional token-level dynamic routing using top-$k$ gating.
  \item \textbf{Vertex-Routing:} Sentence-level modular routing based on historical accuracy.
\end{itemize}
