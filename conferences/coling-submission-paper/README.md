# COLING Submission Paper LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/conferences/coling-submission-paper/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A COLING-style paper in two columns on the article class with natbib, four results tables and a TikZ figure, not the COLING style file itself.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/conferences/coling-submission-paper/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![COLING Submission Paper preview](preview.png)

## What is in it
- Document class: `article` with `10pt, twocolumn`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, `references.bib`, and 7 section files under `sections/`

## Use it online
Open **[COLING Submission Paper on LetX](https://letx.app/templates/conferences/coling-submission-paper/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/conferences/coling-submission-paper
latexmk -pdf main.tex
```
