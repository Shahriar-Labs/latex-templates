\section{Experiments}
We implemented the Synapse compiler as a frontend to the Vertex Virtual Machine. The compiler performs linear typestate checking during the semantic analysis phase. To evaluate the overhead of compile-time verification, we compiled several benchmark suites representing typical server workloads. The benchmarks were executed on a system equipped with an 8-core CPU and 16 GB of RAM, running the Vertex runtime.

We compared Synapse against a Baseline compiler (which lacks typestate checking) and the Apex framework (which performs dynamic, runtime-based checks). We measured three metrics: compilation time, static verification time, and memory overhead during compiler execution. The benchmarks vary in complexity, from simple message passing (Vertex-A) to complex nested actor protocols (Synapse-B and Nexa-C).
