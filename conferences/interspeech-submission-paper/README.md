# INTERSPEECH Submission Paper LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/conferences/interspeech-submission-paper/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

An INTERSPEECH-style speech paper in two columns with natbib and pgfplots, on the article class rather than the INTERSPEECH style kit.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/conferences/interspeech-submission-paper/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![INTERSPEECH Submission Paper preview](preview.png)

## What is in it
- Document class: `article` with `10pt, twocolumn`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, `references.bib`, and 8 section files under `sections/`

## Use it online
Open **[INTERSPEECH Submission Paper on LetX](https://letx.app/templates/conferences/interspeech-submission-paper/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/conferences/interspeech-submission-paper
latexmk -pdf main.tex
```
