\section{Background and Related Work}

\subsection{Automated Program Repair}

APR techniques broadly fall into three categories. \textit{Search-based}
approaches~\cite{le2015history} explore a space of program mutations guided by
fitness functions informed by test suites. \textit{Semantics-based}
methods~\cite{mechtaev2018semantic} use symbolic execution or constraint
solving to synthesise patches that satisfy extracted correctness conditions.
\textit{Learning-based} techniques~\cite{chen2019sequence} frame patch generation
as a neural machine translation problem, mapping buggy code to fixed code.

\subsection{Large Language Models for Code}

Transformer-based models pretrained on large corpora of source code have
shown strong performance on code completion~\cite{chen2021evaluating},
program translation~\cite{roziere2020unsupervised}, and test-case
generation~\cite{tufano2020unit}. Our work builds on this line of research by
incorporating program-analysis signals into the LLM prompting pipeline.
