# USENIX ATC Paper LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/conferences/usenix-atc-paper/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A USENIX ATC-style systems paper in two columns with pgfplots charts, on the article class rather than the USENIX style file.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/conferences/usenix-atc-paper/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![USENIX ATC Paper preview](preview.png)

## What is in it
- Document class: `article` with `10pt, twocolumn`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, `refs.bib`, and 7 section files under `sections/`

## Use it online
Open **[USENIX ATC Paper on LetX](https://letx.app/templates/conferences/usenix-atc-paper/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/conferences/usenix-atc-paper
latexmk -pdf main.tex
```
