# WSDM Submission Paper LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/conferences/wsdm-submission-paper/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A WSDM full paper on ACM's acmart class with the sigconf, anonymous and review options the WSDM 2027 call gives, an ethical considerations section and a pgfplots bar chart.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/conferences/wsdm-submission-paper/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![WSDM Submission Paper preview](preview.png)

## What is in it
- Document class: `acmart` with `sigconf, anonymous, review`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, `wsdmrefs.bib`, and 9 section files under `sections/`

## Use it online
Open **[WSDM Submission Paper on LetX](https://letx.app/templates/conferences/wsdm-submission-paper/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/conferences/wsdm-submission-paper
latexmk -pdf main.tex
```
