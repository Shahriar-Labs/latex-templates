\section{Conclusion}
\label{sec:conclusion}

For a shared random oracle, domain separation is a security boundary.  By
hashing a protocol tag, public key, statement, commitment, and fresh salt using
an injective encoding, the salted Fiat--Shamir transform admits a modular
multi-user analysis.  The public-key field prevents an avoidable user-guessing
loss; the salt exposes two elementary bad-event bounds; and special soundness
handles the remaining extraction step.  The resulting theorem is intentionally
simple enough to audit and to specialize.  Its main practical lesson is
equally simple: specify the bytes that are hashed, size randomness against
system-wide traffic, and make every proof assumption visible at the API
boundary.
