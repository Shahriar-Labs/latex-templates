# ACM CCS Submission Template LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/conferences/acm-ccs-submission-template/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

An ACM CCS security paper on acmart with the sigconf, review and anonymous options, with Threat Model, System Design, Leakage Quantification and pgfplots evaluation charts.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/conferences/acm-ccs-submission-template/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![ACM CCS Submission Template preview](preview.png)

## What is in it
- Document class: `acmart` with `sigconf, review, anonymous`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, `references.bib`, and 7 section files under `sections/`

## Use it online
Open **[ACM CCS Submission Template on LetX](https://letx.app/templates/conferences/acm-ccs-submission-template/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/conferences/acm-ccs-submission-template
latexmk -pdf main.tex
```
