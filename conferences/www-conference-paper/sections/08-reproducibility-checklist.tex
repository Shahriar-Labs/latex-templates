\section{Reproducibility Checklist}
\label{sec:reproducibility}

A complete study should archive or document the following:

\begin{itemize}
  \item immutable question, document-version, and annotation identifiers;
  \item publication, revision, crawl, and question timestamps with time zones;
  \item rules for canonicalization, duplicate detection, and temporal eligibility;
  \item chronological split manifests and leakage audits;
  \item prompts, model versions, retrieval indexes, query budgets, seeds, and
    decoding parameters;
  \item annotation instructions, agreement, adjudication, and compensation;
  \item per-question predictions and bootstrap code for every reported metric;
    and
  \item compute, latency, API, and financial costs sufficient to compare system
    efficiency.
\end{itemize}

Because live pages change, reproducing a Web experiment requires more than
releasing code.  Where redistribution is lawful, content-addressed snapshots
provide the strongest audit trail.  Otherwise, a release should include hashes,
timestamps, URLs, extraction rules, and clear instructions for reconstructing
the closest permissible snapshot.
