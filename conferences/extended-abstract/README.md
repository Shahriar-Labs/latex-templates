# Extended Abstract LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/conferences/extended-abstract/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

Conference extended abstract (2-page mini-paper) LaTeX template, title, authors & affiliations, condensed Introduction/Method/Results sections with a chart or table, conclusion and references.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/conferences/extended-abstract/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Extended Abstract preview](preview.png)

## What is in it
- Document class: `article` with `10pt, twocolumn`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, and 5 section files under `sections/`

## Use it online
Open **[Extended Abstract on LetX](https://letx.app/templates/conferences/extended-abstract/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/conferences/extended-abstract
latexmk -pdf main.tex
```
