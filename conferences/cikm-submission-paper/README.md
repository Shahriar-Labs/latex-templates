# CIKM Submission Paper LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/conferences/cikm-submission-paper/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A CIKM full paper on ACM's acmart class in the two-column sigconf format, anonymized for double-blind review, with CCS concepts, a TikZ framework diagram and ACM-style references.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/conferences/cikm-submission-paper/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![CIKM Submission Paper preview](preview.png)

## What is in it
- Document class: `acmart` with `sigconf, anonymous, review`
- Compiler: pdflatex
- Files: `main.bib`, `main.tex`, `preamble.tex`, and 7 section files under `sections/`

## Use it online
Open **[CIKM Submission Paper on LetX](https://letx.app/templates/conferences/cikm-submission-paper/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/conferences/cikm-submission-paper
latexmk -pdf main.tex
```
