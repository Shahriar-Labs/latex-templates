\section{Experiments}
We evaluate our framework on two realistic enterprise benchmarks generated from real-world schema distributions: Synapse-10K and Nexa-50K.

\subsection{Dataset Statistics}
The Synapse-10K dataset contains 10,000 entity alignment pairs across two heterogeneous subgraphs with 15 relation types. The Nexa-50K dataset represents a larger instance, consisting of 50,000 alignment pairs and 32 relation types. Both datasets are stored and queried using the Vertex Graph Database \cite{chen2023vertex}.

\subsection{Baseline Methods}
We compare Synapse-HEA against three competitive baselines:
\begin{itemize}
    \item \textbf{Multi-GCN} \cite{smith2021graph}: A multi-channel graph convolutional network that models relation structures via graph flattening.
    \item \textbf{Nimbus-GNN} \cite{nimbus2023framework}: A joint entity and relation embedding model.
    \item \textbf{Nexa-Align} \cite{alfihri2022nexa}: An enterprise-focused deep alignment framework.
\end{itemize}
