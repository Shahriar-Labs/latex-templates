\section{Introduction}
\label{sec:intro}
Neuromorphic computing represents a promising paradigm for executing brain-inspired algorithms with low power consumption. Fictional neuromorphic architectures, such as the Nimbus-100 and the Vertex Mesh, consist of thousands of interconnected computational cores that communicate via asynchronous spiking packets. In these systems, the network-on-chip (NoC) is often the primary source of latency and energy dissipation due to the dynamic nature of spike distributions. Static routing strategies, including XY routing or pre-calculated shortest path routing, are common but lead to severe routing hotspots. Dynamic routing methods can mitigate congestion but require heavy calculations, which consumes precious resources on the neuromorphic substrate.

To solve this, we propose SynapticProp, a localized Graph Neural Network (GNN) model designed for hardware implementation. SynapticProp operates directly on the topology graph to predict routing congestion and compute optimal paths. Our contributions are:
\begin{enumerate}
    \item We formulate neuromorphic routing as a dynamic path optimization problem on graphs.
    \item We introduce a lightweight GNN update rule with low precision requirements.
    \item We validate our approach on the Meridian-X emulator, showing superior performance compared to standard baselines.
\end{enumerate}

\section{Related Work}
\label{sec:related}
Routing in neuromorphic fabrics has been studied extensively. Early work utilized static routing, which lacks flexibility. Dynamic routing algorithms, such as those implemented in Nexa networks \citep{rostova2022nexa}, adapt to network state but suffer from high latency during routing decisions. Machine learning-based routing has emerged as a viable alternative \citep{nakamura2023spiking}. GNNs are uniquely suited for this task due to their ability to generalize to arbitrary topologies \citep{vance2025vertex}. However, state-of-the-art GNN models are too computationally expensive for hardware-level integration. SynapticProp addresses this gap by using a simplified message-passing framework with quantized weights.

\section{The SynapticProp Architecture}
\label{sec:method}
We model the neuromorphic interconnect as a directed graph $G = (V, E)$, where $V$ represents the neuromorphic cores and $E$ represents the physical communication channels. Each node $i \in V$ maintains a hidden state $h_i^{(t)}$ representing its current congestion level and packet queue status. At each routing epoch, nodes exchange messages with their direct neighbors.
The state update equation for node $i$ at iteration $t+1$ is given by:
\begin{equation}
h_i^{(t+1)} = \sigma \left( W h_i^{(t)} + \sum_{j \in \mathcal{N}(i)} \alpha_{ij}^{(t)} V h_j^{(t)} \right)
\label{eq:state_update}
\end{equation}
where $W$ and $V$ are weight matrices, $\mathcal{N}(i)$ is the set of neighboring nodes for node $i$, $\sigma(\cdot)$ is a non-linear activation function, and $\alpha_{ij}^{(t)} = \text{dynamic attention weight}$. The attention weights are calculated as:
\begin{equation}
\alpha_{ij}^{(t)} = \frac{\exp\left( \mathbf{a}^T [h_i^{(t)} \parallel h_j^{(t)}] \right)}{\sum_{k \in \mathcal{N}(i)} \exp\left( \mathbf{a}^T [h_i^{(t)} \parallel h_k^{(t)}] \right)}
\label{eq:attention}
\end{equation}
Here, $\parallel$ denotes concatenation, and $\mathbf{a}$ is a learnable vector. Because of the limited memory on neuromorphic cores, we quantize the weights $W$ and $V$ to 4-bit integers and approximate the exponential functions using lookup tables.

\section{Experimental Setup}
\label{sec:experiments}
We evaluate SynapticProp using the Meridian-X Core Emulator \citep{chen2023meridian}, which simulates a network of 1024 neuromorphic cores running spiking neural networks. We generate traffic patterns representing realistic workloads, including multi-modal sensor fusion tasks and deep neural network inference. We compare SynapticProp against three baseline methods:
\begin{itemize}
    \item \textbf{Dijkstra-Static}: Standard shortest-path routing based on static link weights \citep{thompson2022dynamic}.
    \item \textbf{Meridian-SPF}: A dynamically updated shortest-path-first algorithm that updates link weights periodically.
    \item \textbf{Vertex-GNN}: A full-precision graph convolutional network that does not utilize quantization or dynamic attention.
\end{itemize}

\section{Empirical Evaluation}
\label{sec:results}
We present our main empirical results in Table~\ref{tab:results}. SynapticProp outperforms all baseline models in both latency and energy consumption. Specifically, in the grid topology with $N=256$, our method achieves a routing latency of 2.34 ms, compared to 12.45 ms for Dijkstra-Static and 5.12 ms for Vertex-GNN. In the larger torus topology ($N=1024$), the advantage becomes even more pronounced. SynapticProp achieves a 6.78 ms average latency, which is a 82\% improvement over the static baseline.
Furthermore, the energy footprint of SynapticProp is extremely low. It consumes only 8.9 pJ per packet in the grid topology and 24.3 pJ per packet in the torus topology, representing a significant improvement over full-precision GNN models.

\section{Discussion}
\label{sec:discussion}
The dynamic attention mechanism of SynapticProp allows it to automatically detect routing hotspots and redirect traffic before queue buffers overflow. This leads to a much more uniform distribution of packet density across the interconnect. One potential limitation is the overhead associated with the periodic update of the node states. However, our evaluation shows that updating the states every 100 cycles provides a good balance between routing accuracy and computational cost. Additionally, the quantization to 4-bit integers does not degrade routing performance significantly, indicating the robustness of the graph representations learned by SynapticProp.

\section{Conclusion \& Future Work}
\label{sec:conclusion}
In this paper, we proposed SynapticProp, a dynamic graph neural network framework for neuromorphic routing. By leveraging localized message-passing and 4-bit quantization, our method provides real-time congestion awareness and path optimization with minimal hardware overhead. In future work, we plan to implement SynapticProp directly in hardware using Nexa-FPGA prototypes and explore reinforcement learning for online weight adaptation.
