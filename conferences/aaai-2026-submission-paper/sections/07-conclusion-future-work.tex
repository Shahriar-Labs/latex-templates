\section{Conclusion \& Future Work}
\label{sec:conclusion}
In this paper, we proposed SynapticProp, a dynamic graph neural network framework for neuromorphic routing. By leveraging localized message-passing and 4-bit quantization, our method provides real-time congestion awareness and path optimization with minimal hardware overhead. In future work, we plan to implement SynapticProp directly in hardware using Nexa-FPGA prototypes and explore reinforcement learning for online weight adaptation.
