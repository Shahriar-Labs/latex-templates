\section{Experimental Setup}
\label{sec:experiments}
We evaluate SynapticProp using the Meridian-X Core Emulator \citep{chen2023meridian}, which simulates a network of 1024 neuromorphic cores running spiking neural networks. We generate traffic patterns representing realistic workloads, including multi-modal sensor fusion tasks and deep neural network inference. We compare SynapticProp against three baseline methods:
\begin{itemize}
    \item \textbf{Dijkstra-Static}: Standard shortest-path routing based on static link weights \citep{thompson2022dynamic}.
    \item \textbf{Meridian-SPF}: A dynamically updated shortest-path-first algorithm that updates link weights periodically.
    \item \textbf{Vertex-GNN}: A full-precision graph convolutional network that does not utilize quantization or dynamic attention.
\end{itemize}
