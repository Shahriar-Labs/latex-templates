\section{Related Work}
\label{sec:related}
Routing in neuromorphic fabrics has been studied extensively. Early work utilized static routing, which lacks flexibility. Dynamic routing algorithms, such as those implemented in Nexa networks \citep{rostova2022nexa}, adapt to network state but suffer from high latency during routing decisions. Machine learning-based routing has emerged as a viable alternative \citep{nakamura2023spiking}. GNNs are uniquely suited for this task due to their ability to generalize to arbitrary topologies \citep{vance2025vertex}. However, state-of-the-art GNN models are too computationally expensive for hardware-level integration. SynapticProp addresses this gap by using a simplified message-passing framework with quantized weights.
