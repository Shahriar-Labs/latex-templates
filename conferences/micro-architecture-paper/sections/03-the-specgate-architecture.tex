\section{The SpecGate Architecture}
Figure~\ref{fig:architecture} shows where SpecGate sits relative to the rest of the memory hierarchy. On an L1D miss, the miss address is used to index the Prefetch Trigger Table (PTT), a set-associative structure that records, for each recently observed trigger address, the delta to the address that followed it and a 3-bit saturating confidence counter. If the lookup hits, the predicted address (trigger $+$ delta) is passed to the Confidence Gate before it may enter the L2 Prefetch Queue.

\subsection{Confidence Update Rule}
Each PTT entry $a$ maintains a confidence estimate $c_t(a) \in [0,1]$, initialized at $0.5$ on allocation. When a previously issued prefetch for entry $a$ resolves --- meaning the predicted line is later touched by a demand access ($\mathrm{hit}(a)=1$) or evicted unused ($\mathrm{hit}(a)=0$) --- the estimate is updated with an exponentially weighted moving average:
\begin{equation}
  c_{t+1}(a) = \alpha \, c_t(a) + (1-\alpha)\,\mathbb{1}[\mathrm{hit}(a)]
  \label{eq:confidence}
\end{equation}
where $\alpha \in (0,1)$ controls the memory of the estimator; we use $\alpha = 0.75$, which weights roughly the last four resolutions most heavily while still adapting within a few tens of misses. In hardware, Equation~\ref{eq:confidence} is implemented as a 3-bit saturating counter that increments on a hit and decrements on a miss, an integer approximation of the same exponential decay.

\subsection{Gating Decision}
A predicted address is forwarded to the L2 prefetch queue only if $c_t(a) \geq \theta$, where $\theta$ is a fixed threshold (we use $\theta = 0.5$, the counter's reset midpoint). Entries below threshold are still tracked and still updated on resolution --- they are simply not allowed to issue --- so a trigger that starts unreliable can earn its way back above threshold as the access pattern stabilizes. This asymmetry between tracking and issuing is what distinguishes SpecGate from throttling schemes~\cite{gem2019} that disable a whole prefetcher rather than individual trigger entries.
