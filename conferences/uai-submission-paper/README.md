# UAI Submission Paper LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/conferences/uai-submission-paper/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A UAI-style paper in two columns on letter paper with seven theorem environments, eleven numbered equations, Problem Setup, Stress Tests and Practical Diagnostics sections.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/conferences/uai-submission-paper/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![UAI Submission Paper preview](preview.png)

## What is in it
- Document class: `article` with `10pt, letterpaper, twocolumn`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, and 12 section files under `sections/`

## Use it online
Open **[UAI Submission Paper on LetX](https://letx.app/templates/conferences/uai-submission-paper/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/conferences/uai-submission-paper
latexmk -pdf main.tex
```
