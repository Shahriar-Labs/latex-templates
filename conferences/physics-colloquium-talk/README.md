# Astrophysics Beamer Talk LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/conferences/physics-colloquium-talk/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

Modern astrophysics Beamer presentation template, clean custom theme, title & section slides, equations, a pgfplots figure, and a results table. pdflatex-safe (no fontspec).

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/conferences/physics-colloquium-talk/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Astrophysics Beamer Talk preview](preview.png)

## What is in it
- Document class: `beamer` with `11pt, aspectratio=169`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, and 3 section files under `sections/`

## Use it online
Open **[Astrophysics Beamer Talk on LetX](https://letx.app/templates/conferences/physics-colloquium-talk/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/conferences/physics-colloquium-talk
latexmk -pdf main.tex
```
