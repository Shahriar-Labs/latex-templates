# AIAA Conference Paper LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/conferences/aiaa-conference-paper/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

AIAA technical conference paper template for aerospace & space engineering, title, author affiliations, equations, a figure, a table, and references. Ready for AIAA submissions.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/conferences/aiaa-conference-paper/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![AIAA Conference Paper preview](preview.png)

## What is in it
- Document class: `aiaa-tc`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, and 5 section files under `sections/`

## Use it online
Open **[AIAA Conference Paper on LetX](https://letx.app/templates/conferences/aiaa-conference-paper/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/conferences/aiaa-conference-paper
latexmk -pdf main.tex
```
