# ICLR 2026 Submission Paper LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/conferences/iclr-2026-submission-paper/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

An ICLR 2026-style paper in two columns on the article class in Times with pgfplots charts, not the ICLR style file, which is single-column.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/conferences/iclr-2026-submission-paper/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![ICLR 2026 Submission Paper preview](preview.png)

## What is in it
- Document class: `article` with `10pt, twocolumn`
- Compiler: pdflatex
- Files: `main.bib`, `main.tex`, `preamble.tex`, and 7 section files under `sections/`

## Use it online
Open **[ICLR 2026 Submission Paper on LetX](https://letx.app/templates/conferences/iclr-2026-submission-paper/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/conferences/iclr-2026-submission-paper
latexmk -pdf main.tex
```
