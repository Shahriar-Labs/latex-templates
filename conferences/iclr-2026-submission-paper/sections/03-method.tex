\subsection{System Model and Problem Formulation}
Consider a network of $N$ distributed client nodes, where each node $i \in \{1, \dots, N\}$ possesses a local unlabeled dataset $\mathcal{D}_i$. Let $f_{\theta_i}: \mathcal{X} \to \mathbb{R}^d$ denote the local encoder parameterized by $\theta_i$. The goal is to learn parameters $\theta_i$ such that the resulting representations are useful for downstream tasks.

Let $X \in \mathbb{R}^{N \times d}$ be the matrix of average node representations, where the $i$-th row $\mathbf{x}_i = \mathbb{E}_{x \sim \mathcal{D}_i}[f_{\theta_i}(x)]$ represents the global embedding profile of node $i$. We define the latent relationship between nodes using an adjacency matrix $A \in \mathbb{R}^{N \times N}$, where $A_{ij} \ge 0$ measures the structural similarity between client $i$ and client $j$, and $\sum_{j=1}^N A_{ij} = 1$.

We formulate the decentralized SSL task as the joint minimization of local SSL losses and global graph regularization:
\begin{equation}
  \min_{\Theta, A \in \mathcal{A}} \mathcal{L}(\Theta, A) = \sum_{i=1}^N \mathcal{L}_{\text{self}}(\theta_i) + \lambda_1 \|A\|_* + \lambda_2 \sum_{i,j=1}^N A_{ij} \|\mathbf{x}_i - \mathbf{x}_j\|_2^2
  \label{eq:objective}
\end{equation}
where $\Theta = \{\theta_1, \dots, \theta_N\}$, $\mathcal{L}_{\text{self}}(\theta_i)$ is the local self-supervised loss (e.g., InfoNCE), $\|A\|_*$ is the nuclear norm of the adjacency matrix enforcing low-rank structure, and $\lambda_1, \lambda_2 > 0$ are hyperparameters. The third term is a Laplacian regularizer that forces nodes with similar representations to be closely connected in the latent graph $A$.

\subsection{Alternating Dual-Optimization}
Since the objective in Equation~\ref{eq:objective} is non-convex and couples $\Theta$ and $A$, we employ an alternating optimization scheme.

\paragraph{Step 1: Local Representation Update ($\Theta$-step).}
With the adjacency matrix $A$ fixed, each client $i$ updates its local model parameters $\theta_i$. The gradient of the objective with respect to $\theta_i$ is given by:
\begin{equation}
  \nabla_{\theta_i} \mathcal{L} = \nabla_{\theta_i} \mathcal{L}_{\text{self}}(\theta_i) + 2 \lambda_2 \sum_{j=1}^N A_{ij} (\mathbf{x}_i - \mathbf{x}_j) \nabla_{\theta_i} \mathbf{x}_i
\end{equation}
Each client estimates this gradient locally by sharing representation vectors $\mathbf{x}_j$ with its neighbors as determined by the non-zero entries of $A_{i\cdot}$.

\paragraph{Step 2: Latent Graph Refinement ($A$-step).}
With the representations $\mathbf{x}_i$ fixed, we optimize the global latent graph structure $A$. Let $D \in \mathbb{R}^{N \times N}$ be the distance matrix where $D_{ij} = \|\mathbf{x}_i - \mathbf{x}_j\|_2^2$. The optimization problem reduces to:
\begin{equation}
  \min_{A \in \mathcal{A}} \lambda_1 \|A\|_* + \lambda_2 \text{Tr}(A^T D)
\end{equation}
This step is solved periodically at a global consensus level. To preserve privacy and reduce communication, clients only transmit low-dimensional representations $\mathbf{x}_i$ to a distributed consensus pool, rather than raw model weights $\theta_i$ or dataset samples $\mathcal{D}_i$.
