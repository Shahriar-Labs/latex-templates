# Oxford Bioinformatics Journal Template LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/journal-articles/oxford-bioinformatics-journal-template/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

An Oxford Bioinformatics-style two-sided article with Materials and Methods, Results, funding, conflict of interest and data availability statements, on the article class.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/journal-articles/oxford-bioinformatics-journal-template/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Oxford Bioinformatics Journal Template preview](preview.png)

## What is in it
- Document class: `article` with `10pt, twoside`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, `references.bib`, and 6 section files under `sections/`

## Use it online
Open **[Oxford Bioinformatics Journal Template on LetX](https://letx.app/templates/journal-articles/oxford-bioinformatics-journal-template/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/journal-articles/oxford-bioinformatics-journal-template
latexmk -pdf main.tex
```
