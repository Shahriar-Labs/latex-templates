## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/oxford-bioinformatics-journal-template.git
cd oxford-bioinformatics-journal-template
latexmk -pdf main.tex
```
Compiler: **pdflatex** (see `metadata.json`).
