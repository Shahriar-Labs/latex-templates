## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/meta-analysis-report.git
cd meta-analysis-report
latexmk -pdf main.tex
```
Compiler: **pdflatex** (see `metadata.json`).
