# AASTeX Astronomy Paper LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/journal-articles/aastex-apj-paper/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

AASTeX 6.3.1 astronomy paper template (ApJ / AJ / AAS journals), two-column, author affiliations, a deluxetable, equations, a figure, and a bibliography. For astrophysics manuscripts.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/journal-articles/aastex-apj-paper/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![AASTeX Astronomy Paper preview](preview.png)

## What is in it
- Document class: `aastex631` with `twocolumn`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, and 8 section files under `sections/`

## Use it online
Open **[AASTeX Astronomy Paper on LetX](https://letx.app/templates/journal-articles/aastex-apj-paper/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/journal-articles/aastex-apj-paper
latexmk -pdf main.tex
```
