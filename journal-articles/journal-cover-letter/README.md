# Journal Cover Letter LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/journal-articles/journal-cover-letter/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

Academic journal cover letter LaTeX template, author letterhead with ORCID, editor address block, manuscript metadata, and a structured body covering significance, scope fit, originality and no-conflict statements.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/journal-articles/journal-cover-letter/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Journal Cover Letter preview](preview.png)

## What is in it
- Document class: `article` with `11pt, a4paper`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Journal Cover Letter on LetX](https://letx.app/templates/journal-articles/journal-cover-letter/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/journal-articles/journal-cover-letter
latexmk -pdf main.tex
```
