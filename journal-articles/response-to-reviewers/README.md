# Response to Reviewers LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/journal-articles/response-to-reviewers/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

Journal response-to-reviewers LaTeX template, color-coded reviewer comment cards, green author-response bars, and shaded revised-text quotes. Reusable structure for any peer-review rebuttal.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/journal-articles/response-to-reviewers/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Response to Reviewers preview](preview.png)

## What is in it
- Document class: `article` with `11pt, a4paper`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Response to Reviewers on LetX](https://letx.app/templates/journal-articles/response-to-reviewers/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/journal-articles/response-to-reviewers
latexmk -pdf main.tex
```
