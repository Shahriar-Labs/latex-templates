\section{Methods}
\label{sec:methods}

\subsection{Full-spectrum fitting}

We fit each annular spectrum using the penalised pixel-fitting code
\textsc{ppxf} \citep{Cappellari2017} with the MILES extended stellar
library (E-MILES; \citealt{Vazdekis2016}) at solar-scaled and
$\alpha$-enhanced compositions.
The templates span ages $0.1$--$14\,\mathrm{Gyr}$ and metallicities
$-1.5 \le \fe \le +0.4$ on a \citet{Kroupa2001} IMF.

Emission lines (H$\beta$, [O\,\textsc{iii}], [N\,\textsc{ii}], H$\alpha$)
are fitted simultaneously as Gaussians with the stellar continuum.
The best-fit stellar-population parameters---mean light-weighted age,
$\fe$, and $\afe$---are extracted from the regularised weight
distribution.

\subsection{Gradient measurement}

Each stellar-population parameter $Q$ is characterised by a linear
gradient in units of dex per effective radius:
\begin{equation}
  \nabla Q \;=\;
  \frac{\mathrm{d}\,Q}{\mathrm{d}\,(r/\re)} \;,
  \label{eq:gradient}
\end{equation}
measured via an error-weighted least-squares fit to the five radial
bin values.
Uncertainties on $\nabla Q$ are obtained from 200 Monte Carlo
realisations in which the input spectra are perturbed by Gaussian
noise at the measured S/N.
