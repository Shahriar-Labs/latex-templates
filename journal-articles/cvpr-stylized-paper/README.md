## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/cvpr-stylized-paper.git
cd cvpr-stylized-paper
latexmk -pdf main.tex
```
Compiler: **pdflatex** (see `metadata.json`).
