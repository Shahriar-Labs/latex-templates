# CVPR Paper (Stylized) LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/journal-articles/cvpr-stylized-paper/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A CVPR-flavoured paper in two columns set in Lato on a tinted page, with algorithm2e pseudocode, six theorem environments and a Theoretical Analysis section.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/journal-articles/cvpr-stylized-paper/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![CVPR Paper (Stylized) preview](preview.png)

## What is in it
- Document class: `article` with `10pt, twocolumn`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, and 6 section files under `sections/`

## Use it online
Open **[CVPR Paper (Stylized) on LetX](https://letx.app/templates/journal-articles/cvpr-stylized-paper/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/journal-articles/cvpr-stylized-paper
latexmk -pdf main.tex
```
