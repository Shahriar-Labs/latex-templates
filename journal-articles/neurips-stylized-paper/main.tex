    {\small\bfseries\color{accent} Abstract}
  \end{center}
  \begin{small}
  \noindent
  Transformer architectures struggle to efficiently aggregate long-range context
  because self-attention scales quadratically with sequence length. We introduce
  \modelname{}, a lightweight module that learns a sparse, dynamic routing of
  contextual information across arbitrary sequence lengths. \modelname{} inserts
  a learnable \emph{context gateway} between every pair of encoder layers,
  gating each token's receptive field via a differentiable top-$k$ selection
  mechanism. On eight long-document benchmarks---including \textsc{ScrollS},
  \textsc{QuALITY}, and \textsc{QASPER}---\modelname{} improves over the
  baseline Longformer by \textbf{3.1 F\textsubscript{1}} points on average while
  reducing FLOPs by 18\%. We release code and pretrained checkpoints at
  \url{https://github.com/contextflow/contextflow}.
  \end{small}
