# REVTeX 4.2 Physics Paper LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/journal-articles/revtex-aps-paper/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

REVTeX 4.2 physics paper template (APS / Physical Review), two-column, author affiliations, displayed equations, a pgfplots figure, a results table, and a bibliography. Compile-tested.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/journal-articles/revtex-aps-paper/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![REVTeX 4.2 Physics Paper preview](preview.png)

## What is in it
- Document class: `revtex4-2` with `aps, prd, twocolumn, superscriptaddress, nofootinbib`
- Compiler: pdflatex
- Files: `main.tex`, `mainNotes.bib`, `preamble.tex`, and 5 section files under `sections/`

## Use it online
Open **[REVTeX 4.2 Physics Paper on LetX](https://letx.app/templates/journal-articles/revtex-aps-paper/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/journal-articles/revtex-aps-paper
latexmk -pdf main.tex
```
