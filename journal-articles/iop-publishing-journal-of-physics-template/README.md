# IOP Publishing Journal of Physics Template LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/journal-articles/iop-publishing-journal-of-physics-template/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A Journal of Physics-style article on A4 with biblatex, a theoretical framework, experimental methods and pgfplots results, on the article class rather than IOP's own.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/journal-articles/iop-publishing-journal-of-physics-template/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![IOP Publishing Journal of Physics Template preview](preview.png)

## What is in it
- Document class: `article` with `11pt, a4paper`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, `references.bib`, and 8 section files under `sections/`

## Use it online
Open **[IOP Publishing Journal of Physics Template on LetX](https://letx.app/templates/journal-articles/iop-publishing-journal-of-physics-template/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/journal-articles/iop-publishing-journal-of-physics-template
latexmk -pdf main.tex
```
