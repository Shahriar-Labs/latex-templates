## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/iop-publishing-journal-of-physics-template.git
cd iop-publishing-journal-of-physics-template
latexmk -pdf main.tex
```
Compiler: **pdflatex** (see `metadata.json`).
