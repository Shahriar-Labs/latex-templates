# Modern Business Letterhead LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/formal-letters/modern-business-letterhead/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

Modern corporate letterhead + letter LaTeX template, logo placeholder, company name & contact header with an accent side bar, date, recipient, subject line, business body and a registration footer.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/formal-letters/modern-business-letterhead/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Modern Business Letterhead preview](preview.png)

## What is in it
- Document class: `article` with `10.5pt, a4paper`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Modern Business Letterhead on LetX](https://letx.app/templates/formal-letters/modern-business-letterhead/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/formal-letters/modern-business-letterhead
latexmk -pdf main.tex
```
