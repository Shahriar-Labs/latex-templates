# Law Firm Letterhead LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/formal-letters/law-firm-letterhead/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

Formal law firm letterhead LaTeX template, firm name in a classic serif, a right-aligned attorney roster, office contact row, delivery line, bold Re: matter line, formal legal body and confidentiality footer.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/formal-letters/law-firm-letterhead/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Law Firm Letterhead preview](preview.png)

## What is in it
- Document class: `article` with `11pt, letterpaper`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Law Firm Letterhead on LetX](https://letx.app/templates/formal-letters/law-firm-letterhead/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/formal-letters/law-firm-letterhead
latexmk -pdf main.tex
```
