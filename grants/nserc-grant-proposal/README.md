# NSERC Grant Proposal LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/grants/nserc-grant-proposal/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

An NSERC Discovery-style proposal on letter paper with long-term objectives, recent progress, the proposed program, training of highly qualified personnel and other funding.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/grants/nserc-grant-proposal/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![NSERC Grant Proposal preview](preview.png)

## What is in it
- Document class: `article` with `12pt, letterpaper`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, and 6 section files under `sections/`

## Use it online
Open **[NSERC Grant Proposal on LetX](https://letx.app/templates/grants/nserc-grant-proposal/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/grants/nserc-grant-proposal
latexmk -pdf main.tex
```
