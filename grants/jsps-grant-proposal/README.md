# JSPS Grant Proposal LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/grants/jsps-grant-proposal/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A JSPS-style grant proposal on A4 using CJKutf8 for Japanese names, with applicant information, research background, methods, and a work plan and timeline.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/grants/jsps-grant-proposal/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![JSPS Grant Proposal preview](preview.png)

## What is in it
- Document class: `article` with `11pt, a4paper`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[JSPS Grant Proposal on LetX](https://letx.app/templates/grants/jsps-grant-proposal/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/grants/jsps-grant-proposal
latexmk -pdf main.tex
```
