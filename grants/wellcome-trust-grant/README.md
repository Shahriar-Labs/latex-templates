# Wellcome Trust Grant LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/grants/wellcome-trust-grant/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A Wellcome-style grant application on A4 in Charter with a lay summary, scientific vision and aims, research design, environment, budget, and outputs and data management.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/grants/wellcome-trust-grant/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Wellcome Trust Grant preview](preview.png)

## What is in it
- Document class: `article` with `10pt, a4paper`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, and 6 section files under `sections/`

## Use it online
Open **[Wellcome Trust Grant on LetX](https://letx.app/templates/grants/wellcome-trust-grant/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/grants/wellcome-trust-grant
latexmk -pdf main.tex
```
