# NIH Grant Proposal LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/grants/nih-grant-proposal/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

NIH R01-style grant proposal LaTeX template, header block plus a boxed Specific Aims page and a Research Strategy (Significance, Innovation, Approach with Aims). Realistic biomedical sample content.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/grants/nih-grant-proposal/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![NIH Grant Proposal preview](preview.png)

## What is in it
- Document class: `article` with `11pt`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[NIH Grant Proposal on LetX](https://letx.app/templates/grants/nih-grant-proposal/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/grants/nih-grant-proposal
latexmk -pdf main.tex
```
