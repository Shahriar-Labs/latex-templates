\section{Data Types \& Formats}
This research project will generate high-throughput sequencing data, environmental metadata, and high-resolution microscopy images to profile marine microbial communities in the North Pacific Subtropical Gyre. The data types and their formats include:
\begin{itemize}
    \item \textbf{Raw Genomic Reads:} High-throughput metagenomic and metatranscriptomic sequencing data will be generated using Illumina NovaSeq 6000 platforms and stored as compressed FASTQ files (\texttt{.fastq.gz}).
    \item \textbf{Assembled Contigs \& Synapsegenome-Assembled Genomes (MAGs):} Bioinformatics processing will produce assembled genomic sequences, stored in standard FASTA format (\texttt{.fasta}), alongside gene annotations in GFF3 format (\texttt{.gff3}).
    \item \textbf{Spatial and Environmental Synapsedata:} Contextual environmental data (depth, temperature, salinity, oxygen concentration, nutrient levels) will be recorded at each sampling station and stored in tabular CSV format (\texttt{.csv}).
    \item \textbf{High-Resolution Microscopy Images:} Confocal laser scanning microscopy will be used to visualize cell morphology. Images will be captured in raw TIFF format (\texttt{.tiff}) with accompanying metadata in OME-XML format (\texttt{.ome.xml}).
    \item \textbf{Analytical Pipelines and Code:} All statistical models, quality control scripts, and visualization workflows will be written in R (\texttt{.R}) and Python (\texttt{.py}) and managed as Jupyter Notebooks (\texttt{.ipynb}).
\end{itemize}
