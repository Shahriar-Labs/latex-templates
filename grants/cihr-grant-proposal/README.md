# CIHR Grant Proposal LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/grants/cihr-grant-proposal/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A CIHR-style health research proposal with a lay summary, specific aims, preliminary data, research strategy, timeline, budget justification, and an EDI section.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/grants/cihr-grant-proposal/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![CIHR Grant Proposal preview](preview.png)

## What is in it
- Document class: `article` with `11pt, letterpaper`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, and 11 section files under `sections/`

## Use it online
Open **[CIHR Grant Proposal on LetX](https://letx.app/templates/grants/cihr-grant-proposal/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/grants/cihr-grant-proposal
latexmk -pdf main.tex
```
