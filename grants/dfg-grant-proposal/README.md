# DFG Grant Proposal LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/grants/dfg-grant-proposal/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A DFG-style research proposal on A4 with state of the art, objectives and work programme, requested funding in euros, a data management plan, and equal opportunity.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/grants/dfg-grant-proposal/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![DFG Grant Proposal preview](preview.png)

## What is in it
- Document class: `article` with `11pt, a4paper`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, and 7 section files under `sections/`

## Use it online
Open **[DFG Grant Proposal on LetX](https://letx.app/templates/grants/dfg-grant-proposal/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/grants/dfg-grant-proposal
latexmk -pdf main.tex
```
