\section{Data Management Plan}
\label{sec:data}

In accordance with DFG guidelines on the handling of research data (DFG
Leitlinien 2022), all raw measurement data (estimated volume: $\sim$3.2~TB over the
project lifetime) will be stored on the Nexa University research-data infrastructure,
backed up nightly to georedundant Synapse Cloud Storage. Metadata will be described
using the \texttt{NeXus} ontology and deposited in the Zenodo repository (CERN)
with a DOI assigned at each major milestone. Code repositories will be mirrored on
the DFG-endorsed Forschungsdaten.info platform. Raw sensor data will be retained for
ten years post-project in accordance with the DFG subject-specific recommendation for
experimental physics.
