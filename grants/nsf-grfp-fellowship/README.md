# NSF GRFP Fellowship Statements LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/grants/nsf-grfp-fellowship/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

NSF Graduate Research Fellowship (GRFP) statements LaTeX template, Personal/Background and Graduate Research Plan statements with Intellectual Merit and Broader Impacts callouts.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/grants/nsf-grfp-fellowship/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![NSF GRFP Fellowship Statements preview](preview.png)

## What is in it
- Document class: `article` with `11pt, letterpaper`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, and 8 section files under `sections/`

## Use it online
Open **[NSF GRFP Fellowship Statements on LetX](https://letx.app/templates/grants/nsf-grfp-fellowship/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/grants/nsf-grfp-fellowship
latexmk -pdf main.tex
```
