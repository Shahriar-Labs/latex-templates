# NASA ROSES Grant Proposal LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/grants/nasa-roses-proposal/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

NASA ROSES / NSPIRES research grant proposal template, cover block with program element, technical merit, work plan, budget & timeline tables, and references. For NASA astrophysics proposals.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/grants/nasa-roses-proposal/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![NASA ROSES Grant Proposal preview](preview.png)

## What is in it
- Document class: `article` with `11pt`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, and 5 section files under `sections/`

## Use it online
Open **[NASA ROSES Grant Proposal on LetX](https://letx.app/templates/grants/nasa-roses-proposal/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/grants/nasa-roses-proposal
latexmk -pdf main.tex
```
