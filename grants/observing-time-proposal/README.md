# Telescope Observing Proposal LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/grants/observing-time-proposal/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

Telescope observing-time proposal template (Gemini / ESO / NOIRLab TAC style), styled proposal header, scientific & technical justification, and a professional target-list table.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/grants/observing-time-proposal/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Telescope Observing Proposal preview](preview.png)

## What is in it
- Document class: `article` with `11pt`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, and 3 section files under `sections/`

## Use it online
Open **[Telescope Observing Proposal on LetX](https://letx.app/templates/grants/observing-time-proposal/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/grants/observing-time-proposal
latexmk -pdf main.tex
```
