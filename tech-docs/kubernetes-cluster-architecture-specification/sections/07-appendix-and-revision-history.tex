\subsection{Glossary}
\begin{itemize}[itemsep=2pt]
  \item \textbf{CNI} --- Container Network Interface; the plugin responsible for pod networking. This cluster uses Cilium.
  \item \textbf{CSI} --- Container Storage Interface; the plugin responsible for provisioning persistent volumes. This cluster uses the Meridian Block Store CSI driver.
  \item \textbf{HPA / VPA} --- Horizontal / Vertical Pod Autoscaler; controllers that resize a workload's replica count or per-pod resource requests based on observed load.
  \item \textbf{PSA} --- Pod Security Admission; the built-in Kubernetes controller that enforces the \code{restricted}, \code{baseline}, and \code{privileged} standards described in Section 6.1.
  \item \textbf{RPO / RTO} --- Recovery Point / Time Objective; the maximum tolerable data loss and downtime, respectively, for a service during a disaster recovery event.
\end{itemize}
