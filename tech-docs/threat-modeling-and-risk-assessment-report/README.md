# Threat Modeling and Risk Assessment Report LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/tech-docs/threat-modeling-and-risk-assessment-report/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A threat modeling and risk assessment report in Lato with an asset inventory, threat actor profiles, STRIDE analysis, a risk matrix, findings with mitigations and residual risk.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/tech-docs/threat-modeling-and-risk-assessment-report/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Threat Modeling and Risk Assessment Report preview](preview.png)

## What is in it
- Document class: `article` with `11pt, a4paper`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, `references.bib`, and 8 section files under `sections/`

## Use it online
Open **[Threat Modeling and Risk Assessment Report on LetX](https://letx.app/templates/tech-docs/threat-modeling-and-risk-assessment-report/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/tech-docs/threat-modeling-and-risk-assessment-report
latexmk -pdf main.tex
```
