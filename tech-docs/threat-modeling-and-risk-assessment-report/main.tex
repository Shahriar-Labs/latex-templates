\begin{specbox}{Document Purpose}
This report presents the STRIDE-based threat model and qualitative risk assessment for \textbf{Nexa Ledger}, the multi-tenant payment reconciliation and ledger API platform operated by Nexa Systems. It enumerates in-scope assets and trust boundaries, profiles credible threat actors, catalogues threats per system component, scores each threat on a likelihood/impact matrix, and records the mitigations and residual risk carried forward. It is the authoritative reference for the Q3 2026 security architecture review and for any engineering change that touches authentication, the reconciliation engine, or the public webhook surface.
\end{specbox}
