The key words ``\must'', ``\mustnot'', ``\should'', ``\shouldnot'', and ``\may''
in this document indicate requirement levels. Requirements are normative only
when these words appear in uppercase bold type. Examples and explanatory notes
are informative unless explicitly identified as normative.

\subsection*{Change policy}

The major protocol version changes when wire compatibility or required security
semantics change. A minor document revision may clarify behavior or add optional
capabilities without invalidating a conforming version-1 implementation. New
fields are additive: receivers \must ignore unknown non-critical fields and
\must reject an unknown field listed in the manifest's \field{critical} array.
