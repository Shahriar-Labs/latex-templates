\section{Implementation notes}

These notes are informative:

\begin{itemize}
  \item Keep protocol parsing and signature verification in a small, fuzzed module.
  \item Stream hashing directly from network to staging storage to minimize RAM.
  \item Separate ``downloaded'', ``verified'', ``staged'', and ``confirmed'' in code
        and telemetry; collapsing them creates unsafe recovery behavior.
  \item Test with real flash fault modes, including torn writes and bit errors, not
        only process termination in a simulator.
  \item Treat a boot attempt counter as security-critical state and decrement it
        before launching an unconfirmed image.
  \item Rate-limit discovery after reboot so a faulty fleet does not overwhelm the
        service while still preserving prompt recovery reporting.
\end{itemize}
