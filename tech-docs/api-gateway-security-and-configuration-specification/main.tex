\begin{abstract}
This document defines the production security standards, traffic routing logic, and rate-limiting policies for the \textbf{Vertex API Gateway} deployed across the \textbf{Nimbus Corp} enterprise cloud infrastructure. It details configuration specifications for token authentication, path authorization, Cross-Origin Resource Sharing (CORS) security profiles, and compliance logging schemas. These settings are enforced globally to prevent unauthorized data access, mitigate distributed denial-of-service (DDoS) attempts, and maintain regulatory compliance with PCI-DSS v4.0 and SOC 2 Type II audits.
\end{abstract}
