\section{Escalation Ladder \& Contacts}
\label{sec:escalation}
When an incident cannot be resolved within the target restore time (TTR) or requires additional authorization, escalate immediately using the ladder below.

\begin{infobox}{Incident Close-Out Procedure}
    Once the system is restored to green status, the Level 1 SRE is responsible for:
    \begin{enumerate}
        \item Closing the active incident ticket on PagerDuty.
        \item Running the automated diagnostic capture script and posting the summary to the incident channel.
        \item Scheduling a post-mortem review within 24 hours of the incident.
    \end{enumerate}
\end{infobox}
