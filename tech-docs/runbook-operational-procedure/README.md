## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/runbook-operational-procedure.git
cd runbook-operational-procedure
latexmk -pdf main.tex
```
Compiler: **pdflatex** (see `metadata.json`).
