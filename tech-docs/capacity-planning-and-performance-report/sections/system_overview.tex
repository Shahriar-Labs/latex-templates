\section{System Overview \& Architecture}
The system under evaluation consists of the core components of Nexa's cloud infrastructure: the Nimbus API Gateway, the Synapse Caching Layer, and the Vertex Database Cluster. Together, they handle the request-response lifecycle of all Meridian applications. Figure~\ref{fig:architecture} illustrates the layout and flow of data between these components.

\subsection{Resource Configuration}
The current hardware configurations for the production instances are detailed below:
\begin{itemize}[noitemsep]
  \item \textbf{Nimbus API Gateway:} 4$\times$ standard VMs (4 vCPUs, 8\,GB RAM) configured behind an application load balancer.
  \item \textbf{Synapse Caching Layer:} 3$\times$ cache nodes (2 vCPUs, 16\,GB RAM) using Redis cluster sharding.
  \item \textbf{Vertex Database Cluster:} 3$\times$ high-compute VMs (8 vCPUs, 32\,GB RAM, 500\,GB SSD storage with 3,000 baseline IOPS).
\end{itemize}
