## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/capacity-planning-and-performance-report.git
cd capacity-planning-and-performance-report
latexmk -pdf main.tex
```
Compiler: **pdflatex** (see `metadata.json`).
