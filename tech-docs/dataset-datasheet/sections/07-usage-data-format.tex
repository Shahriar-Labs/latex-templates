\section{Usage \& Data Format}

The dataset is distributed as compressed JSON Lines (\texttt{.jsonl.gz}) with one article
per line. Each record follows this schema:

\vspace{4pt}
\begin{lstlisting}[
  language=Python,
  frame=single,
  backgroundcolor=\color{softgray},
  rulecolor=\color{border},
  aboveskip=4pt,
  belowskip=4pt,
]
{
  "id": "en-0047129",
  "language": "en",
  "category": "technology",
  "title": "New Chip Architecture Cuts Data Center Power by 40%",
  "text": "Researchers at MIT have demonstrated a novel...",
  "raw_text": "Researchers at MIT have demonstrated a novel...",
  "source_id": "techcrunch",
  "url": "https://techcrunch.com/2023/03/15/...",
  "date": "2023-03-15",
  "token_count": 412,
  "split": "train"
}
\end{lstlisting}

\smallskip
\textbf{Loading via Hugging Face \texttt{datasets}:}

\vspace{4pt}
\begin{lstlisting}[
  language=Python,
  frame=single,
  backgroundcolor=\color{softgray},
  rulecolor=\color{border},
  aboveskip=4pt,
  belowskip=4pt,
]
from datasets import load_dataset

dataset = load_dataset("gnlpi/multilingua-100k")
print(dataset["train"][0]["title"])
# "New Chip Architecture Cuts Data Center Power by 40%"
\end{lstlisting}
