# Dataset Datasheet LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/tech-docs/dataset-datasheet/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A dataset datasheet in Source Sans Pro covering motivation, collection protocol, preprocessing, demographic and linguistic breakdown, recommended tasks, limitations and licence.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/tech-docs/dataset-datasheet/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Dataset Datasheet preview](preview.png)

## What is in it
- Document class: `article` with `11pt, a4paper`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, and 9 section files under `sections/`

## Use it online
Open **[Dataset Datasheet on LetX](https://letx.app/templates/tech-docs/dataset-datasheet/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/tech-docs/dataset-datasheet
latexmk -pdf main.tex
```
