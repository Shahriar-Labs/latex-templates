# Software Release Notes LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/tech-docs/release-notes-template/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

Software release notes on A4 with new features, resolved issues, deprecations and removals, known issues, and upgrade instructions.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/tech-docs/release-notes-template/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Software Release Notes preview](preview.png)

## What is in it
- Document class: `article` with `11pt, a4paper`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, and 5 section files under `sections/`

## Use it online
Open **[Software Release Notes on LetX](https://letx.app/templates/tech-docs/release-notes-template/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/tech-docs/release-notes-template
latexmk -pdf main.tex
```
