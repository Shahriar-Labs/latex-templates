# API Documentation (Swagger Style) LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/tech-docs/api-documentation-swagger/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

Swagger-style API documentation with authentication, rate limiting and errors, endpoint groups for files and folders, webhooks, pagination and a changelog, in eleven code listings.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/tech-docs/api-documentation-swagger/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![API Documentation (Swagger Style) preview](preview.png)

## What is in it
- Document class: `article` with `10pt`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, and 8 section files under `sections/`

## Use it online
Open **[API Documentation (Swagger Style) on LetX](https://letx.app/templates/tech-docs/api-documentation-swagger/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/tech-docs/api-documentation-swagger
latexmk -pdf main.tex
```
