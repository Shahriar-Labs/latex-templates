\section{Fairness Analysis}

We assess performance parity across demographic axes using the
\textbf{BBQ} (Bias Benchmark for QA) and \textbf{WinoBias} datasets.
The charts below report accuracy disaggregated by subgroup.

\textbf{Key observations.}
Performance gaps are most pronounced along the Religion ($\Delta = 11.4$\,pp,
Muslim vs.\ Christian) and Socio-economic ($\Delta = 10.5$\,pp, Low vs.\ High)
axes. We recommend additional de-biasing fine-tuning and targeted evaluation
before deploying in contexts where these disparities could cause harm.
