# Database Schema Documentation LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/tech-docs/database-schema-doc/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

Compact database schema documentation in 8pt type (extarticle) with an overview, table definitions, enumerated types and foreign keys, and representative queries.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/tech-docs/database-schema-doc/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Database Schema Documentation preview](preview.png)

## What is in it
- Document class: `extarticle` with `8pt, a4paper`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, and 4 section files under `sections/`

## Use it online
Open **[Database Schema Documentation on LetX](https://letx.app/templates/tech-docs/database-schema-doc/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/tech-docs/database-schema-doc
latexmk -pdf main.tex
```
