# Disaster Recovery Plan LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/tech-docs/disaster-recovery-plan/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A disaster recovery plan on A4 with version history, recovery objectives, the recovery team structure, recovery procedures, a communication plan, and testing and maintenance.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/tech-docs/disaster-recovery-plan/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Disaster Recovery Plan preview](preview.png)

## What is in it
- Document class: `article` with `a4paper, 11pt`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, and 7 section files under `sections/`

## Use it online
Open **[Disaster Recovery Plan on LetX](https://letx.app/templates/tech-docs/disaster-recovery-plan/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/tech-docs/disaster-recovery-plan
latexmk -pdf main.tex
```
