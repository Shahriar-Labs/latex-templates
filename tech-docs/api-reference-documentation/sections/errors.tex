\section{Error Handling}
\label{sec:errors}
The Vertex Core API returns standard HTTP response codes to indicate the success or failure of an API request.
In general:
\begin{itemize}
  \item Codes in the \code{2xx} range indicate success.
  \item Codes in the \code{4xx} range indicate an error that failed because of the information provided (e.g., a missing parameter, authentication failure, etc.).
  \item Codes in the \code{5xx} range indicate an error on the Vertex server infrastructure.
\end{itemize}

\subsection{Error Response Body}
When a request fails, additional diagnostics are returned in the response body as a JSON object containing the error details:
\begin{lstlisting}[language=json]
{
  "error": {
    "code": "INVALID_PARAMETER",
    "message": "The request body parameter 'sync_mode' is invalid.",
    "doc_url": "https://docs.vertex.meridian.net/errors/INVALID_PARAMETER",
    "details": [
      {
        "field": "sync_mode",
        "issue": "Must be one of: snapshot, realtime, differential"
      }
    ]
  }
}
\end{lstlisting}
