\section{Results: \(\Delta\)-Metric Waterfall}
% ═══════════════════════════════════════════════════════════════

The waterfall chart below shows how \metric\ degrades as components are sequentially
removed. Each bar represents the \emph{incremental} increase in \metric\ (\(\Delta\))
caused by removing that component, stacked cumulatively from the full-model baseline
(\(0.312\)) to the fully ablated model (\(0.478\)).
