\subsection{Step-by-Step Test Execution}
Verification engineers must perform the testing protocol in sequence. The general testing steps are:
\begin{enumerate}
    \item \textbf{Power-up Sequence Validation}: Ensure that the programmable power supply triggers voltage rails in order ($3.3\text{V} \rightarrow 1.8\text{V} \rightarrow 1.2\text{V} \rightarrow 0.9\text{V}$). Check current draw limits to confirm no short circuits.
    \item \textbf{Clock Initialization Verification}: Monitor the $25\text{\,MHz}$ oscillator. Check phase lock loop (PLL) registers to ensure core clock reaches $1.2\text{\,GHz}$ without frequency jitter.
    \item \textbf{Boundary Scan Validation}: Verify logic pathway continuity using JTAG boundary scan commands.
    \item \textbf{High-speed Interface Validation}: Execute high-speed data bursts on DDR and PCIe channels. Log error rates and eye diagrams on the oscilloscope.
\end{enumerate}

\subsection{Pass/Fail Criteria}
The verification tests are marked pass or fail based on strict technical thresholds:
\begin{itemize}
    \item \textbf{Signal Integrity}: Rise/fall times must be $\le 120\text{\,ps}$ for PCIe lanes, and eye-opening width must exceed $70\%$ of unit interval (UI).
    \item \textbf{JTAG Operation}: TAP controller must return IDCODE matching the Nimbus-5 signature register \texttt{0x0A5C2043}.
    \item \textbf{Bit Error Rate (BER)}: PCIe link must run error-free for a minimum of $10^9$ bits under thermal stress test.
\end{itemize}

\begin{warningbox}{Interface Failure Protocol}
If the PCIe link fails to achieve L0 state after five subsequent re-train loops, power down the DUT immediately. Check if pin probes on TX/RX lines are introducing capacitive load distortion ($\ge 1.5\text{\,pF}$).
\end{warningbox}
