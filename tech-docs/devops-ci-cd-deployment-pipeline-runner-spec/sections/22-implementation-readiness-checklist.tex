\section{Implementation readiness checklist}

\begin{itemize}[label=$\square$]
  \item Product owner, platform owner, security owner, SRE owner, and support rotation are named.
  \item API, event, pipeline schema, runner protocol, and deployment adapter contracts are versioned.
  \item Threat model, data classification, privacy review, and penetration-test scope are approved.
  \item State-machine and lease-fencing proofs are represented in executable tests.
  \item Runner base image, attestation, sandbox, egress, teardown, and quarantine controls are verified.
  \item Workload identity trust rules and environment approval separation are tested end to end.
  \item Logs, artifacts, caches, provenance, SBOM, retention, and legal-hold workflows are operational.
  \item SLOs, dashboards, paging rules, capacity forecasts, and cost allocation are active.
  \item Backup restoration, zone failure, region fencing, and deployment reconciliation are exercised.
  \item Pilot repositories meet exit criteria and retain a tested rollback path.
  \item All acceptance criteria have linked, immutable evidence and accountable sign-off.
\end{itemize}
