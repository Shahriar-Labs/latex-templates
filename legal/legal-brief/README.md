# Legal Brief (Litigation) LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/legal/legal-brief/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A litigation brief on letter paper in Palatino, with argument headings in the style of a securities fraud case covering the elements of a claim, loss causation and control-person liability.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/legal/legal-brief/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Legal Brief (Litigation) preview](preview.png)

## What is in it
- Document class: `article` with `12pt, letterpaper`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, and 3 section files under `sections/`

## Use it online
Open **[Legal Brief (Litigation) on LetX](https://letx.app/templates/legal/legal-brief/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/legal/legal-brief
latexmk -pdf main.tex
```
