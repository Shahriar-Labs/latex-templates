## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/cease-and-desist-letter.git
cd cease-and-desist-letter
latexmk -pdf main.tex
```
Compiler: **pdflatex** (see `metadata.json`).
