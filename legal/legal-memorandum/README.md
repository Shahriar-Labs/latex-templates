# Legal Memorandum LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/legal/legal-memorandum/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A legal memorandum on letter paper in TeX Gyre Pagella, in six parts: question presented, short answer, statement of facts, analysis, recommendations and conclusion.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/legal/legal-memorandum/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Legal Memorandum preview](preview.png)

## What is in it
- Document class: `article` with `11pt, letterpaper`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, and 6 section files under `sections/`

## Use it online
Open **[Legal Memorandum on LetX](https://letx.app/templates/legal/legal-memorandum/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/legal/legal-memorandum
latexmk -pdf main.tex
```
