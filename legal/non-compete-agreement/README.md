# Non-Compete Agreement LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/legal/non-compete-agreement/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A non-compete agreement on A4 in Charter with recitals and defined terms for confidential information, competing business, restricted period and restricted territory.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/legal/non-compete-agreement/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Non-Compete Agreement preview](preview.png)

## What is in it
- Document class: `article` with `11pt, a4paper`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Non-Compete Agreement on LetX](https://letx.app/templates/legal/non-compete-agreement/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/legal/non-compete-agreement
latexmk -pdf main.tex
```
