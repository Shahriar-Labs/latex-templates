# Commercial Lease Agreement LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/legal/lease-agreement-commercial/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A commercial lease agreement on letter paper in Charter covering premises and term, rent and deposit, use, maintenance, insurance, default and remedies, and an exhibit.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/legal/lease-agreement-commercial/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Commercial Lease Agreement preview](preview.png)

## What is in it
- Document class: `article` with `11pt, letterpaper`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, and 9 section files under `sections/`

## Use it online
Open **[Commercial Lease Agreement on LetX](https://letx.app/templates/legal/lease-agreement-commercial/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/legal/lease-agreement-commercial
latexmk -pdf main.tex
```
