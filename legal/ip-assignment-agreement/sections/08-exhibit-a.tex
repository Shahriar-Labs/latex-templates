\vspace{1.5em}

This Exhibit A forms an integral part of the Intellectual Property Assignment Agreement dated July 15, 2026, by and between Sarah Jenkins and Nexa Technologies, Inc.

\vspace{1.5em}

\noindent\textbf{1. DESCRIPTION OF TECHNOLOGY}

The Assigned IP consists of the ``Synapse NLP Engine v2.0'', which includes all software, codebases, algorithms, schemas, models, datasets, and documentation developed by Sarah Jenkins. This includes the natural language processing library that supports zero-shot categorization, sentiment analysis, entity extraction, and custom text generation pipelines.
