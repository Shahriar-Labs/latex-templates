# IP Assignment Agreement LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/legal/ip-assignment-agreement/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

An IP assignment agreement on letter paper in Charter with recitals, definitions, the assignment and transfer, warranties, indemnification, governing law and an exhibit.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/legal/ip-assignment-agreement/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![IP Assignment Agreement preview](preview.png)

## What is in it
- Document class: `article` with `11pt, letterpaper`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, and 8 section files under `sections/`

## Use it online
Open **[IP Assignment Agreement on LetX](https://letx.app/templates/legal/ip-assignment-agreement/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/legal/ip-assignment-agreement
latexmk -pdf main.tex
```
