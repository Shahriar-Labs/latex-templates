# Power of Attorney Form LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/legal/power-of-attorney-form/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A power of attorney form on letter paper in Charter with an important notice to the principal, the appointment of the attorney-in-fact, and a grant of powers to initial by category.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/legal/power-of-attorney-form/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Power of Attorney Form preview](preview.png)

## What is in it
- Document class: `article` with `10pt, letterpaper`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Power of Attorney Form on LetX](https://letx.app/templates/legal/power-of-attorney-form/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/legal/power-of-attorney-form
latexmk -pdf main.tex
```
