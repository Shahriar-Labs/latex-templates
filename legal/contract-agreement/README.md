# Contract Agreement LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/legal/contract-agreement/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A general services contract on A4 in TeX Gyre Pagella with definitions, services, term and termination, payment, confidentiality, IP, indemnification and an exhibit.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/legal/contract-agreement/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Contract Agreement preview](preview.png)

## What is in it
- Document class: `article` with `11pt, a4paper`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, and 10 section files under `sections/`

## Use it online
Open **[Contract Agreement on LetX](https://letx.app/templates/legal/contract-agreement/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/legal/contract-agreement
latexmk -pdf main.tex
```
