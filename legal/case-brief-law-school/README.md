# Case Brief (Law School) LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/legal/case-brief-law-school/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A law school case brief in newpx fonts: facts, procedural history, issue, holding, reasoning, concurrences and dissents, doctrinal significance, key quotes and related authority.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/legal/case-brief-law-school/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Case Brief (Law School) preview](preview.png)

## What is in it
- Document class: `article` with `11pt, letterpaper`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, and 10 section files under `sections/`

## Use it online
Open **[Case Brief (Law School) on LetX](https://letx.app/templates/legal/case-brief-law-school/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/legal/case-brief-law-school
latexmk -pdf main.tex
```
