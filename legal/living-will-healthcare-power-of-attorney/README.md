## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/living-will-healthcare-power-of-attorney.git
cd living-will-healthcare-power-of-attorney
latexmk -pdf main.tex
```
Compiler: **pdflatex** (see `metadata.json`).
