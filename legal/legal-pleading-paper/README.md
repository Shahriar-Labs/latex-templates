# Legal Pleading Paper LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/legal/legal-pleading-paper/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

California-style pleading paper with 28 numbered lines drawn down the margin in TikZ, a superior court caption and an example complaint.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/legal/legal-pleading-paper/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Legal Pleading Paper preview](preview.png)

## What is in it
- Document class: `article` with `12pt, letterpaper`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Legal Pleading Paper on LetX](https://letx.app/templates/legal/legal-pleading-paper/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/legal/legal-pleading-paper
latexmk -pdf main.tex
```
