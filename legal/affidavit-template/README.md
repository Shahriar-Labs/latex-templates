# Sworn Affidavit LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/legal/affidavit-template/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A sworn affidavit on letter paper with a venue caption (state and county), the case caption and number, numbered statements of fact, and a jurat for the notary.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/legal/affidavit-template/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Sworn Affidavit preview](preview.png)

## What is in it
- Document class: `article` with `12pt, letterpaper`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Sworn Affidavit on LetX](https://letx.app/templates/legal/affidavit-template/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/legal/affidavit-template
latexmk -pdf main.tex
```
