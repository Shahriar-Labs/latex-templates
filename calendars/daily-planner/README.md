# Daily Planner LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/calendars/daily-planner/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A daily planner in Lato with an hourly schedule, top three priorities, a water tracker, notes and reminders, and a gratitude box.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/calendars/daily-planner/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Daily Planner preview](preview.png)

## What is in it
- Document class: `article` with `10pt`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Daily Planner on LetX](https://letx.app/templates/calendars/daily-planner/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/calendars/daily-planner
latexmk -pdf main.tex
```
