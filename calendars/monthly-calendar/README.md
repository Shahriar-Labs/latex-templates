# Monthly Calendar LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/calendars/monthly-calendar/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

Clean printable monthly calendar LaTeX template, a 7-column week grid with weekday headers, day numbers, roomy note cells, adjacent-month days greyed, and sample events. Easily change month and accent.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/calendars/monthly-calendar/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Monthly Calendar preview](preview.png)

## What is in it
- Document class: `article` with `11pt`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Monthly Calendar on LetX](https://letx.app/templates/calendars/monthly-calendar/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/calendars/monthly-calendar
latexmk -pdf main.tex
```
