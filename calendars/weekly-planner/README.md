# Weekly Planner LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/calendars/weekly-planner/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A weekly planner on A4 in Lato with a dated week header, a column for each day, and a motivational line in the banner.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/calendars/weekly-planner/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Weekly Planner preview](preview.png)

## What is in it
- Document class: `article` with `10pt, a4paper`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Weekly Planner on LetX](https://letx.app/templates/calendars/weekly-planner/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/calendars/weekly-planner
latexmk -pdf main.tex
```
