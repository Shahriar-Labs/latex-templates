# Study Planner LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/calendars/study-planner/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

Weekly study planner LaTeX template, a subject timetable grid, exam-countdown box, top-priorities checklist, subject color legend and a weekly-notes panel. Elegant, one-page, printable.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/calendars/study-planner/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Study Planner preview](preview.png)

## What is in it
- Document class: `article` with `10pt, a4paper`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Study Planner on LetX](https://letx.app/templates/calendars/study-planner/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/calendars/study-planner
latexmk -pdf main.tex
```
