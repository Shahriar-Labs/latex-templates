## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/viva-preparation-document.git
cd viva-preparation-document
latexmk -pdf main.tex
```
Compiler: **pdflatex** (see `metadata.json`).
