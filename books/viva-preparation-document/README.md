# Viva Preparation Document LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/books/viva-preparation-document/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A viva preparation document in TeX Gyre Pagella with a chapter-by-chapter thesis summary, anticipated questions with answers, a weak-points table and self-criticism.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/books/viva-preparation-document/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Viva Preparation Document preview](preview.png)

## What is in it
- Document class: `book` with `11pt, a4paper, oneside`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, `references.bib`, and 5 section files under `sections/`

## Use it online
Open **[Viva Preparation Document on LetX](https://letx.app/templates/books/viva-preparation-document/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/books/viva-preparation-document
latexmk -pdf main.tex
```
