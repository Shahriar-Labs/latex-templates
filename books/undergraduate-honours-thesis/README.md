# Undergraduate Honours Thesis LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/books/undergraduate-honours-thesis/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

An undergraduate honours thesis on the report class in Palatino with natbib, thirteen tables, a threats to validity section and a reference implementation appendix.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/books/undergraduate-honours-thesis/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Undergraduate Honours Thesis preview](preview.png)

## What is in it
- Document class: `report` with `12pt, a4paper, oneside`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, `references.bib`, and 11 section files under `sections/`

## Use it online
Open **[Undergraduate Honours Thesis on LetX](https://letx.app/templates/books/undergraduate-honours-thesis/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/books/undergraduate-honours-thesis
latexmk -pdf main.tex
```
