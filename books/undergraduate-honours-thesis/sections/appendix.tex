\chapter{Reference Implementation}
\label{app:code}

Listing~\ref{lst:gwc} gives the reference implementation of the GWC update and eviction
routine used in EdgeSim, corresponding to Equation~\ref{eq:gwc-update} in
Section~\ref{sec:gwc-design}.

\begin{lstlisting}[caption={Reference GWC update and eviction routine.}, label={lst:gwc}]
# alpha: learning rate: object size in KB
def on_access(cache, key, size_kb, now):
    entry = cache.get(key)
    if entry is None:
        entry = CacheEntry(freq=0.0, util=0.0, size_kb=size_kb)
        cache.insert(key, entry)

    entry.freq = entry.freq * (1 - ALPHA) + 1.0
    raw_score = entry.freq / log2(size_kb + 2)
    entry.util = (1 - ALPHA) * entry.util + ALPHA * raw_score
    entry.last_access = now

def on_insert_when_full(cache, new_key, new_entry):
    victim_key = min(cache.keys(), key=lambda k: cache[k].util)
    cache.evict(victim_key)
    cache.insert(new_key, new_entry)
\end{lstlisting}
