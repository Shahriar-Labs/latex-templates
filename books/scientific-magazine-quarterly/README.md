# Scientific Magazine (Quarterly) LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/books/scientific-magazine-quarterly/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A quarterly science magazine on A4 in Fira Sans and TeX Gyre Pagella with drop caps, research highlights in columns, an editorial board box and contributor notes.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/books/scientific-magazine-quarterly/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Scientific Magazine (Quarterly) preview](preview.png)

## What is in it
- Document class: `article` with `a4paper, 11pt`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Scientific Magazine (Quarterly) on LetX](https://letx.app/templates/books/scientific-magazine-quarterly/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/books/scientific-magazine-quarterly
latexmk -pdf main.tex
```
