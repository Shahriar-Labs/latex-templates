# Scientific Monograph (Book) LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/books/scientific-monograph/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A scientific monograph on the two-sided book class in TeX Gyre Pagella with margin notes, epigraphs, an index and theorem environments, on the statistical mechanics of networks.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/books/scientific-monograph/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Scientific Monograph (Book) preview](preview.png)

## What is in it
- Document class: `book` with `a4paper, twoside, 11pt`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, and 9 section files under `sections/`

## Use it online
Open **[Scientific Monograph (Book) on LetX](https://letx.app/templates/books/scientific-monograph/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/books/scientific-monograph
latexmk -pdf main.tex
```
