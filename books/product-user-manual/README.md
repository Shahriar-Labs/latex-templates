# Product User Manual LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/books/product-user-manual/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

Product user manual LaTeX template, cover page, table of contents, safety callouts, getting-started and setup steps, features, a troubleshooting table, specifications and warranty. Uses tcolorbox tips/warnings.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/books/product-user-manual/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Product User Manual preview](preview.png)

## What is in it
- Document class: `article` with `11pt, a4paper`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, and 7 section files under `sections/`

## Use it online
Open **[Product User Manual on LetX](https://letx.app/templates/books/product-user-manual/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/books/product-user-manual
latexmk -pdf main.tex
```
