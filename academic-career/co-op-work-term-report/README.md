## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/co-op-work-term-report.git
cd co-op-work-term-report
latexmk -pdf main.tex
```
Compiler: **pdflatex** (see `metadata.json`).
