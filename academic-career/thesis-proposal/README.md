# Thesis Proposal LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/academic-career/thesis-proposal/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

Academic thesis / dissertation proposal LaTeX template, formal title page (candidate, advisor, committee), then Abstract, Introduction, Research Questions, Related Work, Methodology, Preliminary Results, Timeline & References sections.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/academic-career/thesis-proposal/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Thesis Proposal preview](preview.png)

## What is in it
- Document class: `article` with `11pt, a4paper`
- Compiler: pdflatex
- Files: `main-blx.bib`, `main.tex`, `preamble.tex`, `references.bib`, and 8 section files under `sections/`

## Use it online
Open **[Thesis Proposal on LetX](https://letx.app/templates/academic-career/thesis-proposal/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/academic-career/thesis-proposal
latexmk -pdf main.tex
```
