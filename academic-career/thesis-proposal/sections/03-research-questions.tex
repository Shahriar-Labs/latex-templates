\section{Research Questions}
This dissertation proposal aims to address three fundamental research questions:
\begin{enumerate}
    \item \textbf{RQ1: Hardware-Aware Estimation.} How can we accurately model heterogeneous execution latency and energy consumption across diverse edge hardware backends without exhaustive physical benchmarking?
    \item \textbf{RQ2: Multi-Objective NAS.} What optimization algorithms can efficiently search the joint neural-compilation design space under tight hardware constraints?
    \item \textbf{RQ3: Dynamic Runtime Scheduling.} How can dynamic runtime scheduling partition neural network execution graph blocks across concurrent heterogeneous accelerators to minimize end-to-end latency?
\end{enumerate}
