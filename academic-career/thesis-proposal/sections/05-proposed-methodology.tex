\section{Proposed Methodology}
The proposed framework consists of three primary components:
\begin{itemize}
    \item \textbf{Component 1: Multi-Backend Profiler.} A lightweight profiling tool that builds predictive models of layer-wise latency and energy using Gaussian Process Regression.
    \item \textbf{Component 2: Co-Design NAS Engine.} A differentiable search engine that optimizes both operator-level parameters (e.g., convolutional block choices) and compilation schedules.
    \item \textbf{Component 3: Heterogeneous Runtime Scheduler.} A runtime scheduler that partitions the optimized model graph dynamically across available CPU, GPU, and NPU cores based on current system load.
\end{itemize}
