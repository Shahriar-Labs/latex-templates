# Study Abroad Exchange Report LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/academic-career/study-abroad-exchange-report/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A study abroad exchange report in Charter with preparation, the host institution, academic experience compared with home, cultural reflection, and practical advice.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/academic-career/study-abroad-exchange-report/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Study Abroad Exchange Report preview](preview.png)

## What is in it
- Document class: `article` with `11pt, a4paper`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, `references.bib`, and 5 section files under `sections/`

## Use it online
Open **[Study Abroad Exchange Report on LetX](https://letx.app/templates/academic-career/study-abroad-exchange-report/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/academic-career/study-abroad-exchange-report
latexmk -pdf main.tex
```
