# Research Statement LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/academic-career/research-statement/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

Clean academic research statement LaTeX template for faculty job applications, title block, boxed research vision, and Overview, Past & Current Research, Future Directions, Broader Impacts & Publications sections.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/academic-career/research-statement/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Research Statement preview](preview.png)

## What is in it
- Document class: `article` with `10pt, a4paper`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, and 5 section files under `sections/`

## Use it online
Open **[Research Statement on LetX](https://letx.app/templates/academic-career/research-statement/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/academic-career/research-statement
latexmk -pdf main.tex
```
