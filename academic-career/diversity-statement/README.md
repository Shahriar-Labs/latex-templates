# Diversity Statement LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/academic-career/diversity-statement/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

Diversity, equity & inclusion (DEI) statement LaTeX template for faculty applications, title block and Commitment, Past Contributions, Inclusive Teaching, and Future Plans sections.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/academic-career/diversity-statement/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Diversity Statement preview](preview.png)

## What is in it
- Document class: `article` with `11pt, letterpaper`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, and 4 section files under `sections/`

## Use it online
Open **[Diversity Statement on LetX](https://letx.app/templates/academic-career/diversity-statement/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/academic-career/diversity-statement
latexmk -pdf main.tex
```
