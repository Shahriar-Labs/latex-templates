# PhD Progress Report LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/academic-career/phd-progress-report/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

PhD annual progress report LaTeX template, aligned student/supervisor info box, Research Objectives, Progress, a milestones status table, publications, challenges, next-period plan and a supervisor comments box.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/academic-career/phd-progress-report/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![PhD Progress Report preview](preview.png)

## What is in it
- Document class: `article` with `11pt, a4paper`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, and 7 section files under `sections/`

## Use it online
Open **[PhD Progress Report on LetX](https://letx.app/templates/academic-career/phd-progress-report/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/academic-career/phd-progress-report
latexmk -pdf main.tex
```
