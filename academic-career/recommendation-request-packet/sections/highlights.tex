\subsection{Research Projects}

\subsubsection*{1. NimbusDB: Optimizing Log Replication in Edge-Cloud Systems}
In my role as an Undergraduate Research Assistant at the \textit{Apex Distributed Systems Lab}, I worked on designing a consensus protocol tailored for network-constrained edge environments.
\begin{itemize}
    \item Developed a prototype of a consensus engine in \textbf{Go} based on the Raft algorithm, modifying the log replication path to support dynamic pipeline sizes.
    \item Ran comprehensive benchmarks simulating high write contention and high latency network connections.
    \item Achieved a \textbf{24\% reduction in latency} compared to standard Raft implementations under simulated edge-cloud topologies.
    \item This work resulted in a first-authored paper presented at the \textit{14th Meridian Conference on Systems (MCS 2026)} \parencite{chen2026nimbusdb}.
\end{itemize}

\subsubsection*{2. VertexML: Edge Inference for Heterogeneous Accelerators}
Collaborating with the hardware systems group, I explored compiler-level optimizations for running small language models on edge devices.
\begin{itemize}
    \item Implemented custom kernel operators in \textbf{C++} and \textbf{CUDA} to optimize memory layouts for Vertex AI hardware accelerators.
    \item Developed an active pruning framework that dynamically adjusts model size depending on real-time hardware thermals and battery status.
    \item Successfully reduced memory footprint by \textbf{40\%} with less than a 1.5\% loss in inference accuracy.
    \item Co-authored a paper detailing these findings, currently under review at the \textit{Journal of Systems Research} \parencite{chen2025vertex}.
\end{itemize}
