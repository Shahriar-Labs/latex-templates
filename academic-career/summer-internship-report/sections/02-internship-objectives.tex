\section{Internship Objectives}

\begin{itemize}[leftmargin=18pt,itemsep=4pt,topsep=4pt]
    \item Understand the end-to-end lifecycle of an industry ML project --- from
          business-problem framing to model deployment.
    \item Develop a production-grade \textbf{customer churn prediction} model using
          ensemble learning techniques on real-world telecom data.
    \item Gain hands-on experience with data preprocessing at scale, feature
          engineering, and hyperparameter optimisation.
    \item Collaborate within an agile team using Git, Jira, and daily stand-ups.
    \item Document findings in a technical report and present outcomes to the
          senior leadership team.
\end{itemize}
