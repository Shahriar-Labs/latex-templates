\subsection{Online Plasticity and Local Learning Rules}
In biological brains, synapse modification is governed by local information. For instance, Spike-Timing-Dependent Plasticity (STDP) adjusts synaptic weights based solely on the timing difference between pre- and post-synaptic neuron firings. Local rules eliminate the need for global error propagation pathways, which are computationally expensive to route on silicon. 

My current work focuses on mapping STDP variants to hybrid memristive-CMOS chips \cite{reynolds2025hybrid}. I am designing circuitry that implements a localized \emph{eligibility trace} at each synapse. This allows the system to temporarily log temporal associations and update weights only when an global reward signal (such as dopaminergic reinforcement) is present. This architecture enables self-supervised feature extraction, allowing edge sensors to adapt to shifting environmental inputs (e.g., changes in lighting or acoustic background noise) without human intervention.
