## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/research-statement-faculty-application.git
cd research-statement-faculty-application
latexmk -pdf main.tex
```
Compiler: **pdflatex** (see `metadata.json`).
