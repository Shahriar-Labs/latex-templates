# Statement of Purpose LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/academic-career/statement-of-purpose/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A graduate statement of purpose in Lato with motivation, research experience, an example program-fit section written for Stanford, and future directions.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/academic-career/statement-of-purpose/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Statement of Purpose preview](preview.png)

## What is in it
- Document class: `article` with `11pt`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, and 4 section files under `sections/`

## Use it online
Open **[Statement of Purpose on LetX](https://letx.app/templates/academic-career/statement-of-purpose/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/academic-career/statement-of-purpose
latexmk -pdf main.tex
```
