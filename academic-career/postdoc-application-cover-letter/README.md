## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/postdoc-application-cover-letter.git
cd postdoc-application-cover-letter
latexmk -pdf main.tex
```
Compiler: **pdflatex** (see `metadata.json`).
