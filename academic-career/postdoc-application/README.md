# Postdoc Application LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/academic-career/postdoc-application/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

Postdoctoral application LaTeX template, academic letterhead cover letter expressing fit and summarizing PhD work, plus a short proposed-research section with aims linked to the target lab.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/academic-career/postdoc-application/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Postdoc Application preview](preview.png)

## What is in it
- Document class: `article` with `11pt, letterpaper`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, and 4 section files under `sections/`

## Use it online
Open **[Postdoc Application on LetX](https://letx.app/templates/academic-career/postdoc-application/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/academic-career/postdoc-application
latexmk -pdf main.tex
```
