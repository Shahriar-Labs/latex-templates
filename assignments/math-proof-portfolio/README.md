## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/math-proof-portfolio.git
cd math-proof-portfolio
latexmk -pdf main.tex
```
Compiler: **pdflatex** (see `metadata.json`).
