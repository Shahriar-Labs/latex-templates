# Math Proof Portfolio LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/assignments/math-proof-portfolio/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

Mathematics proof portfolio LaTeX template, color-coded tcolorbox theorem environments (Theorem, Lemma, Proposition, Definition, Corollary) with a QED-boxed Proof environment and several classical results fully proved.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/assignments/math-proof-portfolio/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Math Proof Portfolio preview](preview.png)

## What is in it
- Document class: `article` with `11pt, a4paper`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, and 3 section files under `sections/`

## Use it online
Open **[Math Proof Portfolio on LetX](https://letx.app/templates/assignments/math-proof-portfolio/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/assignments/math-proof-portfolio
latexmk -pdf main.tex
```
