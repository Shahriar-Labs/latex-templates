# Course Syllabus LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/assignments/reading-list-syllabus/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

University course syllabus & reading list LaTeX template, course info box, description, learning objectives, a weekly schedule table, grading breakdown, policies and a grouped reading list.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/assignments/reading-list-syllabus/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Course Syllabus preview](preview.png)

## What is in it
- Document class: `article` with `11pt, a4paper`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, and 6 section files under `sections/`

## Use it online
Open **[Course Syllabus on LetX](https://letx.app/templates/assignments/reading-list-syllabus/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/assignments/reading-list-syllabus
latexmk -pdf main.tex
```
