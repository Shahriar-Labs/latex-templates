# Seminar Report LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/assignments/seminar-report/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A seminar report on the report class in Lato with a certificate, abstract and acknowledgement, then background, problem statement, objectives and a literature review.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/assignments/seminar-report/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Seminar Report preview](preview.png)

## What is in it
- Document class: `report` with `12pt, a4paper`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, and 32 section files under `sections/`

## Use it online
Open **[Seminar Report on LetX](https://letx.app/templates/assignments/seminar-report/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/assignments/seminar-report
latexmk -pdf main.tex
```
