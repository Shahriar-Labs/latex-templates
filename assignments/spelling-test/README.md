# Spelling Test Template LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/assignments/spelling-test/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A spelling test sheet in Lato with name, grade, teacher and date fields, twenty numbered word lines, a dictation sentence and bonus words.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/assignments/spelling-test/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Spelling Test Template preview](preview.png)

## What is in it
- Document class: `article` with `11pt`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Spelling Test Template on LetX](https://letx.app/templates/assignments/spelling-test/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/assignments/spelling-test
latexmk -pdf main.tex
```
