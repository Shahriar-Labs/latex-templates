# Capstone Project Report LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/assignments/capstone-project-report/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A capstone project report in Lato with an abstract, introduction, methodology, results, discussion and future work, and conclusion, with TikZ figures.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/assignments/capstone-project-report/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Capstone Project Report preview](preview.png)

## What is in it
- Document class: `article` with `11pt`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, and 6 section files under `sections/`

## Use it online
Open **[Capstone Project Report on LetX](https://letx.app/templates/assignments/capstone-project-report/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/assignments/capstone-project-report
latexmk -pdf main.tex
```
