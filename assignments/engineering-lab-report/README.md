# Engineering Lab Report LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/assignments/engineering-lab-report/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

An engineering lab report on A4 with theory, experimental setup, circuitikz schematics, results with pgfplots and siunitx, simulation code and analysis.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/assignments/engineering-lab-report/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Engineering Lab Report preview](preview.png)

## What is in it
- Document class: `article` with `11pt, a4paper`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, and 7 section files under `sections/`

## Use it online
Open **[Engineering Lab Report on LetX](https://letx.app/templates/assignments/engineering-lab-report/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/assignments/engineering-lab-report
latexmk -pdf main.tex
```
