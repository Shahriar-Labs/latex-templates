# Candidacy Exam Notes LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/assignments/candidacy-exam-notes/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

PhD candidacy / qualifying exam study-notes LaTeX template, topic sections with outlines, color-coded tcolorbox key-results/theorem boxes, definitions, exam-tip callouts and formulas via amsmath.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/assignments/candidacy-exam-notes/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Candidacy Exam Notes preview](preview.png)

## What is in it
- Document class: `article` with `10pt, letterpaper`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, and 4 section files under `sections/`

## Use it online
Open **[Candidacy Exam Notes on LetX](https://letx.app/templates/assignments/candidacy-exam-notes/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/assignments/candidacy-exam-notes
latexmk -pdf main.tex
```
