# Final Year Project Report LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/assignments/final-year-project-report/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A final year project report on A4 in Source Sans Pro with a literature review, methodology, implementation with code listings, results and discussion, and future work.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/assignments/final-year-project-report/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Final Year Project Report preview](preview.png)

## What is in it
- Document class: `article` with `11pt, a4paper`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, and 7 section files under `sections/`

## Use it online
Open **[Final Year Project Report on LetX](https://letx.app/templates/assignments/final-year-project-report/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/assignments/final-year-project-report
latexmk -pdf main.tex
```
