# Assignment Cover Sheet LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/assignments/assignment-cover-sheet/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

An assignment cover sheet in Source Sans Pro followed by three worked algorithm problems (Dijkstra runtime analysis, a priority queue implementation, alternatives) with code.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/assignments/assignment-cover-sheet/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Assignment Cover Sheet preview](preview.png)

## What is in it
- Document class: `article` with `11pt, a4paper`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, and 3 section files under `sections/`

## Use it online
Open **[Assignment Cover Sheet on LetX](https://letx.app/templates/assignments/assignment-cover-sheet/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/assignments/assignment-cover-sheet
latexmk -pdf main.tex
```
