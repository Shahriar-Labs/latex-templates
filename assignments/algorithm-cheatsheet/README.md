# Algorithm Cheatsheet LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/assignments/algorithm-cheatsheet/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

Dense, color-coded algorithms & data-structures cheatsheet LaTeX template, multi-column tcolorbox topic cards, Big-O complexity tables, and syntax-highlighted code for sorting, searching, graphs & dynamic programming.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/assignments/algorithm-cheatsheet/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Algorithm Cheatsheet preview](preview.png)

## What is in it
- Document class: `article` with `10pt, landscape, letterpaper`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Algorithm Cheatsheet on LetX](https://letx.app/templates/assignments/algorithm-cheatsheet/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/assignments/algorithm-cheatsheet
latexmk -pdf main.tex
```
