# Math Practice Worksheet LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/assignments/math-worksheet/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A math practice worksheet in Lato with name, date and score fields at the top and numbered practice problems set out in columns below.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/assignments/math-worksheet/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Math Practice Worksheet preview](preview.png)

## What is in it
- Document class: `article` with `11pt`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Math Practice Worksheet on LetX](https://letx.app/templates/assignments/math-worksheet/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/assignments/math-worksheet
latexmk -pdf main.tex
```
