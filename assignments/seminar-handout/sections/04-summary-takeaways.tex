\section{Summary \& Takeaways}

\begin{itemize}
  \item Transformers replace recurrence with \textbf{self-attention},
        enabling full parallelisation across sequence positions.
  \item \textbf{Multi-head attention} lets the model jointly attend to
        information from different representation sub-spaces.
  \item \textbf{Positional encoding} is the sole source of sequential order
        in the architecture — removing it makes the model bag-of-words.
  \item Residual connections and \textbf{layer normalisation} stabilise
        deep stacks and mitigate vanishing gradients.
  \item The architecture scales predictably: more parameters + more data
        + more compute $\Rightarrow$ log-linear performance gains (scaling laws).
\end{itemize}
