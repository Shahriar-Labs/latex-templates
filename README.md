# Free LaTeX Templates — Theses, Papers, CVs, Posters & Slides

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates) [![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE) [![Templates](https://img.shields.io/badge/templates-350-success.svg)](https://letx.app/templates)

**350 free, open-source LaTeX templates**, organised into 20 categories: university theses, journal articles, conference papers, CVs and résumés, grant proposals, academic posters, Beamer presentations, lab reports and formal letters.

Every template is compile-tested, MIT-licensed, and free to use — no account, no signup, no paywall. Open one in the browser to edit and compile it without installing LaTeX, or clone the repo and run `latexmk` locally. The full library of 601+ templates lives at [letx.app/templates](https://letx.app/templates).

## How to use a template

**Online (no install):** click *Open in LetX* on any template below. It opens ready to edit, compiles to PDF in the browser, and supports real-time collaboration with co-authors.

**Locally:**

```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/<category>/<template>
latexmk -pdf main.tex     # check metadata.json for the right compiler
```

Each template directory contains `main.tex`, a compiled `main.pdf`, a `preview.png`, and a `metadata.json` naming its compiler (`pdflatex`, `xelatex` or `lualatex`).

## Frequently asked questions

### Are these LaTeX templates free?

Yes. All 350 templates in this repository are MIT-licensed and free for academic and commercial use, with no account or signup required. You can clone the repo and use them entirely offline, or open them in the browser at [letx.app/templates](https://letx.app/templates).

### Can I use these without installing LaTeX?

Yes. Click *Open in LetX* on any template and it opens in a browser-based editor that compiles to PDF on managed infrastructure — no TeX Live install, and it works the same on Windows, macOS and Linux.

### Which compiler does each template need?

Each template's `metadata.json` names its compiler. Most use `pdflatex`; templates using custom fonts via `fontspec` require `xelatex` or `lualatex`. Running `latexmk -pdf main.tex` works for the pdflatex ones.

### Do you have a template for my university's thesis format?

This repository groups university and thesis formats under [`universities/`](#university--thesis-templates). The complete set across both repositories and the live library covers 601+ templates including many regional university formats — search [letx.app/templates/universities](https://letx.app/templates/universities). If yours is missing, open an issue or a pull request.

### How is this different from Overleaf's template gallery?

These templates are open source and version-controlled: you can clone them, diff them, and submit fixes. They are also free to open and edit collaboratively without a per-collaborator charge.

## Contributing

Templates are organised as `<category>/<template-slug>/`. To add one, create a directory under the right category containing `main.tex`, `metadata.json`, and a compiled `main.pdf`. Open a pull request — contributions of university thesis formats are especially welcome, since those are the hardest for students to find.
