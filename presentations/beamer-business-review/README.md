# Quarterly Business Review (QBR) LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/presentations/beamer-business-review/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A quarterly business review in 16:9 Beamer with an executive summary, a KPI slide, and a revenue table comparing segments quarter on quarter and year on year.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/presentations/beamer-business-review/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Quarterly Business Review (QBR) preview](preview.png)

## What is in it
- Document class: `beamer` with `11pt, aspectratio=169`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Quarterly Business Review (QBR) on LetX](https://letx.app/templates/presentations/beamer-business-review/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/presentations/beamer-business-review
latexmk -pdf main.tex
```
