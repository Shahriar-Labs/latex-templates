\begin{frame}{Routing Cost Function}
Given query $q$ and index $i \in \{\text{HNSW}, \text{IVF-PQ}, \text{Flat}\}$, AQR scores each candidate index by a weighted cost:
\[
  \mathrm{cost}(q,i) \;=\; \alpha \cdot \widehat{\ell}_i(q) \;+\; \beta \cdot \big(1 - \widehat{r}_i(q)\big) \;+\; \gamma \cdot \mathrm{load}_i
\]
\begin{itemize}
\item $\widehat{\ell}_i(q)$ --- predicted latency of index $i$ for query $q$ (gradient-boosted regressor, 12 features)
\item $\widehat{r}_i(q)$ --- predicted recall@10 of index $i$ for query $q$
\item $\mathrm{load}_i$ --- current queue depth of index $i$, refreshed every 250\,ms
\item $\alpha,\beta,\gamma$ --- tuned on a held-out validation split ($\alpha{=}0.5,\ \beta{=}0.4,\ \gamma{=}0.1$)
\end{itemize}
AQR routes to $\operatorname*{arg\,min}_i \mathrm{cost}(q,i)$, falling back to Flat search when router confidence is below threshold $\tau = 0.62$.
\end{frame}
