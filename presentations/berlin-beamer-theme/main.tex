\section{Introduction}
\subsection{Motivation}

% Slide 3: Motivation
\begin{frame}{The Challenge of Modern Energy Grids}
  The transition to zero-carbon energy grids introduces significant operational volatility:
  \vspace{0.4cm}
  \begin{itemize}
    \item<1-> Rapid integration of intermittent renewable energy sources (solar and wind).
    \item<2-> High peak-to-average load ratios leading to frequent localized grid instability.
    \item<3-> Carbon-intensive legacy backup generators activated during peak demand hours.
    \item<4-> Critical need for an autonomous, decentralized, and real-time balancing solution.
  \end{itemize}
\end{frame}

\subsection{Synapse Microgrid}

% Slide 4: Case Study
\begin{frame}{Case Study: Synapse Microgrid Deployment}
  A real-world testbed designed to demonstrate decentralized edge computing:
  \vspace{0.4cm}
  \begin{itemize}
    \item Jointly developed by \textbf{Synapse Labs} and \textbf{Nexa Corp}.
    \item Deployed in a high-density municipal zone with 12,000 smart nodes.
    \item Core objective: Minimize grid stress and reduce carbon emissions automatically.
    \item Powered by the \textbf{Vertex Framework} for fast, localized decision-making.
  \end{itemize}
\end{frame}

\subsection{System Design}

% Slide 5: Architecture
\begin{frame}{Vertex Framework Architecture}
  Decentralized control loop split between localized edge agents and a cloud orchestrator:
  \vspace{0.1cm}
  \begin{columns}[T]
    \begin{column}{0.48\textwidth}
      \textbf{Core Components:}
      \vspace{0.1cm}
      \begin{itemize}
        \item \textbf{Edge Observers}: Monitor local power draw and voltage fluctuations.
        \item \textbf{Decision Agents}: Localized policy execution via reinforcement learning.
        \item \textbf{Global Orchestrator}: Asynchronously updates global weights.
      \end{itemize}
    \end{column}
    \begin{column}{0.48\textwidth}
