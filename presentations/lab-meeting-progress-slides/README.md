## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/lab-meeting-progress-slides.git
cd lab-meeting-progress-slides
latexmk -pdf main.tex
```
Compiler: **pdflatex** (see `metadata.json`).
