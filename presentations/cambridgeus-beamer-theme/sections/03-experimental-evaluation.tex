% Slide 7: Experimental Setup
\begin{frame}{Experimental Setup}
    To evaluate the Nexa framework, we deployed a benchmark across multiple nodes:
    \begin{itemize}
        \item \faServer ~ \textbf{Infrastructure:} Vertex Cloud Services (50 virtual instances).
        \item \faCogs ~ \textbf{Workload:} Synthetic request streams simulating web-tier access.
        \item \faChartLine ~ \textbf{Baselines:} Compared against Apex Router and Meridian Flow.
    \end{itemize}
\end{frame}

% Slide 9: Qualitative Insights (two-column layout)
\begin{frame}{Qualitative Insights}
    An analysis of trade-offs and deployment requirements:
    \begin{columns}
        \begin{column}{0.48\textwidth}
            \textbf{System Benefits}
            \begin{itemize}
                \item \textbf{Low Complexity:} Light codebase, easy deployment.
                \item \textbf{High Reliability:} Fault tolerant nodes prevent system halts.
                \item \textbf{Extensible API:} Standardized protocols for Nexa extension.
            \end{itemize}
        \end{column}
        \begin{column}{0.48\textwidth}
            \textbf{Deployment Considerations}
            \begin{itemize}
                \item Requires initialization overhead for node routing tables.
                \item Memory footprints scale linearly with active nodes.
                \item Initial cluster synchronization takes 1.2 seconds.
            \end{itemize}
        \end{column}
    \end{columns}
\end{frame}
