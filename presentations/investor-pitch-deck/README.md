## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/investor-pitch-deck.git
cd investor-pitch-deck
latexmk -pdf main.tex
```
Compiler: **pdflatex** (see `metadata.json`).
