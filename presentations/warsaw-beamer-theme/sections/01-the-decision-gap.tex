\section{The decision gap}

% -----------------------------------------------------------------------------
% 3. Motivation
% -----------------------------------------------------------------------------
\begin{frame}{An alert is useful only if it arrives before conditions change}
  \begin{columns}[T,onlytextwidth]
    \begin{column}{0.56\textwidth}
      \begin{itemize}[<+->]
        \item Sensors observe rainfall, channel depth, and flow at different rates.
        \item Central processing adds a network dependency exactly when links are least reliable.
        \item A late or unstable alert erodes operator trust, even when the model is accurate.
        \item The design target is therefore \alert{timely, explainable, and graceful degradation}.
      \end{itemize}
    \end{column}
    \begin{column}{0.40\textwidth}
      \begin{alertblock}{Decision gap}
        Raw measurements do not protect a neighborhood. A dependable pipeline must turn partial evidence into a bounded-risk action.
      \end{alertblock}
      \vspace{0.25cm}
      \begin{exampleblock}{Core question}
        How much intelligence must remain local when cloud connectivity disappears?
      \end{exampleblock}
    \end{column}
  \end{columns}
\end{frame}

% -----------------------------------------------------------------------------
% 4. Design principles
% -----------------------------------------------------------------------------
\begin{frame}{Three principles keep the system useful during disruption}
  \begin{columns}[T,onlytextwidth]
    \begin{column}{0.31\textwidth}
      \begin{block}{1. Decide locally}
        Each gateway maintains a compact risk model and can issue a provisional alert without a round trip.
      \end{block}
    \end{column}
    \begin{column}{0.31\textwidth}
      \begin{block}{2. Fuse uncertainty}
        Missing sensors reduce confidence explicitly instead of silently changing the prediction.
      \end{block}
    \end{column}
    \begin{column}{0.31\textwidth}
      \begin{block}{3. Reconcile later}
        The cloud coordinates models and audit history, but it is not on the critical alert path.
      \end{block}
    \end{column}
  \end{columns}

  \vfill
  \centering
  \color{AstraNavy}\large\bfseries
  Local autonomy shortens the path; explicit uncertainty keeps that autonomy accountable.
\end{frame}
