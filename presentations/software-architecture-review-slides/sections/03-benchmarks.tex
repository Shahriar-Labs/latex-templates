    \begin{column}{0.48\textwidth}
      \textbf{Key Measurements:}
      \begin{itemize}
        \item \textbf{Peak Latency:} Monolith latency degrades exponentially beyond 600 RPS due to DB pool locking.
        \item \textbf{Throughput Limit:} Microservices sustained 1,000+ RPS with flat sub-120ms latency.
      \end{itemize}
