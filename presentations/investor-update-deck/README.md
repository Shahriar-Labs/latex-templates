# Monthly Investor Update Deck LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/presentations/investor-update-deck/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A monthly investor update in 16:9 Beamer with highlights, growth metrics, cash position and burn, product and team news, and a slide on how the board can help.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/presentations/investor-update-deck/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Monthly Investor Update Deck preview](preview.png)

## What is in it
- Document class: `beamer` with `aspectratio=169, xcolor={table}`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, `references.bib`, and 5 section files under `sections/`

## Use it online
Open **[Monthly Investor Update Deck on LetX](https://letx.app/templates/presentations/investor-update-deck/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/presentations/investor-update-deck
latexmk -pdf main.tex
```
