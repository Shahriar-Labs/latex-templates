\section{Summary}

\begin{frame}{Contributions}
  \begin{enumerate}[leftmargin=1.6em, label=\arabic*.]
    \item A single-pass confidence estimator for LLM triage output that
      needs no architecture access beyond token log-probabilities.
    \item A conformal abstention rule that turns that estimator into a
      three-tier action a nursing workflow can run in real time.
    \item (Extension) A clinician-facing study of how exposing calibrated
      uncertainty changes override behavior and trust.
  \end{enumerate}
  \par\vspace{8pt}
  \begin{tealbox}{Bottom line}
    \footnotesize
    The dissertation claim rests on Aims 1--2; Aim~3 strengthens the
    deployment story but is not load-bearing for the core result.
  \end{tealbox}
\end{frame}
