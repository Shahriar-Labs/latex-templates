\section{Motivation}

\begin{frame}{Triage Assistants Are Already in the Loop}{And They Rarely Say ``I'm Not Sure''}
  \begin{columns}[T]
    \begin{column}{0.52\textwidth}
      \begin{itemize}[leftmargin=1.4em]
        \item[\faFlask] Emergency departments at three \textbf{Synapse Health}
          pilot sites now route intake notes through an LLM triage
          assistant before a nurse ever reads them.
        \item[\faFlask] The assistant emits a priority level and a short
          justification -- but no confidence signal a clinician can act on.
        \item[\faFlask] Chart review at one pilot site found the model was
          \textbf{wrong on 14\%} of Level-2 (urgent) calls, evenly split
          between over- and under-triage.
      \end{itemize}
    \end{column}
    \begin{column}{0.44\textwidth}
      \begin{tealbox}{Why this matters}
        \footnotesize
        An overconfident wrong answer costs more than a correct one saves.
        Nurses cannot tell a well-grounded triage call from a plausible
        guess -- so they either over-trust the tool or ignore it entirely.
      \end{tealbox}
    \end{column}
  \end{columns}
\end{frame}

\begin{frame}{Problem Statement}
  \begin{navybox}{The gap this work targets}
    Large language models used for clinical triage produce fluent,
    high-confidence-\emph{sounding} text regardless of how well-supported
    the underlying judgment is. Existing calibration methods either require
    architecture access the deployed model does not expose, or add enough
    latency that they cannot run inside the triage window.
  \end{navybox}
  \par\vspace{10pt}
  \begin{center}
    \Large\color{navy}\bfseries
    Can a triage system know, in real time, when it should defer to a human?
  \end{center}
\end{frame}

\begin{frame}{Research Questions}
  \begin{enumerate}[leftmargin=1.6em, label=\textbf{RQ\arabic*.}]
    \item How well does black-box, single-pass uncertainty estimation
      track \emph{actual} triage error on real intake notes?
    \item Can a calibrated confidence score be converted into a
      selective-abstention rule that a nursing workflow can act on
      without adding meaningful latency?
    \item Does exposing calibrated confidence change clinician trust and
      override behavior, compared to an uncalibrated score or no score
      at all?
  \end{enumerate}
  \par\vspace{8pt}
  \begin{notebox}{Scope for this exam}
    RQ1 and RQ2 are the focus of the proposed dissertation work. RQ3 is a
    planned human-factors extension, discussed briefly under risks.
  \end{notebox}
\end{frame}
