# Lightning Talk Poster Teaser LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/presentations/lightning-talk-poster-teaser/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A three-slide lightning talk in 16:9 Beamer that teases a conference poster, with one key result, a throughput comparison and the poster's time, location and number.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/presentations/lightning-talk-poster-teaser/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Lightning Talk Poster Teaser preview](preview.png)

## What is in it
- Document class: `beamer` with `aspectratio=169, 11pt`
- Compiler: pdflatex
- Files: `main-blx.bib`, `main.tex`, `preamble.tex`, `references.bib`, and 3 section files under `sections/`

## Use it online
Open **[Lightning Talk Poster Teaser on LetX](https://letx.app/templates/presentations/lightning-talk-poster-teaser/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/presentations/lightning-talk-poster-teaser
latexmk -pdf main.tex
```
