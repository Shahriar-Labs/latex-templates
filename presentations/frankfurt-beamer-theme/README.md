# Frankfurt Beamer Theme LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/presentations/frankfurt-beamer-theme/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A talk on Beamer's Frankfurt theme about multi-agent path finding, with an executive summary, decentralized MPC coordination and success-rate results against agent density.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/presentations/frankfurt-beamer-theme/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Frankfurt Beamer Theme preview](preview.png)

## What is in it
- Document class: `beamer` with `xcolor={table, dvipsnames}`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, and 4 section files under `sections/`

## Use it online
Open **[Frankfurt Beamer Theme on LetX](https://letx.app/templates/presentations/frankfurt-beamer-theme/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/presentations/frankfurt-beamer-theme
latexmk -pdf main.tex
```
