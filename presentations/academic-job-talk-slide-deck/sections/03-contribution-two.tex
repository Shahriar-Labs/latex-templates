\begin{frame}{Contribution II: Calibrated Forecasting under Shift}{Vasquez and Okafor, 2025}
  \small
  \begin{columns}[T]
    \begin{column}{0.46\textwidth}
      A robust representation is only useful if the model \emph{knows when it
      does not know}. We combine conformal prediction with the encoder from
      Contribution~I to produce calibrated intervals that hold up as
      corruption severity increases~\cite{vasquez2025uncertainty,diaz2025conformal}.

      \vspace{0.15cm}
      \begin{itemize}
        \item Wraps any point forecaster with distribution-free coverage
          guarantees.
        \item Calibration set is re-weighted using the encoder's own
          corruption-severity estimate.
        \item Deployed on six months of live Apex-Climate buoy data.
      \end{itemize}
    \end{column}
