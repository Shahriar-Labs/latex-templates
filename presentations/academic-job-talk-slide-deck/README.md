# Academic Job Talk Slide Deck LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/presentations/academic-job-talk-slide-deck/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

An academic job talk in 16:9 Beamer: a research vision, two contribution sections, a future research agenda, a teaching slide and a closing fit argument, with biblatex references and pgfplots charts.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/presentations/academic-job-talk-slide-deck/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Academic Job Talk Slide Deck preview](preview.png)

## What is in it
- Document class: `beamer` with `aspectratio=169, xcolor={table}`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, `references.bib`, and 6 section files under `sections/`

## Use it online
Open **[Academic Job Talk Slide Deck on LetX](https://letx.app/templates/presentations/academic-job-talk-slide-deck/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/presentations/academic-job-talk-slide-deck
latexmk -pdf main.tex
```
