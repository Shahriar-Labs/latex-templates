## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/saas-product-demo-slides.git
cd saas-product-demo-slides
latexmk -pdf main.tex
```
Compiler: **pdflatex** (see `metadata.json`).
