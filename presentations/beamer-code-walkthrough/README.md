# Code Walkthrough Presentation LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/presentations/beamer-code-walkthrough/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A code walkthrough deck in 16:9 Beamer on dark cards, stepping through a migration's core changes with listings and closing on the build, test and deploy steps.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/presentations/beamer-code-walkthrough/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Code Walkthrough Presentation preview](preview.png)

## What is in it
- Document class: `beamer` with `10pt, aspectratio=169`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Code Walkthrough Presentation on LetX](https://letx.app/templates/presentations/beamer-code-walkthrough/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/presentations/beamer-code-walkthrough
latexmk -pdf main.tex
```
