# PhD Defense Beamer LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/presentations/phd-defense-beamer/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A PhD defense in 16:9 Beamer set in Lato, organised around three research questions on representation drift: detect it unlabeled, predict it, and recover from it.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/presentations/phd-defense-beamer/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![PhD Defense Beamer preview](preview.png)

## What is in it
- Document class: `beamer` with `aspectratio=169, 11pt`
- Compiler: xelatex
- One self-contained `main.tex`

## Use it online
Open **[PhD Defense Beamer on LetX](https://letx.app/templates/presentations/phd-defense-beamer/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/presentations/phd-defense-beamer
latexmk -xelatex main.tex
```
