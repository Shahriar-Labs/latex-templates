# Journal Club Presentation LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/presentations/journal-club-presentation/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A journal club deck in Beamer that critiques one paper: context, methodology, a recreated figure with its evaluation problems, strengths and limitations, and open discussion questions.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/presentations/journal-club-presentation/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Journal Club Presentation preview](preview.png)

## What is in it
- Document class: `beamer` with `xcolor={table, dvipsnames}, aspectratio=169`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, `references.bib`, and 6 section files under `sections/`

## Use it online
Open **[Journal Club Presentation on LetX](https://letx.app/templates/presentations/journal-club-presentation/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/presentations/journal-club-presentation
latexmk -pdf main.tex
```
