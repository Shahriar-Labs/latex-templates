# Trigon Beamer Theme LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/presentations/trigon-beamer-theme/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A 16:9 talk on the Trigon Beamer theme about edge-cloud scheduling, with a centralization bottleneck, scheduling policies, decision logic and latency convergence results.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/presentations/trigon-beamer-theme/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Trigon Beamer Theme preview](preview.png)

## What is in it
- Document class: `beamer` with `10pt, aspectratio=169`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, and 4 section files under `sections/`

## Use it online
Open **[Trigon Beamer Theme on LetX](https://letx.app/templates/presentations/trigon-beamer-theme/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/presentations/trigon-beamer-theme
latexmk -pdf main.tex
```
