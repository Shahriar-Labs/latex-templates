# Ph.D. Candidacy Proposal Slides LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/presentations/ph-d-candidacy-proposal-slides/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

PhD candidacy proposal slides in 16:9 Beamer, set in Lato, stating the proposal in one sentence and building one thesis from three questions and three studies.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/presentations/ph-d-candidacy-proposal-slides/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Ph.D. Candidacy Proposal Slides preview](preview.png)

## What is in it
- Document class: `beamer` with `aspectratio=169, 11pt`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Ph.D. Candidacy Proposal Slides on LetX](https://letx.app/templates/presentations/ph-d-candidacy-proposal-slides/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/presentations/ph-d-candidacy-proposal-slides
latexmk -pdf main.tex
```
