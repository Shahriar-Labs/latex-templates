# Student Conference Talk Slides LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/presentations/student-conference-talk-slides/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A twelve-minute student conference talk in 16:9 Beamer, structured as hook, method, two results and one takeaway, with natbib references.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/presentations/student-conference-talk-slides/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Student Conference Talk Slides preview](preview.png)

## What is in it
- Document class: `beamer` with `aspectratio=169, 11pt`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, `references.bib`, and 4 section files under `sections/`

## Use it online
Open **[Student Conference Talk Slides on LetX](https://letx.app/templates/presentations/student-conference-talk-slides/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/presentations/student-conference-talk-slides
latexmk -pdf main.tex
```
