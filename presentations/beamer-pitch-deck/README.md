# Startup Pitch Deck (Beamer) LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/presentations/beamer-pitch-deck/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A five-slide startup pitch in 16:9 Beamer: challenge and solution, market opportunity and traction, a competitive comparison table, and the team with the capital ask.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/presentations/beamer-pitch-deck/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Startup Pitch Deck (Beamer) preview](preview.png)

## What is in it
- Document class: `beamer` with `aspectratio=169, xcolor={table}`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Startup Pitch Deck (Beamer) on LetX](https://letx.app/templates/presentations/beamer-pitch-deck/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/presentations/beamer-pitch-deck
latexmk -pdf main.tex
```
