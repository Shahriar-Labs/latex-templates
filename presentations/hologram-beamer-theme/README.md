# Hologram Beamer Theme LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/presentations/hologram-beamer-theme/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A 16:9 Beamer deck with a custom holographic look on the default theme, arguing for shared spatial scenes in collaboration through sentence-style titles and TikZ diagrams.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/presentations/hologram-beamer-theme/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Hologram Beamer Theme preview](preview.png)

## What is in it
- Document class: `beamer` with `10pt, aspectratio=169`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Hologram Beamer Theme on LetX](https://letx.app/templates/presentations/hologram-beamer-theme/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/presentations/hologram-beamer-theme
latexmk -pdf main.tex
```
