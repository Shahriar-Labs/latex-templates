# SINTEF Beamer Theme LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/presentations/sintef-beamer-theme/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A 16:9 Beamer deck in the style of the SINTEF theme, built on the default theme with Source Sans Pro, pitching an industrial flexibility planner with TikZ diagrams and pgfplots.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/presentations/sintef-beamer-theme/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![SINTEF Beamer Theme preview](preview.png)

## What is in it
- Document class: `beamer` with `10pt, aspectratio=169`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[SINTEF Beamer Theme on LetX](https://letx.app/templates/presentations/sintef-beamer-theme/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/presentations/sintef-beamer-theme
latexmk -pdf main.tex
```
