# Machine Learning Model Review Presentation LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/presentations/machine-learning-model-review-presentation/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A machine learning model review in 16:9 Beamer: executive summary, training dynamics and convergence, validation and bias assessment, and production drift monitoring.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/presentations/machine-learning-model-review-presentation/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Machine Learning Model Review Presentation preview](preview.png)

## What is in it
- Document class: `beamer` with `aspectratio=169, xcolor={table}`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, `references.bib`, and 4 section files under `sections/`

## Use it online
Open **[Machine Learning Model Review Presentation on LetX](https://letx.app/templates/presentations/machine-learning-model-review-presentation/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/presentations/machine-learning-model-review-presentation
latexmk -pdf main.tex
```
