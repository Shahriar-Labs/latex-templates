## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/machine-learning-model-review-presentation.git
cd machine-learning-model-review-presentation
latexmk -pdf main.tex
```
Compiler: **pdflatex** (see `metadata.json`).
