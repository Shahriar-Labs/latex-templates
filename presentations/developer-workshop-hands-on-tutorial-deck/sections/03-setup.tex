\section{Installation}
\subsection{Terminal Commands}

\begin{frame}[fragile]{Installing Synapse CLI}{Getting Started on macOS \& Linux}
  We will use the \textbf{Synapse CLI} tool to manage our local mesh configuration and query the directory service.
  
  \vspace{0.3cm}
  Run the following commands to install and verify the mesh environment:
  
  \begin{terminalbox}{Terminal: Installation}
$ curl -sSL https://get.synapse.sh | sh
$ export PATH=$PATH:$HOME/.synapse/bin
$ synapse --version
Synapse Mesh CLI v2.4.1 (build 8a9f2c)
  \end{terminalbox}
\end{frame}

\begin{frame}[fragile]{Initializing Mesh Workspace}{Establishing Registry Communication}
  After verification, initialize your local workspace and authenticate with the central state store.
  
  \vspace{0.3cm}
  Run the configuration initialization process:
  
  \begin{terminalbox}{Terminal: Configuration Init}
$ synapse init --workspace local-mesh --token=syn_tkn_81a7b2
[info] Initialized workspace "local-mesh" in .synapse/
[info] Verified connection to Synapse Registry (latency: 14ms)
  \end{terminalbox}
\end{frame}
