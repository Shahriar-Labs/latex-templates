\section{Introduction}
\subsection{Workshop Goals}

\begin{frame}{Welcome to Synapse Mesh Workshop}{Overview \& Learning Objectives}
  Welcome to the hands-on session for \textbf{Synapse Mesh}, the declarative service directory for next-generation microservices.
  
  \vspace{0.3cm}
  In this session, you will learn to:
  \begin{itemize}
    \item Deploy the \textbf{Vertex Proxy} as an API Gateway.
    \item Configure service discovery using \textbf{Synapse Registry}.
    \item Define traffic splitting and canary routing rules.
    \item Monitor latency using \textbf{Nimbus Analytics}.
  \end{itemize}
  
  \vspace{0.4cm}
  \begin{alertbox}{Prerequisites}
    Ensure you have \texttt{curl}, \texttt{docker-compose}, and a local Kubernetes environment running.
  \end{alertbox}
\end{frame}
