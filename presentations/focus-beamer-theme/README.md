# Focus Beamer Theme LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/presentations/focus-beamer-theme/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A talk on the Focus Beamer theme about edge computing, in three numbered parts, with a system overview, a resource allocation protocol and a latency comparison.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/presentations/focus-beamer-theme/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Focus Beamer Theme preview](preview.png)

## What is in it
- Document class: `beamer`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, and 3 section files under `sections/`

## Use it online
Open **[Focus Beamer Theme on LetX](https://letx.app/templates/presentations/focus-beamer-theme/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/presentations/focus-beamer-theme
latexmk -pdf main.tex
```
