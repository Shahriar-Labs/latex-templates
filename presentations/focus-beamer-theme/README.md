## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/focus-beamer-theme.git
cd focus-beamer-theme
latexmk -pdf main.tex
```
Compiler: **pdflatex** (see `metadata.json`).
