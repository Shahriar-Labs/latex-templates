\section{Balance Verification (EQ-BAL-014)}

\subsection{Method}
Verification followed the gravimetric linearity, repeatability, and eccentricity checks described
in OIML~R76-1 \cite{oiml-r76} and ASTM~E898 \cite{astm-e898}, using Class~E2 reference weights
handled with forceps and allowed to thermally equilibrate on the balance table for 10 minutes
before each series.
