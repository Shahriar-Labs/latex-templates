\section{Tolerance Criteria and Nonconformance Handling}

\subsection{Acceptance Rule}
An instrument passes overall verification only if \emph{every} tested load or volume, at every
tested point, meets both its accuracy and precision limit. A single out-of-tolerance result fails
the whole instrument for that verification cycle --- partial pass is not a valid disposition,
consistent with the pipette policy applied in Section~5.5.

\midrule

\noindent
Tighter limits apply at 100\% of a pipette's nominal capacity; limits widen at lower test
volumes (50\%, 10\%) as relative error grows for the same absolute dispensing variance. Balance
tolerances follow OIML~R76-1 Class~I bands applied per Section~4, scaled to load as shown in
Section~4.2.

\subsection{Corrective Action Procedure}
When a result exceeds its tolerance limit, the technician:
\begin{enumerate}[leftmargin=1.6em]
  \item Repeats the failing test point once, immediately, to rule out a transient handling error
        (draft, static charge, air bubble in the tip).
  \item If the repeat still fails, applies an \textbf{OUT OF SERVICE} tag to the instrument and
        physically removes it from the bench.
  \item Opens a nonconformance record (NCR) referencing this document number and the specific
        test point that failed.
  \item Notifies the QA Manager and any staff who used the instrument since its last passing
        verification, so downstream results can be risk-assessed.
  \item Routes the instrument to service (in-house piston/seal inspection or manufacturer repair)
        and re-verifies fully --- all three test volumes, not only the one that failed --- before
        returning it to use.
\end{enumerate}
