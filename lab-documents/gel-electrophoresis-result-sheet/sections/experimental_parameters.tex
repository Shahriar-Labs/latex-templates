\section{Experimental Run Parameters}

Detailed settings of the run, casting, and imaging conditions are summarized below.

\vspace{4pt}
\begin{minipage}[t]{0.49\textwidth}
\vspace{0pt}
\begin{settingsbox}{Gel Casting \& Buffer Settings}
\small\renewcommand{\arraystretch}{1.0}%
\begin{itemize}[leftmargin=1.0em,itemsep=1.5pt]
  \item \textbf{Gel Type:} Molecular Biology Agarose
  \item \textbf{Agarose Conc.:} \percent{1.5} (w/v) in 1$\times$ TAE
  \item \textbf{Running Buffer:} 1$\times$ TAE
  \item \textbf{Stain:} GelRed\texttrademark\ (1:10,000 in-gel)
  \item \textbf{Gel Vol / Comb:} \microL{100} / 8-well
  \item \textbf{Comb Thickness:} 1.5\,mm
\end{itemize}
\end{settingsbox}
\end{minipage}%

\begin{minipage}[t]{0.49\textwidth}
\vspace{0pt}
\begin{settingsbox}{Electrophoresis \& Imaging Settings}
\small\renewcommand{\arraystretch}{1.0}%
\begin{itemize}[leftmargin=1.0em,itemsep=1.5pt]
  \item \textbf{Running Voltage:} Constant \volt{120}
  \item \textbf{Current (Start/End):} \amp{84} / \amp{89}
  \item \textbf{Run Duration:} \timeMin{80}
  \item \textbf{Imaging System:} Meridian Imager-3000
  \item \textbf{Excitation:} UV Transilluminator (\bp{302} nm)
  \item \textbf{Exposure / Filter:} 150\,ms / orange filter
\end{itemize}
\end{settingsbox}

\par\vspace{4pt}
\begin{warningbox}{Safety Alert \& Reagent Handling}
\small
  GelRed\texttrademark\ is a safer alternative to Ethidium Bromide but must be handled with gloves. Ensure the electrophoresis chamber lid is closed and the power supply is off before touching the buffer. UV radiation is hazardous; always use the protective shield.
\end{warningbox}
