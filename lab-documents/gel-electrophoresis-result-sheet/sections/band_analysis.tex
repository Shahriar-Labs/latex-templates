\subsection*{Calibration Curve Equations}
The standard molecular weight curve was generated using a semi-logarithmic regression analysis of Lane~1:
\begin{equation}
  \log_{10}(\text{Size}) = -0.0245 \cdot (\text{Migration Distance in mm}) + 4.6852 \quad (R^2 = 0.998)
\end{equation}
Fragments smaller than \bp{250} exhibit non-linear migration patterns under the current running conditions and were fitted using a secondary polynomial regression curve.
