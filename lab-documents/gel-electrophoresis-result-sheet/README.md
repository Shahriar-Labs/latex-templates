# Gel Electrophoresis Result Sheet LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/lab-documents/gel-electrophoresis-result-sheet/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A gel electrophoresis result sheet with run parameters, a lane loading protocol, a gel image panel, quantitative band analysis and a QC review.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/lab-documents/gel-electrophoresis-result-sheet/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Gel Electrophoresis Result Sheet preview](preview.png)

## What is in it
- Document class: `article` with `11pt, a4paper`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, `references.bib`, and 6 section files under `sections/`

## Use it online
Open **[Gel Electrophoresis Result Sheet on LetX](https://letx.app/templates/lab-documents/gel-electrophoresis-result-sheet/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/lab-documents/gel-electrophoresis-result-sheet
latexmk -pdf main.tex
```
