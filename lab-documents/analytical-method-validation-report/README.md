## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/analytical-method-validation-report.git
cd analytical-method-validation-report
latexmk -pdf main.tex
```
Compiler: **pdflatex** (see `metadata.json`).
