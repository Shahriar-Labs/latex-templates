\section{Scope, Instrumentation and Materials}

\subsection{Scope}
This study applies to the determination of Zolarvex in Nimbufen Tablets (50\,mg and
100\,mg strengths, identical core formulation) by the HPLC-UV method of Nexa SOP
QC-042. The working range investigated, 0.5--50\,ng/mL, brackets the anticipated LOD
and LOQ and lies well below the routine assay range (2--150\,\textmu g/mL for the
Nimbufen active), so no interaction with the primary assay calibration is implied.

\subsection{Instrumentation}
\begin{itemize}[leftmargin=1.4em]
  \item Nexa LC-3200 UHPLC system with quaternary pump, thermostatted autosampler,
        and photodiode array (PDA) detector
  \item Column: Vertex C18, 100~$\times$~2.1\,mm, 1.8\,\textmu m particle size,
        thermostatted at 40\,\textdegree C
  \item Detection wavelength: 254\,nm (4\,nm bandwidth), reference off
  \item Injection volume: 5\,\textmu L; flow rate: 0.4\,mL/min
  \item Data system: Nexa Chromatics CDS v11.2, 21~CFR~Part~11 compliant
\end{itemize}

\subsection{Mobile Phase and Reagents}
\begin{itemize}[leftmargin=1.4em]
  \item Mobile Phase A: 0.1\,\% v/v formic acid in water (LC-MS grade)
  \item Mobile Phase B: acetonitrile (LC-MS grade)
  \item Diluent: Mobile Phase A / Mobile Phase B, 80:20 v/v
  \item Placebo matrix: Nimbufen Tablet placebo blend, Lot PLB-0472, prepared and
        dispensed by Nexa Formulation Support
  \item Zolarvex Reference Standard, Lot ZLX-RS-0912, certified purity 99.6\,\% (w/w),
        stored at 2--8\,\textdegree C, protected from light
\end{itemize}

\subsection{Statistical Basis}
Regression parameters were computed by unweighted ordinary least-squares linear
regression of detector response against nominal concentration, following the
treatment of Miller and Miller \citep{millermiller2018} and the regression-based
approach of ICH~Q2(R2) \citep{ich2023q2r2}. The resulting LOD and LOQ are treated as
fit-for-purpose performance characteristics of the method in this matrix
\citep{eurachem2014}.
