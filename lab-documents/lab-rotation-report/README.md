# Graduate Lab Rotation Report LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/lab-documents/lab-rotation-report/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A graduate lab rotation report with rotation aims, materials and methods, preliminary results, a discussion with reflection on the rotation, and a supervisor's comments section.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/lab-documents/lab-rotation-report/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Graduate Lab Rotation Report preview](preview.png)

## What is in it
- Document class: `article` with `11pt`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, `references.bib`, and 6 section files under `sections/`

## Use it online
Open **[Graduate Lab Rotation Report on LetX](https://letx.app/templates/lab-documents/lab-rotation-report/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/lab-documents/lab-rotation-report
latexmk -pdf main.tex
```
