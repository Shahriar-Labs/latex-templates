# Geology Field Report LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/lab-documents/geology-field-report/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

Geology field report LaTeX template, site info box, abstract, a TikZ stratigraphic column, lithology and sample-catalog tables, structural observations and interpretation. Realistic field sample.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/lab-documents/geology-field-report/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Geology Field Report preview](preview.png)

## What is in it
- Document class: `article` with `11pt, a4paper`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, and 8 section files under `sections/`

## Use it online
Open **[Geology Field Report on LetX](https://letx.app/templates/lab-documents/geology-field-report/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/lab-documents/geology-field-report
latexmk -pdf main.tex
```
