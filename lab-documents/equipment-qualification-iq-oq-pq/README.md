# Equipment Qualification (IQ/OQ/PQ) Protocol LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/lab-documents/equipment-qualification-iq-oq-pq/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

An equipment qualification protocol covering installation, operational and performance qualification (IQ, OQ, PQ), with pre-execution approvals, deviations and CAPA, and final sign-off.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/lab-documents/equipment-qualification-iq-oq-pq/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Equipment Qualification (IQ/OQ/PQ) Protocol preview](preview.png)

## What is in it
- Document class: `article` with `10pt, a4paper`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, `references.bib`, and 6 section files under `sections/`

## Use it online
Open **[Equipment Qualification (IQ/OQ/PQ) Protocol on LetX](https://letx.app/templates/lab-documents/equipment-qualification-iq-oq-pq/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/lab-documents/equipment-qualification-iq-oq-pq
latexmk -pdf main.tex
```
