\section{Tune Report Placeholder and Calibration}
Mass spectrometer mass calibration and resolution settings are verified weekly using a standard tune solution of Polypropylene Glycol (PPG) or similar calibration mix. The target mass resolution is set to unit resolution in both Q1 and Q3, corresponding to a peak width of $0.70 \pm 0.10$~Da at half height (Full Width at Half Maximum, FWHM).

\subsection{System Suitability Requirements}
Prior to running any sample batch, the system suitability must be verified against the following parameters:
\begin{enumerate}
    \item \textbf{Mass Accuracy:} The observed mass must be within $\pm 0.1$~Da of the target mass.
    \item \textbf{Peak Width (Resolution):} Peak FWHM must be between $0.60$ and $0.80$~Da.
    \item \textbf{Sensitivity:} A minimum signal-to-noise (S/N) ratio of $10:1$ must be achieved for the lowest calibration standard.
\end{enumerate}
