\section{Staining Protocols}

\subsection{Routine Hematoxylin \& Eosin (H\&E)}
Standard progressive H\&E, run on a Nimbus ST-120 linear stainer, calibrated daily
against a control slide before the first clinical batch \citep{fischer2008hematoxylin}.

\subsection{Special Stain: Masson's Trichrome}
Ordered by the sign-out pathologist on Block~BLK-04821-A to assess dermal collagen
distribution at the lesion base. Performed manually per SOP HISTO-SOP-027.

\vspace{6pt}
\textbf{Expected result:} nuclei black, cytoplasm and muscle fibres red, collagen blue.
Fixation in formalin for the duration recorded in Section~\ref{sec:fixation} is adequate
for trichrome staining; specimens fixed under 6~hours can under-stain collagen and would
require re-processing \citep{suvarna2018bancrofts}.

\vspace{6pt}
\begin{itemize}
  \item Stain batch controls (tonsil, appendix) run concurrently with every trichrome load.
  \item Slides screened for uniform blue collagen signal before release to the pathologist.
  \item Any pale or patchy staining triggers a repeat from the block, not a re-stain of the
        same section.
\end{itemize}
