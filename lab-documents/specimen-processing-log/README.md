# Clinical Specimen Processing Log LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/lab-documents/specimen-processing-log/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A clinical specimen processing log on A4 with the receiving and accessioning procedure, a specimen accession log, rejection reason codes, and QC with shift sign-off.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/lab-documents/specimen-processing-log/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Clinical Specimen Processing Log preview](preview.png)

## What is in it
- Document class: `article` with `11pt, a4paper`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, `references.bib`, and 5 section files under `sections/`

## Use it online
Open **[Clinical Specimen Processing Log on LetX](https://letx.app/templates/lab-documents/specimen-processing-log/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/lab-documents/specimen-processing-log
latexmk -pdf main.tex
```
