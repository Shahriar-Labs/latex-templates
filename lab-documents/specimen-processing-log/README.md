## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/specimen-processing-log.git
cd specimen-processing-log
latexmk -pdf main.tex
```
Compiler: **pdflatex** (see `metadata.json`).
