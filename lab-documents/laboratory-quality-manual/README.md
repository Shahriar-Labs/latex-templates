## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/laboratory-quality-manual.git
cd laboratory-quality-manual
latexmk -pdf main.tex
```
Compiler: **pdflatex** (see `metadata.json`).
