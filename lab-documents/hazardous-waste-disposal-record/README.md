## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/hazardous-waste-disposal-record.git
cd hazardous-waste-disposal-record
latexmk -pdf main.tex
```
Compiler: **pdflatex** (see `metadata.json`).
