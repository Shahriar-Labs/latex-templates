# Bioinformatics Report LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/lab-documents/bioinformatics-report/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

Bioinformatics analysis report LaTeX template, abstract, methods with a pipeline/tool-version table, a differential-expression results table, a pgfplots chart, and monospace gene/command formatting. Realistic RNA-seq sample.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/lab-documents/bioinformatics-report/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Bioinformatics Report preview](preview.png)

## What is in it
- Document class: `article` with `11pt, a4paper`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, and 6 section files under `sections/`

## Use it online
Open **[Bioinformatics Report on LetX](https://letx.app/templates/lab-documents/bioinformatics-report/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/lab-documents/bioinformatics-report
latexmk -pdf main.tex
```
