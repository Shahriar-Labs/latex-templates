# Chemistry Lab Report LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/lab-documents/chemistry-lab-report/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

Chemistry laboratory report LaTeX template, title block, abstract, reagents table, mhchem reaction equations, procedure, results with percent-yield calculations, discussion and conclusion.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/lab-documents/chemistry-lab-report/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Chemistry Lab Report preview](preview.png)

## What is in it
- Document class: `article` with `11pt, a4paper`
- Compiler: pdflatex
- Files: `main.tex`, `test.tex`

## Use it online
Open **[Chemistry Lab Report on LetX](https://letx.app/templates/lab-documents/chemistry-lab-report/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/lab-documents/chemistry-lab-report
latexmk -pdf main.tex
```
