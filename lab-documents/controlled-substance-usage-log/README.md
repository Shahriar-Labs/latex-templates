# Controlled Substance Usage Log LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/lab-documents/controlled-substance-usage-log/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A controlled substance usage log form with secure storage and regulatory status, usage instructions, and a disposal and close-out verification section, marked confidential.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/lab-documents/controlled-substance-usage-log/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Controlled Substance Usage Log preview](preview.png)

## What is in it
- Document class: `article` with `10pt, letterpaper`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, `references.bib`, and 3 section files under `sections/`

## Use it online
Open **[Controlled Substance Usage Log on LetX](https://letx.app/templates/lab-documents/controlled-substance-usage-log/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/lab-documents/controlled-substance-usage-log
latexmk -pdf main.tex
```
