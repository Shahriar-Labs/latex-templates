\section{Quality Control Metrics}
\label{sec:qc-metrics}

Run-level QC metrics were pulled from the SeqCall v5.3 run report following completion of
Read~2 and cross-checked by the QC reviewer against the acceptance thresholds defined in
SOP SGC-SOP-021 (\emph{Sequencing Run Acceptance Criteria}). A run is released for
demultiplexing and delivery only when every metric below meets or exceeds its threshold.
