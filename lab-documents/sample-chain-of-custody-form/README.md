## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/sample-chain-of-custody-form.git
cd sample-chain-of-custody-form
latexmk -pdf main.tex
```
Compiler: **pdflatex** (see `metadata.json`).
