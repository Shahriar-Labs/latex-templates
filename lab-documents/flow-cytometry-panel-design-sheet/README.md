## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/flow-cytometry-panel-design-sheet.git
cd flow-cytometry-panel-design-sheet
latexmk -pdf main.tex
```
Compiler: **pdflatex** (see `metadata.json`).
