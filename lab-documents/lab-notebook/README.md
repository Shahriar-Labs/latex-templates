# Lab Notebook LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/lab-documents/lab-notebook/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

Structured lab notebook / research log LaTeX template, header block (project, researcher, date, entry no.), and per-entry Objective, Materials, Procedure, Observations, Results & Conclusion sections. Includes a filled sample entry.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/lab-documents/lab-notebook/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Lab Notebook preview](preview.png)

## What is in it
- Document class: `article` with `10pt, letterpaper`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Lab Notebook on LetX](https://letx.app/templates/lab-documents/lab-notebook/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/lab-documents/lab-notebook
latexmk -pdf main.tex
```
