## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/chemical-spill-response-plan.git
cd chemical-spill-response-plan
latexmk -pdf main.tex
```
Compiler: **pdflatex** (see `metadata.json`).
