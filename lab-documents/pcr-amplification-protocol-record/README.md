## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/pcr-amplification-protocol-record.git
cd pcr-amplification-protocol-record
latexmk -pdf main.tex
```
Compiler: **pdflatex** (see `metadata.json`).
