\section{Instrumentation \& Method Parameters}

The following instrumentation and chromatographic conditions were used for the system suitability test and the subsequent sample analysis of Batch~B26-0417.

\vspace{4pt}
\begin{minipage}[t]{0.49\textwidth}
\vspace{0pt}
\begin{settingsbox}{Instrument \& Column}
\small\renewcommand{\arraystretch}{1.0}%
\begin{itemize}[leftmargin=1.0em,itemsep=1.5pt]
  \item \textbf{HPLC System:} Apex LC-3200 Quaternary System
  \item \textbf{Detector:} UV-Vis Diode Array, \wave{254}
  \item \textbf{Data System:} ApexChrom CDS v4.2
  \item \textbf{Column:} Octadecylsilane (C18), 150~$\times$~4.6\,mm, 5\,\textmu m
  \item \textbf{Column ID:} COL-118 (Lot~C18-0552)
  \item \textbf{Column Temp.:} \degC{30}
\end{itemize}
\end{settingsbox}
\end{minipage}%
\hfill%
\begin{minipage}[t]{0.49\textwidth}
\vspace{0pt}
\begin{settingsbox}{Mobile Phase \& Run Conditions}
\small\renewcommand{\arraystretch}{1.0}%
\begin{itemize}[leftmargin=1.0em,itemsep=1.5pt]
  \item \textbf{Mobile Phase A:} 0.1\% phosphoric acid in water, pH~3.0
  \item \textbf{Mobile Phase B:} Acetonitrile, HPLC grade
  \item \textbf{Elution Mode:} Isocratic, 55:45 (A:B, v/v)
  \item \textbf{Flow Rate:} \flow{1.0}
  \item \textbf{Injection Volume:} \volinj{10}
  \item \textbf{Run Time:} \timeMin{15} per injection
\end{itemize}
\end{settingsbox}
\end{minipage}

\par\vspace{4pt}
\begin{warningbox}{Mobile Phase Handling \& Stability}
\small
Mobile phase A is buffered to pH~3.0 with phosphoric acid and is stable for 48~hours at room temperature; solutions older than 48~hours were discarded prior to use. Both mobile phase components were filtered through a 0.45\,\textmu m membrane and degassed by sonication for 15~minutes before use to prevent baseline noise and pump cavitation.
\end{warningbox}
