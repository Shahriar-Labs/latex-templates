\section{Representative SST Chromatogram}
\label{sec:chromatogram}

Figure~1 shows the chromatogram obtained from injection~3 of the system suitability solution, representative of the six replicate injections summarized in Table~1 (Section~\ref{sec:results}).

\begin{center}
\begin{tikzpicture}[>=latex, scale=0.95]
  \definecolor{ChromBg}{HTML}{FCFCFB}

  % Plot frame
  \draw[fill=ChromBg, draw=HplcBorder, line width=1pt] (0,0) rectangle (12.6,6.8);

  % Gridlines and x ticks
  \foreach \x in {0,1,...,12} {
    \draw[HplcBorder, dashed, opacity=0.6] (\x,0.3) -- (\x,6.2);
    \draw[HplcInk] (\x,0) -- (\x,-0.08);
    \node[below, font=\tiny\sffamily, HplcInk] at (\x,-0.1) {\x};
  }

  % Axes
  \draw[->, HplcInk, line width=1pt] (0,0) -- (12.6,0);
  \node[below, font=\small\sffamily, HplcInk] at (6.3,-0.7) {Retention Time (min)};
  \draw[->, HplcInk, line width=1pt] (0,0) -- (0,6.6);
  \node[rotate=90, font=\small\sffamily, HplcInk] at (-0.9,3.4) {Response (mAU)};

  % Baseline
  \draw[thick, HplcInk] (0,0.3) -- (12.6,0.3);

  % Solvent front / void marker
  \draw[thick, HplcBorder, smooth] plot coordinates {(0.85,0.3)(0.95,0.55)(1.05,0.3)};

  % Impurity-A peak (RT 4.21)
  \draw[thick, HplcGold, smooth] plot coordinates
    {(3.75,0.3)(3.95,0.75)(4.08,1.35)(4.21,1.85)(4.34,1.35)(4.48,0.75)(4.68,0.3)};
  \node[above, font=\scriptsize\sffamily, HplcGold!70!black] at (4.21,1.95) {\shortstack{Imp-A\\4.21}};

  % Main peak: NXA-4471 (RT 7.83), drawn with a slight fronting-free tail
  \draw[thick, HplcTeal, smooth] plot coordinates
    {(6.95,0.3)(7.25,1.3)(7.5,2.9)(7.68,4.4)(7.83,5.6)(7.98,4.5)(8.18,3.0)(8.45,1.6)(8.85,0.72)(9.25,0.3)};
  \node[above, font=\scriptsize\sffamily, HplcTeal!70!black] at (7.83,5.7) {\shortstack{NXA-4471\\7.83}};

  % Impurity-B peak (RT 9.65)
  \draw[thick, HplcInk!70, smooth] plot coordinates
    {(9.35,0.3)(9.48,0.55)(9.65,0.78)(9.82,0.55)(9.95,0.3)};
  \node[above, font=\scriptsize\sffamily, HplcInk] at (9.65,0.9) {\shortstack{Imp-B\\9.65}};

\end{tikzpicture}
\end{center}
\par\vspace{4pt}
\small\textbf{Figure~1:} Representative SST chromatogram (injection~3 of 6) showing Impurity-A (RT~4.21\,min), the NXA-4471 main peak (RT~7.83\,min), and Impurity-B (RT~9.65\,min). Detection at \wave{254}; total run time \timeMin{15}.
