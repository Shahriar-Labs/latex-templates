## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/reagent-preparation-worksheet.git
cd reagent-preparation-worksheet
latexmk -pdf main.tex
```
Compiler: **pdflatex** (see `metadata.json`).
