# Tri-Fold Brochure LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/posters/tri-fold-brochure/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A tri-fold brochure in Lato for a youth nonprofit, with panels for who we are, the programs, ways to give, how to get involved, and contact details.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/posters/tri-fold-brochure/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Tri-Fold Brochure preview](preview.png)

## What is in it
- Document class: `article` with `10pt`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Tri-Fold Brochure on LetX](https://letx.app/templates/posters/tri-fold-brochure/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/posters/tri-fold-brochure
latexmk -pdf main.tex
```
