# A2 Academic Poster LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/posters/scientific-poster-a2/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

An A2 academic poster in columns presenting a neural climate model, with its data sources, encoder and decoder stages, and CRPS evaluation against baselines.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/posters/scientific-poster-a2/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![A2 Academic Poster preview](preview.png)

## What is in it
- Document class: `article`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[A2 Academic Poster on LetX](https://letx.app/templates/posters/scientific-poster-a2/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/posters/scientific-poster-a2
latexmk -pdf main.tex
```
