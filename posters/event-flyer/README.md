# Event Flyer LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/posters/event-flyer/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A dark event flyer in Lato for a club night, with neon accents, the headline act, date and door times in a table, and a QR code for tickets.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/posters/event-flyer/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Event Flyer preview](preview.png)

## What is in it
- Document class: `article` with `12pt`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Event Flyer on LetX](https://letx.app/templates/posters/event-flyer/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/posters/event-flyer
latexmk -pdf main.tex
```
