# Modern Conference Poster (A1) LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/posters/poster-a1-modern/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

Modern A1 academic conference poster LaTeX template (tikzposter), bold title band, a multi-column layout with Introduction, Methods, Results (chart + table), Conclusion and References blocks.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/posters/poster-a1-modern/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Modern Conference Poster (A1) preview](preview.png)

## What is in it
- Document class: `tikzposter` with `25pt, a1paper, portrait, margin=0mm, innermargin=15mm, blockverticalspace=15mm, colspace=15mm`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Modern Conference Poster (A1) on LetX](https://letx.app/templates/posters/poster-a1-modern/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/posters/poster-a1-modern
latexmk -pdf main.tex
```
