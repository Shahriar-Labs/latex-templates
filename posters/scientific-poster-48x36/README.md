# Scientific Poster (48x36 Portrait) LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/posters/scientific-poster-48x36/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A 48 by 36 inch portrait scientific poster on extarticle at 14pt in columns, presenting a binding affinity model with a benchmark table of Pearson R and RMSE.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/posters/scientific-poster-48x36/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Scientific Poster (48x36 Portrait) preview](preview.png)

## What is in it
- Document class: `extarticle` with `14pt`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Scientific Poster (48x36 Portrait) on LetX](https://letx.app/templates/posters/scientific-poster-48x36/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/posters/scientific-poster-48x36
latexmk -pdf main.tex
```
