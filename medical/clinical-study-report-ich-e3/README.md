# Clinical Study Report (ICH E3) LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/medical/clinical-study-report-ich-e3/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A clinical study report structured after ICH E3, in Lato: synopsis, ethics, investigators, objectives, the investigational plan, study patients and efficacy, in eighteen tables.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/medical/clinical-study-report-ich-e3/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Clinical Study Report (ICH E3) preview](preview.png)

## What is in it
- Document class: `article` with `11pt, a4paper`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, and 13 section files under `sections/`

## Use it online
Open **[Clinical Study Report (ICH E3) on LetX](https://letx.app/templates/medical/clinical-study-report-ich-e3/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/medical/clinical-study-report-ich-e3
latexmk -pdf main.tex
```
