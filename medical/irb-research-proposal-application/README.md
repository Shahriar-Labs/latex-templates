## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/irb-research-proposal-application.git
cd irb-research-proposal-application
latexmk -pdf main.tex
```
Compiler: **pdflatex** (see `metadata.json`).
