# Dental Treatment Plan LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/medical/dental-treatment-plan/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A dental treatment plan on A4 in two columns with patient and dentist details (licence, specialty, NPI, referral) and a phased table of planned procedures and fees.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/medical/dental-treatment-plan/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Dental Treatment Plan preview](preview.png)

## What is in it
- Document class: `article` with `11pt, a4paper`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Dental Treatment Plan on LetX](https://letx.app/templates/medical/dental-treatment-plan/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/medical/dental-treatment-plan
latexmk -pdf main.tex
```
