# Statistical Analysis Plan (SAP) LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/medical/statistical-analysis-plan/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A statistical analysis plan (SAP) in Lato with estimands, analysis populations, primary and secondary endpoints, multiplicity, missing data handling, ADaM specs and TFL shells.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/medical/statistical-analysis-plan/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Statistical Analysis Plan (SAP) preview](preview.png)

## What is in it
- Document class: `article` with `11pt, a4paper`
- Compiler: pdflatex
- Files: `main.tex`, `preamble.tex`, and 14 section files under `sections/`

## Use it online
Open **[Statistical Analysis Plan (SAP) on LetX](https://letx.app/templates/medical/statistical-analysis-plan/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/medical/statistical-analysis-plan
latexmk -pdf main.tex
```
