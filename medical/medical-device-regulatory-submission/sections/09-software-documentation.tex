\section{Software documentation}

Software documentation follows IEC 62304:2006+A1:2015 lifecycle processes. The overall software safety classification is \textbf{Class B}: a software failure could contribute to non-serious injury through inaccurate or delayed information, while professional review and clinical context remain independent controls.
