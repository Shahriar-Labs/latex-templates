## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/clinical-trial-protocol.git
cd clinical-trial-protocol
latexmk -pdf main.tex
```
Compiler: **pdflatex** (see `metadata.json`).
