# ICU Critical Care Flowsheet LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/medical/icu-critical-care-flowsheet/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A landscape ICU critical care flowsheet on letter paper with a patient header (MRN, bed, ICU day, code status) and twelve ruled tables for hourly observations.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/medical/icu-critical-care-flowsheet/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![ICU Critical Care Flowsheet preview](preview.png)

## What is in it
- Document class: `article` with `10pt, letterpaper, landscape`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[ICU Critical Care Flowsheet on LetX](https://letx.app/templates/medical/icu-critical-care-flowsheet/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/medical/icu-critical-care-flowsheet
latexmk -pdf main.tex
```
