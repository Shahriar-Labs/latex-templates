# Patient Intake Form LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/medical/patient-intake-form/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A patient intake form on A4 laid out as nineteen tables, including a current medications table by name, dosage, frequency and purpose.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/medical/patient-intake-form/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Patient Intake Form preview](preview.png)

## What is in it
- Document class: `article` with `11pt, a4paper`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Patient Intake Form on LetX](https://letx.app/templates/medical/patient-intake-form/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/medical/patient-intake-form
latexmk -pdf main.tex
```
