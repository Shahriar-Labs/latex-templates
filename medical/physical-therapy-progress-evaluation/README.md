## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/physical-therapy-progress-evaluation.git
cd physical-therapy-progress-evaluation
latexmk -pdf main.tex
```
Compiler: **pdflatex** (see `metadata.json`).
