# Prescription Pad LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/medical/prescription-pad-template/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A prescription pad on letter paper with patient name, date of birth, insurance and allergies, an Rx number and diagnosis, and DEA and NPI number fields, in a TikZ layout.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/medical/prescription-pad-template/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Prescription Pad preview](preview.png)

## What is in it
- Document class: `article` with `12pt, letterpaper`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Prescription Pad on LetX](https://letx.app/templates/medical/prescription-pad-template/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/medical/prescription-pad-template
latexmk -pdf main.tex
```
