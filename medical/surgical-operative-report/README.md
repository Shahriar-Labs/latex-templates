# Surgical Operative Report LaTeX Template

[![Open in LetX](https://img.shields.io/badge/Open%20in-LetX-9333EA.svg)](https://letx.app/templates/medical/surgical-operative-report/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A surgical operative report with patient demographics and pre-operative and intra-operative sections laid out in tables.

Edit and compile it in your browser at **[letx.app](https://letx.app/templates/medical/surgical-operative-report/)**, with no LaTeX install and real-time collaboration. A compile takes a few seconds.

![Surgical Operative Report preview](preview.png)

## What is in it
- Document class: `article` with `10pt`
- Compiler: pdflatex
- One self-contained `main.tex`

## Use it online
Open **[Surgical Operative Report on LetX](https://letx.app/templates/medical/surgical-operative-report/)** and click *Open as Template*. It is free.

## <a name="compile"></a>Compile locally
```bash
git clone https://github.com/Shahriar-Labs/latex-templates.git
cd latex-templates/medical/surgical-operative-report
latexmk -pdf main.tex
```
